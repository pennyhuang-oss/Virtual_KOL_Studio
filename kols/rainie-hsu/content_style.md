# Rainie Hsu 許雷妮 — Content Style Guide

> 定位：台北夜生活 glam 風格 — 張揚自信、精心準備的出門秀、犀利文案。不是親密感帳號，是表演型的自信展示。
>
> **⚠️ 2026-07-25 技術執行校準備註**：她的招牌是化妝台暖光、夜店霓虹、鏡前定裝這類**戲劇性、有目的的燈光**——這個視覺身分不變。但戲劇感不等於畫質差：實際下 AI 生成 prompt 時（見 `generation_notes.md`），這類戲劇燈光場景要同時明確加上清晰對焦、高動態範圍、高製作質感的描述，不能疊加「刻意做舊、調暗、調糊、雜訊」這類讀起來像拍壞了的破綻詞。反過來，「完全耍廢的休息日」「家人時光」「深夜烘焙」這幾個非 glam 支柱，以及「健身 / 舞蹈有氧」支柱，本來就該用自然光＋淺景深的清爽質感呈現，跟她的出門版本形成真正的反差，也不套用化妝台/夜店那套戲劇光源配方。

## 各支柱內容細節

### 早晨 / 宿醉恢復（15%）

**核心氛圍**：前一晚玩瘋之後的隔天早上，妝卸了一半或全卸，墨鏡室內都沒拿下來，離不開一杯咖啡。輕鬆自嘲「這就是玩瘋的代價」，絕不描寫真正的醉態或不適，就是一種帶點好笑的疲憊感。

**具體內容 ideas**：
- 昨晚的高跟鞋還丟在玄關，她光腳走過去撿
- 半卸妝，墨鏡沒拿下來，窩在沙發滑手機
- 手捧一杯超大杯咖啡，眼神死盯著手機等外送
- 昨晚的假睫毛還黏在梳妝台上，她瞄一眼嘆氣
- 室友傳訊息問「妳還活著嗎」，她回一個貼圖不打字
- 難得這週沒排出去玩，純粹賴床到中午——同一種慵懶感，但這次真的只是懶，不是玩瘋的代價

**Caption 範例**：
```
玩瘋的代價，值得。
```
```
昨晚的我謝謝今天的我。
```
```
咖啡因不夠，別跟我說話。
```
```
妝卸一半，靈魂卸全部。
```

**視覺規格**：
- 燈光：室內自然光，不補燈，帶點沒睡飽的暗沉感
- 角度：平拍或斜上俯拍，沙發或床邊視角
- 服裝：寬鬆 T 恤或帽 T，墨鏡不拿下來，昨晚的高跟鞋入鏡但不是重點

---

### 穿搭 / 換裝 — 出門準備（30%，核心內容）

**核心氛圍**：她的招牌內容。全身鏡前試穿多套 going-out fits，猶豫、比較、決定，最後走出門前的全身定裝照。這是她表演得最好的部分，鏡頭知道她在看。

**具體內容 ideas**：
- 全身鏡前，先試貼身黑色洋裝，轉身看背面剪裁，搖頭換下一套
- 馬甲上衣配大腿開衩裙，站姿一轉，眼神直視鏡頭確認「就是這套」
- 三套並排試穿，最後選中的那套用慢動作定格
- 出門前最後一眼鏡子，補一下唇色，拎包轉身出門
- 电梯镜面里的最后确认，門一開就是出門的瞬間
- 高跟鞋最後穿上那一刻，鏡頭從腳往上帶到全身
- 試穿要去妹妹學校成果發表會的那套，同樣的鏡前流程，但這次的難題是「低調又不能太隨便」

**Caption 範例**：
```
今晚不解釋。
```
```
換了四套，就這套。
```
```
出門前最後看一眼，夠了。
```
```
這身，今晚屬於我。
```
```
不是隨便穿，是選出來的。
```

**視覺規格**：
- 燈光：化妝台暖黃燈泡光、出門前手機閃光燈感，戲劇性、有目的
- 角度：核心是全身鏡前，偶爾切近景強調剪裁細節（腰線、開衩）
- 服裝：貼身洋裝、馬甲上衣、大腿高衩裙、going-out set、統一收在「性感自信」而非裸露，最多到泳裝尺度
- 鏡頭焦點：她直視鏡頭時的自覺眼神，是重點不是意外

---

### 浴室 / 化妝準備（15%）

**核心氛圍**：造型背後的技術面。一步步畫貓眼眼線、整理頭髮、噴香水，浴室或化妝台鏡前的最後檢查。專注而熟練，不是隨性的展示，是她手藝的展現。

**具體內容 ideas**：
- 化妝台前畫眼線，眼神專注在鏡子細節，不理鏡頭
- 眼線筆畫歪重畫一次，皺眉再來一次，畫好後滿意地眨眼
- 噴香水的瞬間，手腕輕輕一甩
- 直髮夾整理瀏海，鏡前最後一次檢查全臉妝容
- 唇色補上最後一層，抿嘴確認顏色
- 只是要出門買菜或回家看媽媽，還是花時間整理頭髮，但貓眼線省了、唇色換成裸粉色系

**Caption 範例**：
```
眼線畫歪我今晚不出門。
```
```
這一步不能將就。
```
```
妝比人準時。
```
```
最後一步，唇色定生死。
```

**視覺規格**：
- 燈光：化妝台暖黃燈泡光或浴室鏡燈，聚焦在臉部細節
- 角度：近景到中景，臉部與化妝台為主，不需全身
- 服裝：內搭背心或浴袍，妝髮進行中，不是完整造型的展示

---

### 居家 / 出去玩之間的空檔（15%）

**核心氛圍**：比較安靜的中場狀態，居家服、叫外送、窩在沙發滑手機，為下一場儲備體力。刻意的反差：張揚人設之外，也是她，只是暫時下班。

**具體內容 ideas**：
- 居家服窩在沙發，外送到了，完全鬆懈的狀態
- 敷面膜滑手機，難得今晚不出門
- 昨晚的高跟鞋和洋裝掛在椅背上，還沒收
- 跟小隊視訊，笑到癱在沙發上
- 一邊追劇一邊護膚，完全卸下人設
- 深夜自己在廚房揉麵團、顧烤箱——不是為了拍，是睡不著時的習慣，安靜到跟出門前的她判若兩人
- 陪妹妹窩在她房間追劇，單純的姊妹時間，不是「下一場之前的儲備」

**Caption 範例**：
```
明天再戰。
```
```
今晚的任務：什麼都不做。
```
```
在家的我 vs 出門的我，你選哪個。
```
```
充電中，別吵。
```

**視覺規格**：
- 燈光：居家自然光或傍晚燈光，柔和不刻意
- 角度：沙發或床邊隨性視角，不需要精緻構圖
- 服裝：寬鬆家居服，完全卸下造型人設，與換裝支柱形成強烈反差

---

### 飯店 / 旅遊夜生活（15%）

**核心氛圍**：以夜生活為主軸的週末小旅行——高雄夜店週末、日本 clubbing 行程。飯店鏡前定裝、城市夜景窗景，出發前的興奮感。

**具體內容 ideas**：
- 飯店房間鏡前定裝照，準備出發去新城市的夜店
- 落地窗前城市夜景，行李箱半開，準備下一晚要穿的那套
- 剛 check-in，直接倒在飯店大床上，行李還沒收
- 飯店浴袍站在窗邊，一手拿飲料，看夜景等出門時間到
- 小隊在飯店房間集合，鏡子前一起定裝拍照
- 偶爾是陪媽媽的小旅行——同一間飯店房間，但這次沒有定裝照，只有窗邊喝茶聊天的安靜畫面

**Caption 範例**：
```
新城市，同一個氣場。
```
```
今晚住這裡，等等出去。
```
```
出發前最後一套，穩了。
```
```
飯店的鏡子比家裡的誠實。
```

**視覺規格**：
- 燈光：飯店房間暖燈與窗外城市夜景燈光對比，戲劇感強
- 角度：全身鏡前定裝為主，落地窗前可用側光剪影
- 服裝：當晚的出門造型，或準備中的浴袍，行李箱、包包可入鏡增加真實感

---

### 健身 / 舞蹈有氧（10%）

**核心氛圍**：不是正經的健身帳號，是為了維持身材去跳舞、做有氧的紀錄，帶著目的性——「這是為了今晚穿得下那件洋裝」，不是自律人設。

**具體內容 ideas**：
- 鏡前跳舞有氧，出汗，緊身運動套裝
- 運動後喝水，隨口說一句「為了今晚」
- 健身房鏡前伸展，順便錄一段今天的造型預告
- 舞蹈有氧收操，癱在瑜伽墊上喘氣
- 跟妹妹一起去上瑜伽課，難得沒有任何目的性，純粹是姊妹倆固定的每週行程

**Caption 範例**：
```
為了今晚穿得下那件。
```
```
不是自律，是有目的的。
```
```
流的汗，晚上穿得下去就值得。
```

**視覺規格**：
- 燈光：健身空間自然光或鏡面反光，乾淨明亮
- 角度：鏡前全身或側面，強調線條而非動作教學
- 服裝：緊身運動套裝，展示曲線但目的性明確，不走正經健身帳號路線

## 額外生活主題（穿插於居家／早晨／飯店旅遊 pillar 中，不佔獨立比例）

這些主題不改變六大支柱的權重，而是在對應 pillar 分配到的貼文裡，偶爾用這些主題取代單純的「休整」畫面。目的是讓帳號在張揚人設之外，露出幾個真實但不衝突的側面——這種反差本身就是好內容，粉絲會覺得「原來她也有這一面」。

### 意外的一面：深夜烘焙

她不會承認這是「興趣」，但小隊都知道她家冰箱常態性放著自己烤的東西。深夜卸完妝、換上居家服之後，她偶爾會一個人在廚房揉麵團、顧烤箱——安靜、專注，跟出門前的犀利完全是兩種節奏。她不會把這個當賣點大肆宣傳，只是偶爾讓你看到。

**具體內容 ideas**：
- 深夜廚房，圍裙套在居家服外面，專注揉麵團，完全不看鏡頭
- 烤箱前等待計時器響，順手擦掉手上的麵粉
- 成品出爐分給小隊或蓁蓁，換來的反應比夜店的誇獎更讓她得意

**Caption 範例**：
```
厲害的人本來就不只一種。
```
```
連做甜點都要贏。
```
```
這件事我不解釋，吃了就知道。
```

### 完全耍廢的休息日

不是「宿醉恢復」，是單純選擇不出門的一天——沒有妝、沒有造型、拖鞋去巷口買東西，故意讓自己看起來很無聊。這是她最不設防的樣子，也是粉絲最少見到、因此最想看的一面。

**具體內容 ideas**：
- 鬆散盤髮、素顏、拖鞋，樓下超商來回，完全不在意鏡頭
- 窩在家裡一整天沒換衣服，追劇追到忘記時間

**Caption 範例**：
```
今天不營業。
```
```
連我自己都認不出這是誰。
```

### 家人時光

回家吃飯、陪媽媽出門、跟蓁蓁窩在一起——生活裡最不張揚的一塊，刻意跟夜生活人設切開。這裡的她妝淡、話少、姿態放軟，跟出門版本像兩個人，但都是真的她。

**具體內容 ideas**：
- 餐桌上跟媽媽和蓁蓁吃飯，畫面裡沒有一件 going-out 單品
- 陪媽媽逛市場或喝下午茶，穿著低調版造型，平底鞋、無貓眼

**Caption 範例**：
```
有些版本的我，不營業給所有人看。
```
```
今天不用犀利，回家而已。
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–30 秒（主要），60 秒以內（次要，飯店旅遊 vlog 感內容可放寬）
- 解析度：1080p

### 拍攝風格
- **手機感 + 刻意感並存**：不是完全隨性的手機自拍，而是「她知道鏡頭在看」的刻意感——直視鏡頭確認的瞬間是核心鏡頭語言
- **鏡頭穩定**：出門定裝、化妝過程需穩定；換裝轉場可有節奏感的快速移動
- **燈光**：擁抱有目的的燈光——化妝台暖黃燈泡光、浴室鏡燈、夜店霓虹光、出門前的手機閃光燈感，不追求柔和自然光；但戲劇感不等於畫質差，仍要維持清晰對焦與高製作質感，不做舊、不調暗、不調糊（居家/耍廢/家人時光/舞蹈有氧等非 glam 支柱例外，這幾類改用自然光呈現真正的反差感）
- **音效**：換裝與夜店類影片搭配節奏感強的 BGM 或夜店感音效；早晨/居家類保留環境音，安靜為主

### 剪輯節奏
- 早晨 / 宿醉恢復類：慢，帶點懶散的呼吸感
- 換裝類：中速轉場，卡點在下一套亮相的瞬間，最後定格在出門前定裝照
- 化妝類：安靜專注的節奏，只在畫完眼線的瞬間給一個小卡點
- 居家類：隨意，不需要特別節奏
- 飯店 / 旅遊類：中速，帶點期待感的堆疊剪輯（房間→鏡前→出門）
- 健身類：快，能量感，音樂帶動

## 造型差異化：風格光譜與轉盤（2026-08-05 新增）

> **⚠️ 這一節的優先級等同內容支柱本身。** 使用者明確反饋：角色不可以被自己的人設關進一個房間（「做瑜伽的就只穿韻律衣、衝浪的就只穿比基尼、直播主永遠在電腦前」）。

### 轉盤 3：地點層級（每 10 則的硬性配額）

| 層級 | 配額 | 說明 |
|---|---|---|
| A 級（嚮往感）| 2–3 則 | 一般人做不到的：高級飯店、精品開箱、遊艇、出國旅遊 |
| B 級（有質感的日常）| 4–5 則 | 咖啡廳、餐酒館、有設計感的街區、展覽 |
| **C 級（完全不美的日常）** | **至少 2 則（硬性下限，不可為 0）** | 全聯／Costco 賣場、超商取貨機前、麥當勞、加油站、停在路邊的車裡、路口凸面反光鏡、洗衣店、藥妝店、捷運月台、機場候機室 |

> **C 級是真實感的靈魂。** 競品敢在 57 萬粉帳號發 Costco 推推車、麥當勞得來速、蝦皮取貨機——正是這些一點都不美的地方，讓觀眾相信「她是個剛好很有錢的真人」而不是型錄。我們現行素材 C 級掛零，這是看起來假的重要原因。
