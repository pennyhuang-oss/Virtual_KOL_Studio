## 各支柱內容細節

### 早晨 / 起床（20%）

**核心氛圍**：京都的早晨極安靜。紙拉門的光，被子的溫度，Mochi（貓）蜷在腳邊。她從這一切慢慢醒來，不急。

**具體內容 ideas**：
- 被子裹著，只露臉，眼睛還沒完全開
- 紙拉門或窗簾邊的晨光，人在被子裡看向光的方向
- 床上側躺，黑色細直髮散在枕頭上，看著鏡頭
- 貓跳上床，她把手伸出被子摸了一下
- 慢慢坐起來，被子滑下肩膀，呆坐著

**Caption 範例**（日文）：
```
今朝も布団から出たくない
```
```
もう少しだけ
```
```
京都の朝、静かすぎてまだ夢の中みたい
```
```
Mochiに起こされた
```

**視覺規格**：
- 柔和自然光，紙拉門光或白色薄窗簾光最佳
- 白色或米白床鋪
- 低飽和，奶白暖調
- 不補燈，光要柔

---

### 穿搭 / 換衣服（20%）

**核心氛圍**：她的穿搭有自己的邏輯，柔和、素淨，偶爾有一個意外的細節。換衣服的過程比穿好的結果更有看頭。

**具體內容 ideas**：
- 白色蕾絲上衣試穿，鏡前轉了一下，點頭決定
- 換上碎花棉質洋裝，拉好肩帶，看看鏡子
- 奶油色 oversized 毛衣，袖子很長，把手藏進去
- 睡衣換到日常服的過程，從最少開始
- 試穿兩件，最後選了更簡單的那件

**Caption 範例**：
```
今日のコーデ
```
```
これにした
```
```
シンプルが一番かな
```
```
悩んで悩んでこれ
```

**視覺規格**：
- 全身鏡或衣帽間感
- 自然光，不要強打燈
- 奶油色、白色、淺米色為主調
- 身材線條自然可見，不刻意強調

---

### 浴室 / 洗完澡（15%）

**核心氛圍**：她洗完澡之後是整個人最放鬆的狀態。白瓷感的皮膚，濕髮，浴巾，浴室鏡前那幾分鐘是她一天中最安靜的時刻。

**具體內容 ideas**：
- 浴巾裹著，濕髮，對著鏡子發呆
- 用護髮油整理濕髮，動作細緻，側臉
- 浴室鏡自拍：素顏，浴巾，霧氣在鏡角
- 塗身體乳，動作輕柔，鏡頭中景
- 洗完臉，拍了拍臉上的水，抬頭看鏡

**Caption 範例**：
```

```
```

```
```

```
```

```

**視覺規格**：
- 浴室暖燈，白色磁磚感
- 鏡中倒影構圖
- 白色浴巾
- 霧氣效果自然，不刻意製造

### 在家 / 窩著（20%）

- 下午的光打進來，她在看書，沒發現有人在拍

### 飯店 / 旅行（15%）

**核心氛圍**：她不常旅行，但去了就會很安靜地享受那個空間。飯店的床比家裡的整，窗外的景不熟悉，那種輕微的陌生感才是旅行的質感。

**具體內容 ideas**：
- 東京或大阪飯店，床上，窗外是城市夜景
- 飯店浴室：比家裡更現代的設計，同樣的洗完澡狀態
- 新幹線上：靠窗，看窗外，頭靠在玻璃上
- 飯店的早晨：白色被子，窗外的城市還很安靜
- check-in 第一晚：行李放著，坐在床邊看房間

- 飯店白色床鋪，俐落設計感
- 城市夜景或清晨光線作為背景
- 她的東西（小包包、護膚品）入鏡增加真實感

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–30 秒（主要），最長 45 秒
- 解析度：1080p

### 拍攝風格
- **極安靜感**：環境音為主，幾乎不說話，BGM 選輕柔日本獨立音樂或鋼琴
- **鏡頭穩定**：非常穩，像她的性格一樣不急不晃
- **燈光**：自然光，柔散光，不用人工燈
- **色調**：低飽和奶白暖調，Fuji 底片感

### 剪輯節奏
- 早晨類：極慢，幾乎沒有剪輯，長鏡頭
- 換裝類：中速，安靜卡點，不誇張
- 浴室類：一個鏡頭，不剪，只有環境音
- 在家類：幾乎靜態，像一張會動的照片
- 運動類：慢，有呼吸感，不是激烈感

## Caption 語言與語氣（2026-08-25 新增）

### 語言比例：中文為主

她人在台灣、逛的是台灣的店、代言的是台灣的餐廳——**觀眾看不懂日文就沒有意義**。

| 形式 | 比例 | 說明 |
|---|---|---|
| **純中文** | 約 50% | 日常主力 |
| **中文 ＋ 一句日文** | 約 35% | 她的招牌。日文放結尾或開頭當簽名 |
| 純日文 | 約 15% | 回日本時、或特別的心情 |

### 語氣：可愛、軟，話少但有溫度

她話少是人設核心，**但「少」不等於「冷」**。20 歲的日本女生在台灣生活，
語氣應該是軟的、可愛的、偶爾笨笨的。

- 句子短，可以只有一行
- 會用「好可愛」「好好吃」「好厲害」——**重複強調是她的招牌**（「好吃…真的很好吃」）
- 會有小失敗、小驚喜——扭蛋轉不到、雨傘忘記帶
- Emoji **1–2 個**，不堆疊。她的常用：🌙 🍓 ☔️ 🐈 🥺 ✨
- 長度 10–20 字

### 範例

```
草莓蛋糕🍓
今天也是很好的一天
```
```
Mochi 也搬家了！
花了兩個月才習慣🐈
```
```
台北下雨了☔️
雨の台北、こういう日が好き
```
```
這個扭蛋轉了五次才轉到😭
但很可愛所以沒關係
```
```
いただきます🙏
好吃…真的很好吃
```
```
今天的光很好🌙
```

**盡量避免**：hashtag 堆疊、長篇解釋、推薦語氣、emoji 排排站。
（這是語氣的預設方向——真的有需要時當然可以破例。）

## 妝容基準（2026-08-25 新增）

`character.md` 一直沒寫妝容，但生成時不寫，模型會自己決定，每張都不一樣。

**基調：日系可愛。乾淨、明亮、有少女感。**

| 部位 | 預設 |
|---|---|
| 底妝 | 明亮白皙、輕薄通透，**保留自然質感與毛孔**（⚠️ 英文不可寫 `porcelain skin`） |
| 眉 | 平緩自然眉，顏色偏淺 |
| 眼影 | **粉色系**為主，暈染在眼窩與下眼瞼；下眼瞼打亮 |
| 眼線 | 細內眼線，不上揚（不要韓系的銳利感） |
| 睫毛 | **下睫毛要看得出來**——這是日系可愛妝的識別點 |
| 腮紅 | **曬傷妝**：淡粉色橫跨鼻樑與兩頰上方 ← **她最重要的妝容特徵** |
| 唇 | 粉色或珊瑚色水潤唇，**唇中心加深的漸層唇** |

**變化範圍**（不是每張都一樣）：
- **素顏場景**（剛起床、洗完澡）：保留一點唇色，其餘乾淨
- **和服／祭典**：可以稍濃——加一點紅色眼尾與更明確的漸層唇
- **出門玩**：標準可愛妝

> 這是**預設值與範圍**，不是每張都要照抄。她是活人，會有精心打扮的一天，
> 也會有素顏在家跟貓待一整天的一天。

## ⚠️ 這份文件的規則怎麼讀

本檔（以及 `character.md`）裡的規定分兩類，**份量完全不同**：

| 類型 | 例子 | 怎麼看待 |
|---|---|---|
| **技術性**（少數，真的要遵守） | 英文不可寫 `porcelain skin`／`smooth`／`flawless`（會把皮膚推成塑膠感）、光線段落不可寫 `high dynamic range`／`well-exposed`（等於兩邊都不犧牲＝假）、生成時髮型髮色必須寫明（Soul V2 不繼承） | 這些是**AI 生成的技術問題**，不是美學偏好。照做就對了 |
| **風格偏好**（絕大多數） | 妝容基準、穿搭區間、場景清單、色調、caption 語氣 | 這些是**預設值與範圍**，用來避免每則都長一樣。**不是不能違反的規定** |

**第二類的東西不要當成鐵律。**

她是我們創造的虛擬人，不是被鎖在設定裡的角色。今天要她做什麼、走什麼風格，
我們隨時可以改——**這正是虛擬 KOL 相對真人最大的價值**。
如果把風格設死到每張都必須符合，版面會單調，而且一看就假。

所以：**看到「不要 X」「避免 X」的時候，讀成「這不是她的主軸」，不是「絕對禁止」。**
真正不能鬆動的只有內容尺度（SFW）與上面那格技術性規則。
