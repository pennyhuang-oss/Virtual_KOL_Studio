## 各支柱內容細節

### 早晨 / 起床（20%）

**核心氛圍**：京都的早晨極安靜。紙拉門的光，被子的溫度，Mochi（貓）蜷在腳邊。她從這一切慢慢醒來，不急。

**具體內容 ideas**：
- 被子裹著，只露臉，眼睛還沒完全開
- 紙拉門或窗簾邊的晨光，人在被子裡看向光的方向
- 床上側躺，黑色細直髮散在枕頭上，看著鏡頭
- 貓跳上床，她把手伸出被子摸了一下
- 慢慢坐起來，被子滑下肩膀，呆坐著

**Caption 範例**（日文）：
```
今朝も布団から出たくない
```
```
もう少しだけ
```
```
京都の朝、静かすぎてまだ夢の中みたい
```
```
Mochiに起こされた
```

**視覺規格**：
- 柔和自然光，紙拉門光或白色薄窗簾光最佳
- 白色或米白床鋪
- 低飽和，奶白暖調
- 不補燈，光要柔

---

### 穿搭 / 換衣服（20%）

**核心氛圍**：她的穿搭有自己的邏輯，柔和、素淨，偶爾有一個意外的細節。換衣服的過程比穿好的結果更有看頭。

**具體內容 ideas**：
- 白色蕾絲上衣試穿，鏡前轉了一下，點頭決定
- 換上碎花棉質洋裝，拉好肩帶，看看鏡子
- 奶油色 oversized 毛衣，袖子很長，把手藏進去
- 睡衣換到日常服的過程，從最少開始
- 試穿兩件，最後選了更簡單的那件

**Caption 範例**：
```
今日のコーデ
```
```
これにした
```
```
シンプルが一番かな
```
```
悩んで悩んでこれ
```

**視覺規格**：
- 全身鏡或衣帽間感
- 自然光，不要強打燈
- 奶油色、白色、淺米色為主調
- 身材線條自然可見，不刻意強調

---

### 浴室 / 洗完澡（15%）

**核心氛圍**：她洗完澡之後是整個人最放鬆的狀態。白瓷感的皮膚，濕髮，浴巾，浴室鏡前那幾分鐘是她一天中最安靜的時刻。

**具體內容 ideas**：
- 浴巾裹著，濕髮，對著鏡子發呆
- 用護髮油整理濕髮，動作細緻，側臉
- 浴室鏡自拍：素顏，浴巾，霧氣在鏡角
- 塗身體乳，動作輕柔，鏡頭中景
- 洗完臉，拍了拍臉上的水，抬頭看鏡

**Caption 範例**：
```
お風呂上がり、一番好きな時間かも
```
```
やっと入れた
```
```
すっぴんでごめんね
```
```
湯上がり、幸せ
```

**視覺規格**：
- 浴室暖燈，白色磁磚感
- 鏡中倒影構圖
- 白色浴巾
- 霧氣效果自然，不刻意製造

---

### 在家 / 窩著（20%）

**核心氛圍**：她的家像她這個人——安靜，有點老式，有貓的氣息，木頭地板，一個小書架。她在這裡是最真實的狀態。

**具體內容 ideas**：
- 木地板上盤腿坐著，Mochi 在旁邊，輕薄睡衣或大 tee
- 趴在榻榻米上，下巴撐著手，看向鏡頭
- 窩在沙發角落，毛毯，手裡一杯茶，什麼都不做
- 下午的光打進來，她在看書，沒發現有人在拍
- 地板上仰躺，Mochi 走過她身上

**Caption 範例**：
```
何もしない日
```
```
Mochiと一緒にゴロゴロ
```
```
今日は家から出ない
```
```
お気に入りの場所
```

**視覺規格**：
- 家裡自然光，偏暖偏柔
- 榻榻米、木地板、低矮家具
- 貓可以入鏡
- 不整理背景，生活感保留

---

### 飯店 / 旅行（15%）

**核心氛圍**：她不常旅行，但去了就會很安靜地享受那個空間。飯店的床比家裡的整，窗外的景不熟悉，那種輕微的陌生感才是旅行的質感。

**具體內容 ideas**：
- 東京或大阪飯店，床上，窗外是城市夜景
- 飯店浴室：比家裡更現代的設計，同樣的洗完澡狀態
- 新幹線上：靠窗，看窗外，頭靠在玻璃上
- 飯店的早晨：白色被子，窗外的城市還很安靜
- check-in 第一晚：行李放著，坐在床邊看房間

**Caption 範例**：
```
旅先の朝
```
```
知らない街で目が覚めた
```
```
ホテルのベッドが好き
```
```
ちょっと遠くに来た
```

**視覺規格**：
- 飯店白色床鋪，俐落設計感
- 城市夜景或清晨光線作為背景
- 她的東西（小包包、護膚品）入鏡增加真實感

---

### 健身 / 運動（10%）

**核心氛圍**：她不上健身房，但她做瑜伽、拉伸，在家裡，早上，動作緩慢，溫柔，像她這個人。

**具體內容 ideas**：
- 家裡木地板，瑜伽墊，晨光，做前屈或貓牛式
- 拉伸動作，柔軟，身體線條在光中可見
- 做完，坐在瑜伽墊上，喝水，放鬆看向鏡頭
- 慢跑回來，坐在玄關換鞋，還有點喘
- 腿部拉伸，靠著牆，動作安靜

**Caption 範例**：
```
朝のストレッチ
```
```
ゆっくりやってる
```
```
体が喜んでる気がする
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–30 秒（主要），最長 45 秒
- 解析度：1080p

### 拍攝風格
- **極安靜感**：環境音為主，幾乎不說話，BGM 選輕柔日本獨立音樂或鋼琴
- **鏡頭穩定**：非常穩，像她的性格一樣不急不晃
- **燈光**：自然光，柔散光，不用人工燈
- **色調**：低飽和奶白暖調，Fuji 底片感

### 剪輯節奏
- 早晨類：極慢，幾乎沒有剪輯，長鏡頭
- 換裝類：中速，安靜卡點，不誇張
- 浴室類：一個鏡頭，不剪，只有環境音
- 在家類：幾乎靜態，像一張會動的照片
- 運動類：慢，有呼吸感，不是激烈感
