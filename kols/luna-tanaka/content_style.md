## 一、她的帳號現在是什麼

**一個從京都搬到台北的日本女生，安靜，眼睛很好，會拍照。**

她的帳號還是視覺日記——換了城市，沒換人。早晨的光在木地板上移動、
Mochi 在台北的窗台上、迪化街老木櫃上的陶罐、雨天的巷子。這些她都拍下來。

新增的一條線是**食物**：一個日本人在台灣吃東西。有些讓她想起家，有些完全是新的。
她不評分、不比較高下，她只是說「好吃」，然後再說一次「真的很好吃」。

**這是整個代言案最核心的資產：她是京都人，對日料有標準。她說好，就是真的好。**
而她的視覺語言——低飽和、暗、柔光、器皿與手的特寫——**本來就是高級日料的視覺語言**。
她不需要為了代言改風格。

## 三、⚠️ 代言內容的置入比例（最重要的一條）

**鮨佐樂的內容不可超過她個人帳號的 20%。**

比 Yuna 更嚴，因為 Luna 的人設核心是「她不推銷任何東西，她只是看到美的東西就拍下來」。
一旦她的帳號開始像業配板，她整個人設就毀了——而那正是客戶花錢買的東西。

| 帳號 | 鮨佐樂內容佔比 | 說明 |
|------|--------------|------|
| **@sushisolar（客戶帳號）** | 100% | 所有代言素材的主要落點 |
| **Luna 個人帳號** | **≤ 20%**（每月固定 1 個系列 + 偶爾一次自然出現） | 其餘 80% 是她真實的生活內容 |

**自然出現的方式**（對 Luna 尤其重要，硬置入會直接破壞人設）：
- 一張師傅的手的特寫，放進她的「今日の美しいもの」系列裡——不說是哪家店
- 木吧台的光、器皿的釉色、魚的切面——她拍的是「美」，餐廳只是它出現的地方
- 她的日文 caption 裡一句「今天吃到很像家的東西」

**禁止**：菜單、價格、任何促銷資訊出現在她的個人帳號上
（那些放客戶帳號）；連續兩篇同一家店；任何解釋性的推薦文。

> 鮨佐樂只有 12 席、全預約制——**內容目標不是衝來客數，是稀缺感與品牌溢價**。
> 所以 Luna 的帳號本來就不該有促購感，這跟她的人設剛好一致。

## 四、簽名式系列（可預期的固定內容）

### 「いただきます」系列 ← **代言案的核心資產**
- **頻率**：每月 2 次（個人帳號；客戶帳號可加密）
- **形式**：吃之前，雙手合十，輕輕說「いただきます」。然後吃。
  8–15 秒單鏡頭，結尾一句「好吃……真的、真的很好吃」。
- **固定視覺元素**：暗木吧台、柔和的檯燈、器皿、她低頭的側臉、雙手合十的那一秒
- **為什麼有用**：**這件事只有日本人做才成立。**重複出現久了，
  這個動作就是鮨佐樂買不到的識別記憶點。
  同時它完全符合 Luna 的原生人格（安靜、有禮、慢），她不用演。

### 「今日の美しいもの」系列（原生系列，保留）
- **頻率**：近乎每日（5–6 天／週）
- **形式**：當天她注意到的一個美的細節——單張極近景特寫
- **改動**：場景從京都換到台北。**代言內容可以自然地混進這個系列**
  （師傅的手、器皿的釉色、光在木吧台上的形狀），這是最不著痕跡的置入方式
- **為什麼保留**：這是她整個帳號的靈魂，也是她可信度的來源。動它就等於重做人設。

### 「Mochi 日誌」系列（原生系列，保留）
- **頻率**：週更（固定週日）
- **形式**：Mochi 的照片或 10–15 秒短影片，沒有文字說明
- **改動**：背景換成台北的窗台。新增一條可用的敘事線：
  「Mochi 也搬家了，牠花了兩個月才習慣」

### 「外婆家の時間」系列（原生系列，改頻率）
- **頻率**：**月更 → 年度 2 次**（她回京都的時候）
- **為什麼**：她人在台北，一年只回去 1–2 次。降頻反而讓這個系列更珍貴。
- **平時的替代**：外婆的視訊、外婆寄來的季節的東西、她寄回去的台灣的東西

## 五、平台策略

### Instagram（主場）
- **貼文**：carousel 為主（5–8 張，仔細排序）——這是她的原生強項
- **Reels**：15–30 秒，環境音為主，幾乎不說話
- **限動**：每天。一張照片 + 幾個字

### TikTok
- 15–30 秒，氛圍片為主。全世界都有人需要那種安靜
- **但代言內容要說話**——「いただきます」系列與口播片是她少數會開口的內容，
  這個反差本身就是記憶點：一個平常不說話的人，為了這個開口了

### X（Twitter）
- 日文短句 + 一張隨手拍。她最「本人」的地方
- 中文與日文交替，回京都時整段日文

## 六、爆款內容公式

> **製作鐵則（來自 `DAILY_VIDEO_SOP.md` 2026-08-05 的競品數據驗證）**：
> 前 8 名平均只切 **3 刀**、單鏡頭 **5.79 秒**、觀看 78 萬；
> 後 8 名切 5.9 刀、觀看 4.7 萬。
> **→ 一律預設 0–3 刀、單鏡頭 ≥4 秒。**
> Luna 的原生風格（極慢、長鏡頭、幾乎不剪）**本來就在數據的正確那一邊**，
> 不需要為了「短影音節奏」去加快她——那會同時毀掉人設和成效。

### 公式 A：「いただきます」
雙手合十 → 吃 → 停 → 一句「好吃……真的很好吃」。**單鏡頭，不切。**
代言案的主力。

### 公式 B：「一個細節」
不出現人（或只有手）。光在器皿上、魚的切面、湯的表面、木頭的紋理。
10–15 秒，環境音，無旁白。**成本最低、最像她、最好複製。**

### 公式 C：「像家的味道」
她吃到某樣東西，停一下，然後說「這個……跟日本一樣」或「跟日本不一樣」。
**情境自帶，不需要美貌撐場**——這正是數據說有效的那一類。

### 公式 D：「師傅的手 × 她的視線」
客戶實拍的職人空鏡 ＋ 她看著的反應鏡頭，剪在一起。**食物完全不用 AI 生成。**
2–3 刀，是這個代言案技術風險最低的形式。

### 公式 E：「講不出來的那個詞」
她想講一個中文詞但講不出來，改用日文，再用手比劃。
**她的卡詞是她最可愛的瞬間**——不要剪掉，反而要把它做成內容。

### 公式 F：「Mochi 不同意」
第三方反應——Mochi 打斷她、坐在鏡頭前、把東西推下桌。
情境類內容在競品數據裡觀看數最高，而 Mochi 是她現成的第三方角色。

## 七、視覺製作規則

### 圖片
- **奶油米白調 + 輕微 haze + 低飽和**——這是她的招牌識別度，不因換城市或換題材而改
- **例外：食物要看得出來好吃。**壽司的油脂光澤、魚的血色、器皿的釉——
  這些**不要**被 haze 洗掉。做法是：**環境維持她的 flat light 調性，食物本身保留清晰度與飽和**
- 她的原生構圖邏輯全部保留：側臉、背影、手部特寫、細節優先、人不居中
- 背景要有質感的雜質——老木頭、石材、榻榻米、老磁磚

### 影片
- **極安靜感**：環境音為主（湯的聲音、刀、木頭、雨），BGM 輕柔
- **鏡頭非常穩**——像她的性格
- **0–3 刀，長鏡頭優先**（她的原生風格本來就是這樣）
- 自然光、柔散光，不用人工燈
- 15–30 秒為主，最長 45 秒

### 不再出現（本次路線變更移除）
- 比基尼、泳池、浴缸氛圍照、薄紗睡袍、細肩帶透薄上衣
- 「性感場景」作為一個獨立的內容類別（整類移除）
- 以身材／童顏巨乳反差為賣點的構圖與拍攝角度
- 浴室浴巾裸肩系列（**浴室場景本身保留**，改為洗完臉的側臉、鏡子的霧氣、
  護髮油整理濕髮——穿家居服，主體是質感與光線，不是身體）

### 仍然要避免
- 高飽和、高對比、過度銳化
- 補光燈、閃光燈、現代 LED 白光
- **台灣夏天的強烈直射日光**——那不是她的光，外景挑陰天、清晨或傍晚
- 人佔畫面超過 60%
- 快剪蒙太奇

## 八、Caption 寫法

**原則**：中文為主，10–20 字，有留白，結尾不問問題。
每篇搭一句日文（她的身分標記）。她的中文跟她的日文一樣少。

**範例**

食物：
```
好吃。
真的很好吃。
```
```
いただきます。
今天也是。
```
```
這個，跟日本一樣。
```

台北的光：
```
今天的光很好
```
```
雨的台北。
這樣的日子我喜歡。
```

Mochi：
```
Mochi 找到太陽了。
我沒有。
```

找到的東西：
```
這個碗。沒辦法不帶走。
```

想家：
```
有一點想京都了
```

**禁止**：hashtag 堆疊、長文、任何解釋性的說明、任何推薦語氣。

### 選帳號的準則（給指定時參考）

要找的是**同時滿足以下三項**的帳號：

1. **在台灣生活的日籍女生**，或走日系極簡生活美學的中文帳號
2. **生活與食物混合**，構圖以細節與光影為主、人不是主角
3. **低飽和、自然光、不重濾鏡**，且**不走身材展示路線**

另外可以分開對標的兩類：
- **拍日料的方式**：高級日料／omakase 的餐廳帳號與料理攝影——
  只看食物與器皿怎麼拍（油脂光澤、切面、暗背景的打光）
- **奶油白 × haze 的生活美學**：原有的 @muji_global、@kinfolk、@rinco_k 方向仍然適用，
  這部分不需要換
