> 方向：高雄健身正妹 — 真實訓練感、力量自信、body-positive。不是健身網美濾鏡帳號。

## 各支柱內容細節

### 早晨 / 出門前（15%）

**核心氛圍**：高雄的早晨，熱度還沒完全上來，她已經是準備出門訓練的狀態——運動服上身、頭髮正在往上綁，沒有多餘的鋪陳，晨練前那種收心的情緒。

**具體內容 ideas**：
- 鏡子前把頭髮綁成高馬尾，運動內衣和緊身褲已經穿好
- 廚房快速吃點東西（香蕉、蛋白棒），運動包放在旁邊椅子上
- 賴床多滑五分鐘手機，回思穎昨晚傳的迷因和媽媽的貼圖，才心不甘情不願爬起來
- 綁鞋帶、拿水壺，最後看一眼手機確認今天的訓練菜單
- 一邊喝黑咖啡一邊滑手機看今天要帶的學員名單

**Caption 範例**（繁體中文）：
```
六點半的鬧鐘沒在跟你商量
```
```
頭髮綁好，人還沒醒，但要出門了
```
```
今天菜單有硬舉，先讓我醒一下
```
```
出門前的自己，先醜後美
```
```
賴床五分鐘先回完閨蜜的迷因，才算真的起床
```

**視覺規格**：
- 光線：自然晨光，硬光為主，不柔焦不夢幻
- 場景：住家鏡子前或廚房，簡單不刻意佈置
- 角度：平拍或稍微俯拍，捕捉綁頭髮、穿鞋的動作
- 穿著：運動內衣＋緊身褲，外套尚未罩上

### 穿搭 / 訓練服（15%）

**核心氛圍**：不是時尚穿搭，是機能穿搭——今天配哪套運動內衣、哪件緊身褲，練完隨手拉開或滑落一邊肩膀的帽 T。實用、自信、完全不做作。

**具體內容 ideas**：
- 站在全身鏡前，比對兩三款運動內衣配色，最後選定
- 換上高腰緊身褲，轉身確認今天的訓練服適不適合腿日菜單
- 難得跟思穎約吃飯，對著衣櫃猶豫要不要穿一次「不是運動服」的衣服，最後還是選了最好活動的那件
- 練完直接把帽 T 拉鏈拉開或滑下一邊肩膀，招牌造型
- 訓練包整理：毛巾、水壺、護腕，順手拍一下今天要帶的裝備

**Caption 範例**：
```
今天這件內衣真的挺得住深蹲
```
```
帽 T 從來不是為了好看，是練完真的冷
```
```
換了兩次最後還是這套，機能第一
```
```
今天的戰袍，該蹲的都蹲得下去
```
```
難得穿一次不是運動服，衣櫃裡找半天
```

**視覺規格**：
- 全身鏡，鏡框邊緣可入鏡，不需要棚燈
- 燈光：居家燈光或健身房更衣室燈，真實不美化
- 連續換裝鏡頭比單張定格更有說服力
- 色調：偏高對比、真實膚色，不磨皮抹掉肌肉線條

### 浴室 / 練後恢復（15%）

**核心氛圍**：練完後的沖洗與恢復——沖掉汗水、冰敷或熱敷痠痛的肌肉，皮膚還帶著訓練後的紅潤。誠實、不浪漫化，就是身體被操過一輪之後的真實狀態。

**具體內容 ideas**：
- 練完沖澡，水珠還掛在肩背肌肉線條上
- 浴室地上做恢復性伸展或滾筒放鬆，毛巾隨手搭在肩上
- 冰敷痠痛的膝蓋或肩膀，表情是真實的痠痛感不是擺拍
- 換上寬鬆 T 恤前，鏡子前檢查今天練出來的泵感
- 熱敷完伸懶腰，皮膚泛紅，滿足感寫在臉上

**Caption 範例**：
```
今天這個泵感值回票價
```
```
冰敷比什麼都誠實
```
```
洗掉的是汗，洗不掉的是痠
```
```
练完这澡，才算真的下班
```

**視覺規格**：
- 燈光：浴室日光燈或暖白燈，不刻意美化
- 鏡中倒影構圖，展現訓練後的肌肉線條與微紅皮膚
- 服裝：運動內衣濕透或換上寬鬆 T，毛巾搭肩
- 不上妝，不磨皮，汗水和泛紅是重點不是缺點

### 居家 / 生活日常（15%）

**核心氛圍**：下班後的高雄公寓——備餐、地板伸展、練完整個人癱在沙發上。這是她最搞笑、最放鬆的一面最常出現的地方，跟訓練時的強勢形成反差。

**具體內容 ideas**：
- 客廳地板上做飯後伸展，旁邊放著蛋白粉罐和搖搖杯
- 跟室友一起在廚房煮晚餐，兩人搶鍋鏟，聊的是八卦不是訓練
- 抱著貓室友抹茶窩在沙發上追劇，完全不想到訓練這件事
- 備餐時間：雞胸肉、地瓜、隔夜燕麥，隨手拍不精緻
- 練完整個人癱在沙發上，運動服都還沒換，帽 T 半脫

**Caption 範例**：
```
帽 T 都沒脫就躺下了
```
```

```

```
```

**視覺規格**：
- 光線：居家自然光，下午斜射光最好
- 場景不整理，沙發、地墊、蛋白粉罐都可入鏡，越生活越對
- 角度可以更近，呈現真實的疲憊感和肌肉細節
- 服裝：crop tank ＋短褲，或直接穿著訓練服癱著

### 飯店旅遊（10%）

**核心氛圍**：她的旅遊圍繞著訓練——比賽出差、營隊移動、一到飯店先確認樓下健身房幾點開。偶爾真的放假,但訓練模式很難完全關掉。

**具體內容 ideas**：
- 比賽或營隊出差,行李還沒收好先在飯店健身房訓練一組
- 剛 check-in,對著手機查飯店健身房開放時間,語氣有點興奮
- 難得跟思穎的姐妹小旅行,行李箱裡訓練服被壓到最底層,兩人只顧著找哪裡好吃
- 少數真正放假的日子,泳池邊做伸展,嘴上說放假身體還是閒不下來
- 出差包整理:比賽服、護具、蛋白粉分裝袋一次入鏡

- 訓練裝備和飯店環境並存，不是純度假照

### 健身 / 訓練（30% — 核心支柱）

**核心氛圍**：這是她的主場，也是她帳號存在的理由——重訓、功能性訓練、破 PR 嘗試、教學員上課。真實的汗水和肌肉線條在動作中，不是拿來當背景板的健身房自拍。

**具體內容 ideas**：
- 深蹲架前，破 PR 前的專注表情，桿鈴上片的過程
- 硬舉組間休息，喘氣、擦汗、不看鏡頭，完全投入狀態
- 幫學員上課，喊配速、糾正動作、大聲數拍子
- 功能性訓練循環（壺鈴、繩索、戰繩），滿身大汗的收操瞬間
- 破 PR 當下的短影片：卸下槓鈴那一秒的爽感和隊友的歡呼
- 跟訓練夥伴互相嗆聲比重量，笑對方今天狀態差

**Caption 範例**：
```
新的重量，新的我
```
```

```
```
他今天蹲得比我輕還敢說話
```
```

```

**視覺規格**：
- 光線：健身房日光燈或大窗自然光，不是浪漫柔光，線條要清楚，汗水要看得到反光
- 鏡頭距離：中景到全身為主，展示動作和身材線條；破 PR 瞬間可用近景捕捉表情
- 色調：偏高對比、真實膚色，不磨皮不假裝沒有汗水
- 盡量避免：過度精緻、看起來沒流過汗的健身房自拍；節食暗示道具也不是她會主動入鏡的東西，因為那違背她的價值觀（見人設「絕不會說少吃一點」），但這是她的個性選擇，不是視覺上的硬性禁止

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（Instagram Reels / TikTok），16:9（YouTube 訓練 vlog）
- 時長：Reels / TikTok 30–60 秒為主，YouTube vlog 可到 5–10 分鐘
- 解析度：1080p

### 拍攝風格
- **手機感優先**：shot on iPhone 效果，自然顆粒感，訓練片段可帶輕微手持晃動（她自己或訓練夥伴隨手拍）
- **健身房實拍**：日光燈或大窗自然光為主，不補外部燈光，不做棚拍質感
- **色調**：偏高對比、真實膚色，保留汗水反光與肌肉線條，不套用柔焦濾鏡
- **音效**：保留健身房環境音（鐵片碰撞聲、喘氣聲、教練口令），搭配節奏感強的 BGM 或純環境音

### 剪輯節奏
- 早晨類：中速，簡短，有出門前的收心感
- 穿搭類：中速，換裝過程卡點，最後定格在完整造型
- 浴室類：慢，安靜，環境音為主，呈現恢復的平靜
- 居家類：隨意，不需要特別節奏，越隨性越真實
- 健身類：快，能量感強，鐵片碰撞聲與喘氣聲同步，破 PR 片段用短促剪輯放大爽感
- 飯店旅遊類：中速，行李與訓練裝備交錯出現，帶一點出差的匆忙感

## 造型差異化：風格光譜與轉盤（2026-08-05 新增）

> **⚠️ 這一節的優先級等同內容支柱本身。** 使用者明確反饋：角色不可以被自己的人設關進一個房間（「做瑜伽的就只穿韻律衣、衝浪的就只穿比基尼、直播主永遠在電腦前」）。
>
> **造型（穿搭／髮型／配件）與地點，是獨立於上方內容支柱的變數。** 決定完「這則屬於哪個支柱」之後，必須再獨立轉四個轉盤。完整系統見 repo 根目錄 `WARDROBE_SYSTEM.md`，該文件基於競品 @sherry_digitalp510 抽樣 60 則貼文／109 張圖片的實測分析。

### 轉盤 1：Vicky Lin 林薇淇 的 8 種風格區間

**配額規則**：連續兩則貼文不可落在同一區間；⚠️ 使用者點名的反例：「做瑜伽的就只穿韻律衣、韻律褲」。★運動機能 ≤30%。

| 3 | 日常有型 | 合身背心 + 高腰牛仔褲 + 短靴 |

### 轉盤 3：地點層級（每 10 則的硬性配額）

| 層級 | 配額 | 說明 |
|---|---|---|
| A 級（嚮往感）| 2–3 則 | 一般人做不到的：高級飯店、精品開箱、遊艇、出國旅遊 |
| B 級（有質感的日常）| 4–5 則 | 咖啡廳、餐酒館、有設計感的街區、展覽 |
| **C 級（完全不美的日常）** | **至少 2 則（硬性下限，不可為 0）** | 全聯／Costco 賣場、超商取貨機前、麥當勞、加油站、停在路邊的車裡、路口凸面反光鏡、洗衣店、藥妝店、捷運月台、機場候機室 |

> **C 級是真實感的靈魂。** 競品敢在 57 萬粉帳號發 Costco 推推車、麥當勞得來速、蝦皮取貨機——正是這些一點都不美的地方，讓觀眾相信「她是個剛好很有錢的真人」而不是型錄。我們現行素材 C 級掛零，這是看起來假的重要原因。
