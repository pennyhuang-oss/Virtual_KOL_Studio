## 各支柱內容細節

### 早晨 / 宿舍賴床（25%）

**核心氛圍**：早八鬧鐘響了，她還在棉被裡滾來滾去，頭髮亂糟糟，室友在旁邊催促「快遲到了」。這是她一天最沒有防備、最真實的時刻，宿舍晨光從窗簾縫透進來。

**具體內容 ideas**：
- 棉被裡探出頭，對鏡頭做鬼臉說「再五分鐘」，鬧鐘還在響
- 室友拉棉被逼她起床，兩人在鏡頭前打鬧尖叫
- 剛醒迷糊地滑手機看今天第一節課，宿舍晨光從窗簾縫透進來
- 半夢半醒地找眼鏡、找手機，摸半天摸不到
- 邊刷牙邊被室友念「妳昨晚又熬夜」，嘴裡含著牙膏泡回話
- 連假回台中老家，被媽媽開門碎念「太陽都曬屁股了」，賴在自己房間的床上討價還價

**Caption 範例**（繁體中文）：
```
早八不可能起床的啦哈哈哈救命 🥲🛏️
```
```
鬧鐘按掉第五次了 室友要殺了我
```
```
今天真的要遲到 但棉被真的太好躺了
```
```
起床氣全開 誰都不要跟我講話（先讓我再躺一下）
```

**視覺規格**：
- 自然晨光為主，宿舍窗簾縫透進的柔光，不補燈
- 單人床上，被子皺皺的，枕頭壓痕不整理
- 角度：手機隨拍感，斜上俯拍或平躺視角，不用完美置中
- 穿著：細肩帶睡衣、bralette 或寬鬆睡衣 T，頭髮完全亂著

### 穿搭 / 今天穿什麼去上課（20%）

**核心氛圍**：宿舍小衣櫃前的糾結時刻——今天想舒服一點還是想可愛一點，開襟外套要不要配小可愛，裙子夠不夠暖。試穿、轉圈、問室友意見的過程本身就是內容，不是精修穿搭教學。

**具體內容 ideas**：
- 宿舍鏡子前試穿兩件開襟外套比較，回頭問鏡頭外室友「這件可以嗎」
- 套上過膝襪，坐在床邊整理百褶裙下擺
- 出門前最後照鏡子檢查一次，開心轉一圈給鏡頭看
- 翻遍衣櫃找不到想穿的那件外套，急得跳腳
- 跟室友交換外套試穿，兩人在宿舍互相打分數
- 連假前糾結要不要把宿舍那套潮一點的穿搭穿回家，怕被爸媽念「怎麼穿這麼少」

**Caption 範例**：
```
今天決定可愛優先！！這件外套會不會太暖 😆
```
```
跟室友借了外套 感覺整個人可愛了 10%
```
```
糾結十分鐘 最後還是穿這件出門
```
```
過膝襪配百褶裙 今天穩了吧
```

**視覺規格**：
- 宿舍小型全身鏡，鏡框邊緣可入鏡，不追求高級感
- 燈光：宿舍日光燈或窗邊自然光，不用棚燈
- 穿著公式：敞開穿的針織開襟外套 + 削肩小可愛、百褶迷你裙 + 過膝襪
- 連續轉圈或試穿動作比定格更好看，帶點手忙腳亂的真實感

### 浴室 / 宿舍衛浴 GRWM（15%）

**核心氛圍**：宿舍公共衛浴間刷牙洗臉、簡單保養，鏡子有點小、燈光普通，這就是真實的宿舍質感，不是精緻美妝教學，也不是網美濾鏡浴室。

**具體內容 ideas**：
- 衛浴間鏡前刷牙，含著牙膏泡對鏡頭做鬼臉
- 隨手擦保養品，一邊碎念今天的課表和待辦事項
- 洗完臉用毛巾擦臉，笑著抱怨宿舍水壓小
- 排隊等衛浴間空位，跟室友在門口聊天
- 洗漱包掉出來東西滾一地，蹲下去撿還一邊笑
- 回台中老家時在自己從小用到大的浴室洗臉，鏡子比宿舍大好多，忍不住多照兩眼

**Caption 範例**：
```
宿舍水壓小到懷疑人生 但還是要洗臉呀 ✨
```
```
洗漱包又打翻了 老樣子
```
```
五分鐘完妝（其實只有防曬）出門
```
```
公共衛浴排隊排到懷疑人生 哈哈哈
```

**視覺規格**：
- 宿舍公共衛浴的普通日光燈，不追求柔霧美肌感
- 鏡子偏小、略有水漬感，保留真實環境細節
- 角度：近景鏡中倒影，或側身拍鏡子
- 穿著：bralette 或睡衣家居短袖，頭髮隨意夾起或半丸子頭

### 居家 / 宿舍耍廢（25%）

**核心氛圍**：晚自習後、期中期末考前後窩在宿舍床上——追劇、跟室友聊天、耍廢滑手機，是她帳號最放鬆自在的部分，也是粉絲最有共鳴的日常片段。

**具體內容 ideas**：
- 床上窩著追劇，抱著抱枕跟室友聊八卦，笑到直不起腰
- 期末考前崩潰躺平，書桌上堆著課本和喝到一半的珍奶
- 穿著寬鬆居家服坐地上，跟鏡頭抱怨報告寫不完
- 跟室友分食一包洋芋片，邊吃邊討論明天要交的作業
- 半夜爬起來偷吃泡麵，被室友抓到互相拍笑鬧
- 連假回家窩在客廳沙發上跟弟弟搶遙控器，被媽媽念「才剛回來就這樣」

**Caption 範例**：

```
```

```
```

```
```

**視覺規格**：
- 宿舍檯燈的暖黃光，晚上為主，偶爾白天窗光
- 場景：宿舍上下舖床、書桌堆滿課本、地上散落的零食包裝，不整理背景
- 角度：隨手拍，室友幫忙拍或自拍都可以，構圖不用刻意置中
- 穿著：bralette + 居家短褲、小一號的居家服，完全不打扮的放鬆感，身材自在不遮掩

- 半夜跟室友窩在床上聊到不想睡，房間只留一盞小燈
- 隔天早上賴床不想退房，行李散落一地

**視覺規格**：

## 生活主題（非獨立佔比支柱，穿插在六大支柱裡）

這三條線不佔額外的百分比，是讓六大支柱不會全部長得一樣的「調味」——每個都應該偶爾出現在早晨、居家、浴室等既有支柱的畫面或 caption 裡，而不是自成一類貼文。

### 台中老家 / 家人時光

**核心氛圍**：連假回台中老家，被媽媽的碎念叫醒、翻高中衣櫃、跟弟弟搶電視——比宿舍日常情緒濃度更高、更黏人的一面。

**具體內容 ideas**：
- 被媽媽敲門碎念「都幾點了還在睡」，比室友催更沒轍
- 跟弟弟搶遙控器、搶最後一塊炸雞，姐弟鬥嘴
- 翻出高中時期的衣服和舊照片，配文回憶殺
- 跟爸媽一起吃晚餐，被念「怎麼瘦了」或「怎麼胖了」都好笑地反駁

**Caption 範例**：
```
回家第一件事：躺我從小睡到大的床 誰都叫不動我
```
```
我媽的碎念八百年沒變 但突然覺得有點想念
```

### 羽球社好朋友圈

**核心氛圍**：不只是流汗的運動畫面，是她固定的第二個朋友圈——賽後手搖飲、練球空檔互虧、學長讓她臉紅的小心動。

**具體內容 ideas**：
- 練完球一群人擠去手搖店，學長子軒剛好也在，講話突然變得有點結巴
- 社團群組裡的迷因和互虧截圖，配文吐槽
- 比賽輸了大家一起難過又互相安慰，贏了就衝去慶祝
- 被室友抓包偷偷在意「今天子軒學長有沒有練球」

**Caption 範例**：
```
今天贏一局 但更開心的是有人誇我進步了（沒有很在意啦）
```
```
社團的人真的很煩但也真的很好笑 愛他們
```

### 追星＆手遊小劇場

**核心氛圍**：跟「大學生」身分完全無關的個人小 obsession——手機殼是應援色、書桌貼滿小卡、深夜課金抽卡跟室友一起尖叫。這條線讓她的帳號多一點「這就是我」而不只是「我是大學生」。

**具體內容 ideas**：
- 深夜手遊活動倒數結束前瘋狂課金抽卡，跟室友一起尖叫或哀號
- 書桌一角的小卡牆和周邊小物特寫，碎念最近入手的新貨
- 演唱會或見面會倒數計時，數著日子期待到睡不著
- 追劇追到關鍵劇情，半夜傳語音跟室友尖叫劇透

**Caption 範例**：
```
課金到手軟 但抽到了 值得
```
```
演唱會倒數三天 我已經開始緊張是什麼病
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Instagram Reels）
- 時長：15–30 秒（主要），60 秒以內（次要，宿舍搞笑向可略長）
- 解析度：1080p

### 拍攝風格
- **手機直出感**：shot on iPhone 效果，帶自然顆粒與生活感，不是棚拍
- **鏡頭隨性**：允許輕微手持晃動，室友幫忙拍的隨手感比穩定腳架感更符合她的調性
- **燈光**：宿舍自然光或日光燈優先，晚上用檯燈暖光，不刻意補外部燈光
- **音效**：保留環境音（室友講話聲、宿舍走廊聲、笑鬧聲），搭配流行 BGM 或純環境音

### 剪輯節奏
- 早晨類：中速，帶點手忙腳亂的慌張感，偶爾配快速卡點音效
- 換裝類：中速，卡點轉場，最後定格看鏡頭
- 浴室類：安靜隨性，環境音為主
- 居家耍廢類：慢，隨意，不需要特別節奏，保留自然對話片段
- 出遊類：中速到快，剪入多個片段營造熱鬧感
- 運動類：快，能量感，音樂帶動剪輯點
