## 各支柱內容細節

### 早晨 / 起床（20%）

**核心氛圍**：台北早上的陽光從窗簾縫漏進來，她還沒完全醒，頭髮亂著，被子拉著，像是剛好被你看見的那一秒。

**具體內容 ideas**：
- 床上翻身，眼睛還瞇著，慢慢坐起來
- 手機螢幕照在臉上，滑了幾秒，嘆氣
- 窗簾拉開，光一下子進來，用手擋了一下
- 早上第一杯水喝完，放回床頭櫃
- 被子拉到胸口，側躺，看向鏡頭

**Caption 範例**（繁體中文）：
```
還要再睡十分鐘
```
```
鬧鐘已經按掉四次了
```
```
台北的早上真的太好躺了
```
```
起不來
```

**視覺規格**：
- 自然晨光，不補燈
- 白色或米色床鋪
- 角度：斜上俯拍或平拍，不要正上方
- 頭髮散著，不整理

---

### 穿搭 / 換衣服（20%）

**核心氛圍**：鏡前換衣服的過程，不是展示，是真的在選，有猶豫，有穿上去不對又脫掉，最後對了就定在那。

**具體內容 ideas**：
- 站在鏡前，穿著平口上衣比了幾款下身，最後選了
- 脫掉外套，只剩細肩帶，轉了個身
- 換了三套，最後穿著黑色短褲和 crop hoodie 出門
- 準備出去：tube top + mini skirt，在門口對著鏡子最後看一眼
- 居家換睡衣：大 T 或睡衣褲，那種不打扮的放鬆

**Caption 範例**：
```
換了四套決定這個
```
```
今天的
```
```
出門前最後看一眼
```
```
在家不打扮
```

**視覺規格**：
- 全身鏡，可以有鏡框的邊緣
- 燈光：家裡燈或浴室燈，不要棚燈
- 連續鏡頭比定格更好看

---

### 浴室 / 洗完澡（15%）

**核心氛圍**：浴室鏡前，剛洗完的樣子。霧氣，濕頭髮，浴巾，皮膚還帶著洗完澡的溫度感。不刻意，就是那個狀態。

**具體內容 ideas**：
- 浴巾裹著，用吹風機吹頭髮，側臉看鏡頭
- 擦臉，浴室鏡上還有水霧
- 保養程序：精華液、乳液，隨意塗，不是教學
- 剛洗完頭，濕髮垂著，直接拍
- 照浴室鏡自拍：浴巾、濕髮、自然素顏

**Caption 範例**：
```
洗完澡最舒服了
```
```
終於洗澡了
```
```
洗完澡要先發一下
```
```
整個人好多了
```

**視覺規格**：
- 浴室燈光（暖白或暖黃均可）
- 鏡中倒影構圖
- 浴巾白色或米色
- 不要過度裁切，保留浴室環境感

---

### 在家 / 窩在沙發（20%）

**核心氛圍**：家裡最放鬆的版本。最少的衣服，最自然的狀態，不打算給任何人看，但剛好記錄了。

**具體內容 ideas**：
- 沙發上窩著，看電視或滑手機，家居短褲 + crop tee
- 趴在床上，臉對著鏡頭，問問你在幹嘛
- 地板上坐著，背靠沙發，隨手拍的角度
- 吃外賣，膝蓋上放著，不優雅，就是這樣吃
- 肚子朝下趴在床上，腳踢著，看書或手機

**Caption 範例**：
```
週末的樣子
```
```
不想動
```
```
今天的任務：什麼都不做
```
```
在家的我 vs 出門的我
```

**視覺規格**：
- 家裡自然光，下午的那種斜角光最好
- 家居感：沙發、地毯、枕頭都可以入鏡
- 不要整理背景，就是住的樣子

---

### 飯店 / 旅行（15%）

**核心氛圍**：飯店的床比家裡的床更白，窗外的景更遠，那種「我現在在某個地方」的感覺。

**具體內容 ideas**：
- 飯店床上的早晨：白色被子，窗外台灣或日本的城市
- 飯店浴室：比一般浴室更有設計感，一樣拍鏡前
- 落地窗前：看著窗外，背光或側光
- 去日本：大阪、東京，飯店 check-in 之後的那個晚上
- 出差感：行李沒收，包包放著，坐在床邊

**Caption 範例**：
```
今晚住這裡
```
```
出去玩的第一晚
```
```
剛到，還沒出去
```
```
飯店的床比家裡的好睡
```

**視覺規格**：
- 飯店床：白色床鋪、床頭燈、窗簾
- 落地窗光線或床頭燈暖光
- 行李、包包可以入鏡增加真實感

---

### 健身 / 運動（10%）

**核心氛圍**：運動完的狀態。汗，貼身運動服，還在喘，有那種身體被用過的感覺。

**具體內容 ideas**：
- 健身房鏡前，運動後，有汗，看鏡頭
- 跑步回來，坐在外面喝水，還在喘
- 瑜伽動作，家裡，早上
- 運動完直接拍，不換衣服，就是這樣
- 運動服試穿：緊身褲 + 運動內衣，看哪件合適

**Caption 範例**：
```
去運動了，很痛
```
```
今天逼自己去的
```
```
出完汗整個人舒服了
```

### TikTok 熱梗舞 / 舞蹈影片（20%）

**核心氛圍**：跟跳 TikTok 熱門歌曲，性感有活力，節拍感強。不是芭蕾，不是表演藝術，就是那種每週都有新熱梗舞的 TikTok IT girl。

**具體內容 ideas**：
- 跟跳當週 TikTok 熱門舞蹈（黑色 crop top + 短褲，簡潔服裝為主）
- 換不同服裝跳同一支舞（比較效果）
- 性感 vibe 的舞蹈配慢歌（反差感）
- 越南鼓、韓文歌、台灣流行曲都可以

**服裝公式**：
- 上衣：black crop top / tube top / sports bra crop
- 下身：high-waist biker shorts / mini skirt / tight shorts
- 洋裝：V 領 mini dress（飄逸感）
- **禁止**：寬鬆衣服、全長褲（遮掉腿部線條）

**生成規則**：
- 使用 `seedance_2_0` + `start_image` + `audio_references`
- Start frame 必須 THREE QUARTER SHOT（mid-thigh up, no shoes）
- 詳細流程見 `DANCE_VIDEO_SOP.md`

**Caption 範例**：
```
這週的熱梗 🎵
```
```
跳起來了
```
```
今天的穿搭跳起來超好看
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–30 秒（主要），60 秒以內（次要）
- 解析度：1080p

### 拍攝風格
- **手機感**：shot on iPhone 效果，有自然顆粒感，不是棚拍
- **鏡頭穩定**：不要晃動，穩定但不是腳架感
- **燈光**：自然光優先，家裡燈光次之，不補外部燈光
- **音效**：環境音保留（冷氣聲、外面的聲音、吹風機聲），搭配 BGM 或純環境音

### 剪輯節奏
- 早晨類：慢，安靜，有呼吸感
- 換裝類：中速，卡點，最後定格
- 浴室類：安靜，只有環境音
- 在家類：隨意，不需要特別節奏
- 運動類：快，能量感，音樂帶動
