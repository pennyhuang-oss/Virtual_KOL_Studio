## 各支柱內容細節

### 早晨 / 起床（20%）

**核心氛圍**：台北早上的陽光從窗簾縫漏進來，她還沒完全醒，頭髮亂著，被子拉著，像是剛好被你看見的那一秒。

**具體內容 ideas**：
- 床上翻身，眼睛還瞇著，慢慢坐起來
- 手機螢幕照在臉上，滑了幾秒，嘆氣
- 窗簾拉開，光一下子進來，用手擋了一下
- 早上第一杯水喝完，放回床頭櫃
- 被子拉到胸口，側躺，看向鏡頭

**Caption 範例**（繁體中文）：
```
還要再睡十分鐘
```
```
鬧鐘已經按掉四次了
```
```
台北的早上真的太好躺了
```
```
起不來
```

**視覺規格**：
- 自然晨光，不補燈
- 白色或米色床鋪
- 角度：斜上俯拍或平拍，不要正上方
- 頭髮散著，不整理

---

### 穿搭 / 換衣服（20%）

**核心氛圍**：鏡前換衣服的過程，不是展示，是真的在選，有猶豫，有穿上去不對又脫掉，最後對了就定在那。

**具體內容 ideas**：
- 站在鏡前，穿著平口上衣比了幾款下身，最後選了
- 脫掉外套，只剩細肩帶，轉了個身
- 換了三套，最後穿著黑色短褲和 crop hoodie 出門
- 準備出去：tube top + mini skirt，在門口對著鏡子最後看一眼
- 居家換睡衣：大 T 或睡衣褲，那種不打扮的放鬆

**Caption 範例**：
```
換了四套決定這個
```
```
今天的
```
```
出門前最後看一眼
```
```
在家不打扮
```

**視覺規格**：
- 全身鏡，可以有鏡框的邊緣
- 燈光：家裡燈或浴室燈，不要棚燈
- 連續鏡頭比定格更好看

---

### 浴室 / 洗完澡（15%）

**核心氛圍**：浴室鏡前，剛洗完的樣子。霧氣，濕頭髮，浴巾，皮膚還帶著洗完澡的溫度感。不刻意，就是那個狀態。

**具體內容 ideas**：
- 浴巾裹著，用吹風機吹頭髮，側臉看鏡頭
- 擦臉，浴室鏡上還有水霧
- 保養程序：精華液、乳液，隨意塗，不是教學
- 剛洗完頭，濕髮垂著，直接拍
- 照浴室鏡自拍：浴巾、濕髮、自然素顏

**Caption 範例**：
```
洗完澡最舒服了
```
```
終於洗澡了
```
```
洗完澡要先發一下
```
```
整個人好多了
```

**視覺規格**：
- 浴室燈光（暖白或暖黃均可）
- 鏡中倒影構圖
- 浴巾白色或米色
- 不要過度裁切，保留浴室環境感

---

### 私下 / 她自己的房間（25%）

**核心氛圍**：收工回到台北的租屋處之後——絲質吊帶、貼身家居服、床邊與鏡子，房間的暖光。她私下依然把自己打理得好看，只是方向從『出門見人』換成『只給自己和特定的人看』。這是她反差的落點，不是鬆懈的落點。

**具體內容 ideas**：
- 剛洗完澡坐在床邊，絲質吊帶，頭髮還在滴水
- 房間只開一盞床頭燈，鏡子裡的自己，手機擋住一半的臉
- 換上今天新買的貼身家居服，站在全身鏡前轉一圈
- 趴在床上，臉朝鏡頭，背後是沒整理的被子
- 深夜，窗外台北的燈，房間裡只有她

**Caption 範例**：
```
只有這裡是我的
```
```
晚安（不是要睡）
```
```
今天沒有要給誰看
```

**視覺規格**：
- 單一光源（床頭燈或窗外的城市光），不要頂燈
- 服裝一定要明確寫出來：絲質、蕾絲、貼身針織的具體款式
- 鏡子與床是主要載體，避免沙發（沙發是公開面貌的場景）

---

### 外出 / 台北的日常（15%）

**核心氛圍**：不在房間裡的台北——大安區的巷子、咖啡廳、朋友的店、買東西、等紅燈。這個支柱存在的目的很單純：讓她有房間以外的地方可以去，避免素材永遠困在同一個空間。她在這裡做什麼、有沒有在上班，都是開放的。

**具體內容 ideas**：
- 大安區巷子裡走路，回頭
- 咖啡廳靠窗的位子，外套掛在椅背
- 便利商店結帳前的等待
- 朋友的店裡試東西
- 等紅燈，風把頭髮吹亂

**Caption 範例**：
```
出來走走
```
```
今天的台北
```
```
順路
```

**視覺規格**：
- 自然光為主，街景要有真的雜訊（招牌、人、車）
- 穿著是得體的公開版本，跟私下支柱要看得出差別

### 飯店 / 旅行（15%）

**核心氛圍**：飯店的床比家裡的床更白，窗外的景更遠，那種「我現在在某個地方」的感覺。

**具體內容 ideas**：
- 飯店床上的早晨：白色被子，窗外台灣或日本的城市
- 飯店浴室：比一般浴室更有設計感，一樣拍鏡前
- 落地窗前：看著窗外，背光或側光
- 去日本：大阪、東京，飯店 check-in 之後的那個晚上
- 出差感：行李沒收，包包放著，坐在床邊

**Caption 範例**：
```
今晚住這裡
```
```
出去玩的第一晚
```
```
剛到，還沒出去
```
```
飯店的床比家裡的好睡
```

**視覺規格**：
- 飯店床：白色床鋪、床頭燈、窗簾
- 落地窗光線或床頭燈暖光
- 行李、包包可以入鏡增加真實感

### 健身 / 運動（10%）

**核心氛圍**：運動完的狀態。汗，貼身運動服，還在喘，有那種身體被用過的感覺。

**具體內容 ideas**：
- 健身房鏡前，運動後，有汗，看鏡頭
- 跑步回來，坐在外面喝水，還在喘
- 瑜伽動作，家裡，早上
- 運動完直接拍，不換衣服，就是這樣
- 運動服試穿：緊身褲 + 運動內衣，看哪件合適

**Caption 範例**：

**核心氛圍**：跟跳 TikTok 熱門歌曲，性感有活力，節拍感強。不是芭蕾，不是表演藝術，就是那種每週都有新熱梗舞的 TikTok IT girl。

**具體內容 ideas**：
- 跟跳當週 TikTok 熱門舞蹈（黑色 crop top + 短褲，簡潔服裝為主）
- 換不同服裝跳同一支舞（比較效果）
- 性感 vibe 的舞蹈配慢歌（反差感）
- 越南鼓、韓文歌、台灣流行曲都可以

- 上衣：black crop top / tube top / sports bra crop

- **少用**：寬鬆衣服、全長褲——跳舞影片多數會選能看清線條的服裝，但不是唯一選項

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–30 秒（主要），60 秒以內（次要）
- 解析度：1080p

### 拍攝風格
- **手機感**：shot on iPhone 效果，有自然顆粒感，不是棚拍
- **鏡頭穩定**：不要晃動，穩定但不是腳架感
- **燈光**：自然光優先，家裡燈光次之，不補外部燈光
- **音效**：環境音保留（冷氣聲、外面的聲音、吹風機聲），搭配 BGM 或純環境音

### 剪輯節奏
- 早晨類：慢，安靜，有呼吸感
- 換裝類：中速，卡點，最後定格
- 浴室類：安靜，只有環境音
- 在家類：隨意，不需要特別節奏
- 運動類：快，能量感，音樂帶動

## 造型差異化：風格光譜與轉盤（2026-08-05 新增）

> **⚠️ 這一節的優先級等同內容支柱本身。** 使用者明確反饋：角色不可以被自己的人設關進一個房間（「做瑜伽的就只穿韻律衣、衝浪的就只穿比基尼、直播主永遠在電腦前」）。
>
> **造型（穿搭／髮型／配件）與地點，是獨立於上方內容支柱的變數。** 決定完「這則屬於哪個支柱」之後，必須再獨立轉四個轉盤。完整系統見 repo 根目錄 `WARDROBE_SYSTEM.md`，該文件基於競品 @sherry_digitalp510 抽樣 60 則貼文／109 張圖片的實測分析。

### 轉盤 2：髮型（每則必須明確指定，不可讓模型自己決定）

長直髮放下／高馬尾／鯊魚夾盤髮／半盤＋緞帶／低雙辮

### 轉盤 3：地點層級（每 10 則的硬性配額）

| 層級 | 配額 | 說明 |
|---|---|---|
| A 級（嚮往感）| 2–3 則 | 一般人做不到的：高級飯店、精品開箱、遊艇、出國旅遊 |
| B 級（有質感的日常）| 4–5 則 | 咖啡廳、餐酒館、有設計感的街區、展覽 |
| **C 級（完全不美的日常）** | **至少 2 則（硬性下限，不可為 0）** | 全聯／Costco 賣場、超商取貨機前、麥當勞、加油站、停在路邊的車裡、路口凸面反光鏡、洗衣店、藥妝店、捷運月台、機場候機室 |

> **C 級是真實感的靈魂。** 競品敢在 57 萬粉帳號發 Costco 推推車、麥當勞得來速、蝦皮取貨機——正是這些一點都不美的地方，讓觀眾相信「她是個剛好很有錢的真人」而不是型錄。我們現行素材 C 級掛零，這是看起來假的重要原因。

### 轉盤 4：微物件（每則至少換 2 樣，prompt 中必須具體點名）

手機殼／包款／鞋款／髮飾／指甲／耳環／手上拿的東西（飲料、食物、購物袋）。

### 服裝 prompt 必須寫滿五層

上身（單品＋材質＋顏色）＋ 下身 ＋ 鞋 ＋ 包或外套 ＋ 首飾髮飾。
只寫 `wearing a casual top and shorts` 這種等級一律退回重寫；`[HAIR]` 要獨立成欄位。
