## 各支柱內容細節

### 下午甦醒（她的「早晨」）（20%）

**核心氛圍**：下午兩點的光線斜斜打進直播間，她剛醒，帽T連著昨晚沒脫，頭髮亂翹，還沒切換成主播模式——這是她一天最沒有防備的狀態。

**具體內容 ideas**：
- 電腦桌前趴著剛醒，帽T連著頭，螢幕還沒開機，手先摸向手機看彈幕留言
- 沙發上滾來滾去不想起床，遊戲鍵盤和昨晚的耳機還在旁邊
- 剛起床往浴室走的路上，經過昨晚沒收的空零食袋和飲料罐
- 半瞇著眼滑手機，看到訂閱通知才勉強清醒一點
- 桌燈還沒關（忘記關了一整個白天），提醒著昨晚肝到多晚
- 難得的休息日賴床滑手機回婷婷的訊息，聊的是甜點店和逛街，完全沒提到昨晚的排位

**Caption 範例**：
```
下午兩點，我的早上
```
```
鬧鐘？沒有這種東西
```
```
起床氣還沒退，先別跟我說話
```
```
彈幕比我起得早，很合理
```

**視覺規格**：
- 光線：下午斜射光透過窗簾縫，混合桌燈餘光，偏冷偏暗，不刻意打亮
- 角度：近距離、平視或略俯，捕捉沒睡醒的臉部細節
- 服裝：帽T連著睡，頭髮亂翹不整理
- 背景：直播桌、未關的螢幕待機畫面、零食空袋自然入鏡

### 穿搭 / 換裝（直播戰袍）（20%）

**核心氛圍**：決定今晚戰袍的過程，不是展示教學，是真的在猶豫——寬鬆帽T還是削肩背心，今晚要不要戴貓耳，鏡子前來回比劃到最後定案才坐回直播椅。

**具體內容 ideas**：
- 全身鏡前試穿今晚戰袍，帽T只到大腿，猶豫要不要換成別件
- 削肩背心配耳機，對著鏡頭比劃「今晚這樣會不會太過」
- 大腿襪 + 貓耳頭飾的 cosplay-lite 造型，開台前最後檢查一次
- 換了三套後回到最順手的那件，順手把耳機戴上準備定裝
- 站在衣櫃前糾結，順口問一句「你們想看哪個」當作今晚的哏
- 難得的白天出門前，翻遍衣櫃找一件「看起來像正常人」的衣服，跟平常的戰袍反差很大

**Caption 範例**：
```
今晚穿這個 chat 應該會暴動
```
```
換到第三套決定不想再換了
```
```
今晚貓耳出場，你們準備好了嗎
```
```
戰袍定了，開台見
```

**視覺規格**：
- 光線：房間 RGB 燈條的漸層色混合桌邊補光，不用自然光
- 角度：全身鏡照或半身近景，鏡框邊緣可入鏡增加真實感
- 服裝：寬鬆電競帽T、削肩背心、cosplay-lite 配件（大腿襪、貓耳頭飾）— 至多到 cosplay-lite，不做全套 cosplay
- 連續換裝過程比單一定格更有效果

### 浴室 / 深夜保養（10%）

**核心氛圍**：開台前的快速保養，或凌晨下播後的卸妝流程。動作快、隨性，這是實用環節，不是精緻的保養儀式。

**具體內容 ideas**：
- 開台前浴室鏡前快速上一層底妝，嘴上唸著「時間快來不及了」
- 凌晨三點下播後卸妝，臉上還帶著剛下播的疲憊感
- 刷牙洗臉的隨手鏡頭，配著「今晚又肝到這麼晚」的字幕
- 保養品隨手抹幾下，不是教學，順口抱怨保養步驟太多懶得做
- 戴上藍光眼鏡前的最後一步，準備進入深夜模式
- 難得白天要出門前的正常保養流程，不趕時間慢慢做，跟平常的匆忙完全不同

**Caption 範例**：
```
開台前五分鐘，緊急保養
```
```
卸完妝才是我真正的臉
```
```
今晚又肝到這麼晚，保養隨便做做
```

**視覺規格**：
- 光線：浴室日光燈的冷白光，偏功能性不刻意營造氛圍
- 角度：鏡前近景，臉部至上半身
- 節奏感：動作偏快、隨性，不追求精緻構圖
- 偶爾入鏡藍光眼鏡，暗示即將進入直播模式

- 遊戲椅上打到一半的反應臉，螢幕光打在臉上，嘴巴在對彈幕碎念

- 貓跳上鍵盤打斷直播，她整個人瞬間融化，語氣完全變軟
- 遊戲送頭瞬間的浮誇崩潰表情，下一秒又開始嘴硬找藉口
- 對著鏡頭直接講話，像在回覆某個彈幕留言，打破第四堵牆的招牌動作

- 沒開台的休息夜，螢幕是黑的，窩在沙發上跟 GG 耍廢，不是表演給誰看的狀態


### 飯店 / 展會旅遊（10%）

**核心氛圍**：極少發生、發生時是大事——電競展攤位、創作者聚會、簽名會。她幾乎不離開新竹，所以飯店內容對她本身就是新鮮事，比平常一週的內容都更有「事件感」。

**具體內容 ideas**：
- 展會前一晚飯店房間，行李和周邊商品攤了一床，還在確認明天的行程
- 創作者聚會後回飯店，還穿著展會戰袍窩在床上滑手機
- 飯店窗邊，難得看到白天的城市景色，一臉「原來太陽長這樣」的表情

- 跟爸媽安排的一趟小旅行，兩天一夜，行李箱裡混著換洗衣物和給爸媽的伴手禮

**Caption 範例**：

### 面基日：跟阿光和朋友的線下聚會

**核心氛圍**：偶爾她會跟阿光和幾個常一起開黑的朋友約出來吃飯、去電玩街機店打實體格鬥電玩、或逛電競展攤位——這是她少數以「本人」而不是「直播畫面裡的她」出現在朋友面前的時刻，能量比獨自直播更外放、更吵鬧。

**具體內容 ideas**：
- 跟阿光和幾個網友第一次面基，發現「本人比想像中更吵」

- 跟阿光面對面吵架式鬥嘴，比在麥克風裡聽起來更誇張

**Caption 範例**：
```

```

## 影片格式規範 Video Format Notes

### 基本規格
- Twitch / YouTube Live 直播片段：16:9，原始直播畫面比例
- TikTok / Instagram Reels 剪輯：9:16，15–30 秒為主，可到 60 秒
- 解析度：1080p / 720p，保留直播畫面本身的顆粒與噪點感，不過度銳化

### 拍攝風格
- **直播畫面感優先**：素材看起來就像直播截取片段，不是額外拍的精修內容
- **RGB / 螢幕光不修掉**：燈光的過曝、色偏、螢幕反光都保留，是她視覺語言的一部分
- **字幕即語言**：clip 字幕、梗圖文字是內容本體，不是後製裝飾，彈幕截圖可直接疊加畫面
- **鏡頭幾乎不移動**：固定機位（桌上鏡頭 / 攝影機），互動感靠她對鏡頭講話和表情變化製造，不靠運鏡

### 剪輯節奏
- 下午甦醒類：慢，安靜，帶點沒睡醒的呆滯感
- 換裝類：中速，卡點在「今晚戰袍定案」的那一瞬間
- 保養類：快、隨性，不追求精緻運鏡
- 居家 / 直播間類：節奏隨遊戲進程走，反應臉瞬間用快剪放大，其餘保留原始直播步調
- 展會旅遊類：稍慢，帶一點難得的「事件感」鋪陳
- 伸展類：短、隨手，不需要特別剪輯節奏

> **⚠️ 這一節的優先級等同內容支柱本身。** 使用者明確反饋：角色不可以被自己的人設關進一個房間（「做瑜伽的就只穿韻律衣、衝浪的就只穿比基尼、直播主永遠在電腦前」）。

### 轉盤 3：地點層級（每 10 則的硬性配額）

| 層級 | 配額 | 說明 |
|---|---|---|
| A 級（嚮往感）| 2–3 則 | 一般人做不到的：高級飯店、精品開箱、遊艇、出國旅遊 |
| B 級（有質感的日常）| 4–5 則 | 咖啡廳、餐酒館、有設計感的街區、展覽 |
| **C 級（完全不美的日常）** | **至少 2 則（硬性下限，不可為 0）** | 全聯／Costco 賣場、超商取貨機前、麥當勞、加油站、停在路邊的車裡、路口凸面反光鏡、洗衣店、藥妝店、捷運月台、機場候機室 |
