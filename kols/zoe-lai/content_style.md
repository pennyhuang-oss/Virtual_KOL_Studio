# Zoe Lai 賴柔伊 — Content Style Guide

> 方向：東岸衝浪女孩日常 — 陽光、健康體態、不刻意的性感。SFW，強調生活真實感而非表演。

> **⚠️ 2026-07-25 燈光校準備註**：本文件各支柱「視覺規格」裡提到的自然光（晨光、正午強光、黃金時段）都應理解成明亮、清晰、有淺景深的「討喜自然光」，不是刻意調暗、調糊、做舊的畫質。晨間衝浪支柱裡「允許天還沒全亮的低光感」指的是天色本身還沒亮的物理狀態，畫面仍要維持清晰銳利、不刻意加顆粒/降畫質——實際送出生成的 prompt 字串已依此在 `generation_notes.md` 校準，詳見該文件「2026-07-25 燈光/身材數字校準」note。

## 各支柱內容細節

### 晨間衝浪 / Dawn Patrol（20%）

**核心氛圍**：花蓮天還沒亮，天色從深藍轉紫再轉金，除了浪聲什麼都沒有。她一天中最不設防、最不表演的時刻。

**具體內容 ideas**：
- 天還沒亮，走路去海邊，板夾在腋下，路燈昏黃、腳踩過的沙帶著露水
- 沙灘上蹲坐打蠟，動作專注，晨光在她背後慢慢亮起來
- 划水出海，回頭看岸邊的視角，海水拍打手臂
- 站板起乘的瞬間，逆光剪影，水花被晨光照亮
- 划完浪回岸上，板插在沙裡，背影看著剛升起的太陽
- 浪況太平淡，跟阿翔坐在防坡堤上喝手沖咖啡等浪起，板子擱在腳邊沒下水

**Caption 範例**：
```
浪不錯
```
```
起得早，值得
```
```
今天第一道光
```
```
划出去就對了
```

**視覺規格**：
- 只用晨間自然光，不補燈，允許天還沒全亮的低光感
- 划水/起乘用中距離或 3/4 身，打蠟等準備動作可以近一點
- 服裝：比基尼或連身泳衣，視季節加防寒衣，頭髮綁起或鬆散的辮子
- 皮膚帶著海水的濕氣，不上妝

---

### 泳裝穿搭 / Swimwear as Daily Wear（20%）

**核心氛圍**：選今天穿哪件比基尼，外面隨手套一件寬大襯衫，就這樣出門——不是換裝儀式，是她大多數時候的實際穿著狀態。

**具體內容 ideas**：
- 站在小房間鏡子前，比基尼外披一件男友襯衫，隨手扣兩顆扣子
- 光腳踩過木地板到沙地的轉場瞬間，門口回頭看一眼
- 沙灘上，比基尼加牛仔短褲，走向水邊，很自然的行走姿態
- 抽屜或衣架上一排比基尼，隨手抽一件出來
- 曬衣繩上曬乾的泳衣被風吹著晃動，換衣服前的畫面
- 騎車去爸媽的雜貨店買東西，比基尼外套一件寬T，順路跟顧店的媽媽聊兩句

**Caption 範例**：
```
今天穿這件
```
```
洗衣繩上都是這些
```
```
出門就這樣
```
```
衣櫃一半是比基尼
```

**視覺規格**：
- 明亮直射日光，室內到戶外的自然轉場
- 全身鏡或門口的中距離鏡頭，連續動作比定格更好看
- 服裝：比基尼 + 寬大男裝襯衫或素T，牛仔短褲，光腳
- 曬痕、膚色深淺不修飾，這是真實感的來源

---

### 沖鹽淨身 / Rinse & Salt Off（15%）

**核心氛圍**：衝完浪後在戶外沖水柱沖掉鹽分和沙子，擦防曬，頭髮還是濕的。務實、不浪漫化、完全自在的狀態。

**具體內容 ideas**：
- 戶外沙灘沖澡柱下，沖掉身上的鹽和沙，頭往後仰
- 沖完澡後補防曬乳，坐在板子旁邊，動作隨意
- 濕髮甩水，陽光下水珠四濺的瞬間
- 沖完後光腳走回車上或民宿，濕腳印留在木地板或沙地上
- 沖完澡坐著整理板具和裝備，身上還在滴水
- 沖完澡跟剛下課的小樂坐在岸邊喝水，順手講評她今天抓浪的時機

**Caption 範例**：
```
鹽都沖掉了
```
```
沖完舒服多了
```
```
防曬補一下
```
```
濕著也沒差
```

**視覺規格**：
- 正午高對比日光或黃金時段光線，水珠在陽光下要清楚可見
- 中近景為主，捕捉水花和濕髮的細節
- 服裝：比基尼，濕身，道具是防曬乳瓶罐、沖澡柱、板具
- 不刻意擺拍，像是恰好被看見的日常動作

---

### 東岸小屋 / Home & Van Life（15%）

**核心氛圍**：花蓮簡單公寓，或衝浪季睡的小貨車——吊床、板架、家具很少，室內時間本來就不多。家是放裝備跟睡覺的地方，不是拿來展示生活風格的舞台。

**具體內容 ideas**：
- 公寓陽台的吊床上躺著，板子靠牆立著，風吹進來
- 小貨車後座，睡袋和裝備堆在一角，車門開著看外面的海
- 簡單廚房煮東西，濕泳衣曬在窗邊晾乾
- 板架前整理板具，動作俐落不拖泥帶水
- 窗邊坐著喝水，看著外面天氣決定要不要出門
- 陽台上澆水整理她種的多肉和幾盆香草，完全跟衝浪無關的畫面
- 弟弟阿哲來家裡吃飯，兩人坐地上配電視，板子在旁邊當背景但沒人在意它

**Caption 範例**：
```
今天沒下水，在家躺著
```
```
車上也能睡
```
```
天氣不好，在家晾板
```
```
家裡沒什麼，夠用就好
```

**視覺規格**：
- 自然窗光或車內透進來的光，不做室內佈景感
- 中景到全身，環境要看得出「儲物+睡覺」的簡樸感，不精緻
- 服裝：寬鬆T恤或簡單居家服，光腳
- 道具：板架、吊床、睡袋，家具越少越對

### 衝浪旅行 / Surf Trips & Coastal Stays（15%，重點）

**核心氛圍**：沿海岸線跟著季節移動——墾丁待一陣子、路邊民宿、板子綁在車頂、找新的浪點。她最主要的旅遊內容，永遠是關於浪，不是關於打卡景點。這是她內容中最常被放大處理的支柱。

**具體內容 ideas**：
- 車頂綁著好幾支板，沿海公路開車，車窗開著，風吹頭髮
- 墾丁海邊民宿陽台，板子晾在欄杆上，海景在後面
- 到新的浪點，蹲在岸邊看浪況，評估要不要下水
- 剛到民宿，行李還沒收，先走去看海
- 衝完浪後路邊小吃攤覓食，board 還放在車邊
- 傍晚跟東岸移動社群的朋友們在海灘生火，分享今天的浪況跟簡單晚餐，不是每張都在講浪

**Caption 範例**：
```
墾丁待幾天
```
```
新浪點，還在看
```
```
路上，板子都綁好了
```
```
這裡浪型不錯
```

**視覺規格**：
- 明亮的旅行日光，公路/海岸線用寬景建立場景感，民宿陽台用中景
- 服裝：泳裝或簡單洋裝＋牛仔短褲，板具、車頂架、民宿陽台都可入鏡
- 整體感覺樸素、在路上，不是精品旅遊的精緻感

---

### 划水健身 / Paddle Fitness & Beach Yoga（15%）

**核心氛圍**：衝浪本身就是她的健身——划水、鴨式下潛、站板。加上沙灘上的瑜伽伸展。沒有健身房，沒有器材，只有海跟她的身體。

**具體內容 ideas**：
- 趴板划水的側面鏡頭，肩背線條清楚，動作連貫有節奏感
- 沙灘上做瑜伽伸展，日落金色光線，動作專注不看鏡頭
- 衝完浪坐在板上休息，喘氣，看著海面發呆
- 扛板走過沙灘，全身動態，肌肉線條自然呈現
- 鴨式下潛的瞬間，水花四濺，動作有力
- 淺水區教小樂划水的基本動作，示範怎麼抓時機，笑她老是慢半拍

**Caption 範例**：
```
划到手痠，值得
```
```
今天練了鴨式下潛
```
```
伸展一下，收操
```
```
划水比健身房實在
```

**視覺規格**：
- 強烈自然光：划水動作用正午高對比光，瑜伽伸展用黃金時段柔光
- 划水/衝浪動作用中距離捕捉連貫動作，瑜伽伸展可以全身或半身
- 服裝：比基尼或運動泳裝，濕身，肌肉線條自然呈現，不刻意健身房式打光
- 完全戶外，沒有器材、沒有鏡子牆

## 額外生活主題 Additional Life Themes

這三個主題不佔獨立的支柱百分比，是穿插在六大支柱裡的內容——尤其常出現在東岸小屋、划水健身、沖鹽淨身的畫面中，目的是讓帳號有六大支柱之外的呼吸空間。

### 教衝浪 / Teaching Beginners

**核心氛圍**：她兼職教衝浪，固定學生是小樂——一個每個月從台北飛來上兩次課的初學者，抓浪時機永遠慢半拍。這是她帳號裡少見需要說話、示範、等別人的內容，energy 跟她自己一個人衝浪完全不同，更有耐心，更多笑場。

**具體內容 ideas**：
- 淺水區示範划水基本動作，小樂在旁邊笨拙模仿
- 岸上喝水討論剛剛的動作，順手比劃時機點
- 小樂終於站起來的瞬間，Zoe 在旁邊笑到拍手
- 課後兩人並肩坐在板上，喘氣，聊些無關緊要的話

**Caption 範例**：
```
她今天又慢半拍
```
```
教到笑出來
```
```
進步了，一點點
```

**視覺規格**：跟晨間衝浪同樣的自然光邏輯，但鏡頭要有「兩個人」的互動感，不是她一個人的獨白式構圖。

### 花蓮家人時光 / Family Time in Hualien

**核心氛圍**：回爸媽的雜貨店幫忙顧店、跟弟弟阿哲鬥嘴、留下來吃一頓家常飯——帳號裡步調最慢的部分，跟海完全無關，是她另一半的生活。

**具體內容 ideas**：
- 顧店，坐在店門口的板凳上，跟媽媽有一搭沒一搭聊天
- 跟阿哲坐地上配電視吃飯，板子在旁邊當背景但沒人在意它
- 幫忙包貨、整理店裡的破布子罐頭
- 飯桌上一家人吃飯的畫面，不特別擺拍

**Caption 範例**：
```
回家吃飯
```
```
顧店中，浪的事明天再說
```
```
阿哲又輸我
```

**視覺規格**：室內自然光或店面日光燈也可以出現（這是唯一允許非自然光的場景），構圖生活感重於美感，不刻意好看。

### 陽台植栽 / Balcony Plants

**核心氛圍**：公寓陽台養的幾盆多肉和香草，澆水、換盆、偶爾曬死一株再重種。安靜、慢、家常，跟她其他強動作感內容形成對比。

**具體內容 ideas**：
- 澆水，蹲在陽台盆栽前，動作專注
- 換盆，手上沾土，隨手擦在短褲上
- 曬死的一株拔掉重種，不當一回事
- 陽台的植栽跟曬著的泳衣、板子並排，構成她生活的縮影

**Caption 範例**：
```
這盆又活了
```
```
澆水，跟浪無關的十分鐘
```
```
種死一株，再買一株
```

**視覺規格**：柔和的窗邊或陽台自然光，近景為主，節奏比其他支柱都慢，允許完全靜態的畫面。

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / IG Reels 及 Stories）
- 時長：15–30 秒為主，衝浪旅行類可到 60 秒
- 解析度：1080p

### 拍攝風格
- **手機 / 運動相機感**：像 iPhone 或 GoPro 直出，自然顆粒感，不是棚拍精緻感
- **鏡頭**：划水、划船類允許輕微自然晃動（貼合 POV 真實感），日常換裝、沖澡類鏡頭要穩定
- **燈光**：完全依賴自然光——晨光、正午高對比、黃金時段，絕不用室內棚燈
- **音效**：保留環境音為主（海浪聲、風聲、水聲），晨間衝浪類不加配樂，旅行類可加輕量 BGM

### 剪輯節奏
- 晨間衝浪類：慢起漸快，安靜，幾乎只有海浪聲
- 泳裝穿搭類：中速，卡點在出門/轉身瞬間
- 沖鹽淨身類：安靜，環境音為主，沒有旁白
- 東岸小屋類：隨意慢步調，不需要特別節奏
- 衝浪旅行類：中速到快，公路移動感和目的地抵達感要出來
- 划水健身類：快，動作連貫，能量感強，划水的節奏就是剪輯的節奏
