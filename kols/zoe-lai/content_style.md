# Zoe Lai 賴柔伊 — Content Style Guide

> 方向：東岸女孩日常 — 陽光、健康體態、不刻意的性感。SFW，強調生活真實感而非表演。

> **⚠️ 2026-07-25 燈光校準備註**：本文件各支柱「視覺規格」裡提到的自然光（晨光、正午強光、黃金時段）都應理解成明亮、清晰、有淺景深的「討喜自然光」，不是刻意調暗、調糊、做舊的畫質。晨間衝浪支柱裡「允許天還沒全亮的低光感」指的是天色本身還沒亮的物理狀態，畫面仍要維持清晰銳利、不刻意加顆粒/降畫質——實際送出生成的 prompt 字串已依此在 `generation_notes.md` 校準，詳見該文件「2026-07-25 燈光/身材數字校準」note。

> **⚠️ 2026-08-05 重大修訂：從「衝浪女孩」改為「東岸女孩，衝浪是她生活的一部分，不是全部」**
>
> **背景**：原本 6 個支柱全部圍繞衝浪/海邊展開（晨間衝浪、泳裝日常、沖鹽淨身、東岸小屋、衝浪旅行、划水健身），導致實際生成時每一批次都預設走向海邊/衝浪場景，完全沒有日常生活的畫面。使用者明確反饋：**不要讓所有素材都往衝浪方向走，她可以更日常一點**。
>
> `character.md` 其實本來就設計了「花蓮家人時光」「陽台植栽」「小鎮辦事」這些跟衝浪無關的日常元素（見服裝公式表的「小鎮辦事」「家庭聚餐」兩列），但這次修訂之前它們只是內容方向章節末尾的補充段落，**沒有被排進正式的內容支柱權重**，實際生成批次自然就不會用到。這次修訂把它們正式提升為獨立支柱，並大幅調降純衝浪內容的比重。她仍然是「花蓮出身、會衝浪、認同東岸生活方式」的女生，這個背景不變——只是衝浪不再是她每一則貼文的主題。

## 每週發文節奏 Weekly Posting Rhythm

### Instagram（主力，每週 4–5 篇 + 每日限時動態）

| 天 | 支柱 | 內容形式 |
|----|------|----------|
| 週一 | 日常穿搭出門 | 騎車辦事、市場、超商，一般日常穿著 |
| 週二 | 居家生活 | 在家煮飯、耍廢、澆花草 |
| 週三 | 花蓮家人時光 / 朋友社交 輪替 | 顧店、跟阿哲鬥嘴，或跟阿翔小樂互動 |
| 週五 | 海邊日常（含衝浪）| 有時是真的下水，有時只是去看海 |
| 週末 | 彈性發文 | 浪好就是海邊內容，浪差就是居家或辦事的日常——**不是每週都要有衝浪** |

> 註：Zoe 的節奏不是死板排程，但**衝浪只是她生活的一部分**，這也是這次修訂的重點——她的帳號不該讓人覺得她每天都在衝浪。上表是慣常節奏，實際發文順序可依當週天氣調整。

### TikTok（每週 3–4 支）

| 天 | 支柱 | 內容形式 |
|----|------|----------|
| 週一 | 日常穿搭出門 | 騎車、市場、辦事片段，15 秒內，無配樂旁白 |
| 週三 | 居家生活 / 花蓮家人時光 輪替 | 在家或雜貨店的日記感片段 |
| 週五 | 海邊日常 / 朋友社交 輪替 | 有衝浪就拍衝浪，沒有就是海邊閒晃或跟朋友互動 |
| 彈性加碼 | 大浪天或特殊行程 | 浪況特別好時才額外加開一支衝浪內容 |

### Stories（每日）

- 大多是海況、天氣的隨手記錄，文字極少
- 沒圖時純文字：「今天浪型不對」「補防曬中」
- 語氣：像講今天天氣一樣平淡，不是「跟大家分享」的口吻

## 各支柱內容細節

### 日常穿搭出門 / Errands & Everyday Outfits（20%）

> **⚠️ 2026-08-05 二次修正**：第一版把這個支柱寫成傳統市場提菜籃、破舊機車、五金行雜貨店這種寫實鄉土路線，使用者反饋看起來「太土」。**「不衝浪的日常」不等於「不精緻的日常」**——這條支柱要維持studio 一貫的「漂亮女生的生活記錄」質感，只是把場景從沙灘換成城市/小鎮的咖啡廳、選品店、街拍，不是換成寫實的市井小民紀錄片。

**核心氛圍**：外出辦事、喝咖啡、逛街——她一般日常但依然好看的穿搭，泳裝不是這個支柱的重點。

**具體內容 ideas**：
- 騎車經過有質感的街區，停在一間好看的咖啡廳外
- 手拿外帶咖啡走在乾淨的街道上，穿搭休閒但有造型感（合身T恤、牛仔褲、好看的鞋）
- 在選品店/文具店挑東西，隨手拿起一件小物看
- 巷口買早餐，穿搭乾淨簡約，不是隨便的睡衣感
- 傍晚騎車兜風，經過打了燈的店家招牌

**Caption 範例**：
```
出門辦點事
```
```
這杯咖啡不錯
```
```
騎車吹風最舒服
```

**視覺規格**：
- 明亮直射日光或黃昏光線，場景挑乾淨有質感的街區/店家，不是老舊市場攤販
- 中距離為主，背景可以有生活感細節，但整體要維持「好看」而不是「寫實破舊」
- 服裝：合身簡約日常穿搭（T恤/針織/牛仔），**不是泳裝，也不是刻意隨便的邋遢感**
- 皮膚質感真實（毛孔、非磨皮）但整體畫面依然要好看，不是刻意調醜

### 居家生活 / Home Life（20%）

**核心氛圍**：花蓮公寓裡煮飯、耍廢、澆花草、跟朋友窩著看電視——室內場景，跟衝浪完全無關的畫面，是她生活裡步調最慢的一半。

**具體內容 ideas**：
- 簡單廚房煮東西，窗邊透進自然光
- 澆水整理陽台種的多肉和香草，換盆，手上沾土
- 窗邊坐著喝水發呆，看著外面天氣
- 跟阿翔或小樂窩在沙發上看電視，很日常的閒散
- 曬死的一株植物拔掉重種，不當一回事
- 小貨車後座整理裝備（衝浪季限定），車門開著

**Caption 範例**：
```
在家耍廢
```
```
這盆又活了
```
```
今天哪都沒去
```

**視覺規格**：
- 自然窗光為主，允許室內自然光場景（不是棚拍打燈）
- 中景到近景，環境要看得出簡樸、不精緻的生活感
- 服裝：寬鬆T恤或簡單居家服，光腳
- 家具越少越對，不需要板具當背景道具

### 花蓮家人時光 / Family Time in Hualien（15%）

> **⚠️ 2026-08-05 二次修正**：第一版把雜貨店畫成堆滿醃漬罐頭的老舊柑仔店，使用者反饋太土。改成溫馨但依然好看的家庭場景——家人時光的重點是「溫暖的互動感」，不是刻意營造樸素/老舊的場景美術。

**核心氛圍**：跟爸媽、弟弟阿哲相處的溫暖時刻——帳號裡步調最慢的部分，跟海完全無關，是她生活裡很重要的另一半。

**具體內容 ideas**：
- 在家裡明亮的餐廚空間跟媽媽一起準備晚餐，隨手聊天
- 跟阿哲坐沙發上一起看電視，兩人鬥嘴
- 一家人在餐桌上吃飯的溫馨畫面，燈光柔和
- 陪媽媽在家裡的小花園/陽台整理植栽

**Caption 範例**：
```
回家吃飯
```
```
今晚在家
```
```
阿哲又輸我
```

**視覺規格**：室內自然光或店面日光燈都可以出現，構圖生活感重於美感，不刻意好看。

### 海邊日常（含衝浪）/ Coastal Life incl. Surfing（20%）

**核心氛圍**：她的背景與嗜好，但不再是唯一主題——包含真的下水衝浪，也包含單純去海邊散步、看海、跟朋友坐著聊天，不是每一張海邊畫面都在衝浪。

**具體內容 ideas**：
- 天還沒亮走去海邊，板夾在腋下（衝浪季，非天天）
- 划水出海、站板起乘的瞬間
- 單純走在沙灘上看海、光腳踩水，沒有板子、沒有要衝浪
- 跟阿翔坐在防坡堤上喝咖啡看海況，不下水
- 到新的浪點蹲在岸邊看浪況，評估要不要下水
- 淺水區教小樂划水基本動作，笑她慢半拍

**Caption 範例**：
```
浪不錯
```
```
今天就看看海
```
```
划出去就對了
```

**視覺規格**：
- 晨間或黃金時段自然光，允許天還沒全亮的低光感，但畫面仍要清晰銳利
- 划水/起乘用中距離或 3/4 身；純散步看海可以更悠閒的全身鏡頭
- 服裝：不衝浪時是簡單洋裝或T恤短褲，衝浪時才是泳裝＋防寒衣
- **不是每張海邊照片都要有衝浪板入鏡**

### 沖水沙灘澡 / Rinse & Salt Off（10%）

**核心氛圍**：衝完浪後在戶外沖水柱沖掉鹽分和沙子，擦防曬，頭髮還是濕的。務實、不浪漫化、完全自在的狀態。

**具體內容 ideas**：
- 戶外沙灘沖澡柱下，沖掉身上的鹽和沙
- 沖完澡後補防曬乳，坐在板子旁邊
- 濕髮甩水，陽光下水珠四濺的瞬間
- 沖完後光腳走回車上或民宿，濕腳印留在地上

**Caption 範例**：
```
鹽都沖掉了
```
```
防曬補一下
```

**視覺規格**：正午高對比日光，中近景捕捉水花與濕髮細節，服裝為比基尼濕身，不刻意擺拍。

### 朋友社交 / Friends & Social（15%）

**核心氛圍**：跟阿翔、小樂的互動，防坡堤生火、教衝浪、閒聊——重點是「有另一個人在場」的互動感，不一定在水裡，也不一定跟海有關。

**具體內容 ideas**：
- 淺水區教小樂划水基本動作，小樂在旁邊笨拙模仿
- 岸上喝水討論剛剛的動作，小樂終於站起來時 Zoe 笑到拍手
- 傍晚跟東岸移動社群朋友在海灘生火，分享簡單晚餐
- 跟阿翔在便利商店外聊天、一起去買晚餐
- 跟朋友窩在家裡看電視、聊天，完全跟衝浪無關的社交畫面

**Caption 範例**：
```
她今天又慢半拍
```
```
教到笑出來
```
```
今晚生火
```

**視覺規格**：跟其他支柱同樣的自然光邏輯（室內或戶外皆可），但鏡頭要有「兩個人以上」的互動感，不是她一個人的獨白式構圖。

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / IG Reels 及 Stories）
- 時長：15–30 秒為主，衝浪旅行類可到 60 秒
- 解析度：1080p

### 拍攝風格
- **手機 / 運動相機感**：像 iPhone 或 GoPro 直出，自然顆粒感，不是棚拍精緻感
- **鏡頭**：划水、划船類允許輕微自然晃動（貼合 POV 真實感），日常換裝、沖澡類鏡頭要穩定
- **燈光**：以自然光為主——晨光、正午高對比、黃金時段、室內自然窗光皆可（居家生活/家人時光支柱允許室內自然光或店面日光燈），但絕不用棚拍式打燈
- **音效**：保留環境音為主（海浪聲、風聲、水聲），晨間衝浪類不加配樂，旅行類可加輕量 BGM

### 剪輯節奏
- 晨間衝浪類：慢起漸快，安靜，幾乎只有海浪聲
- 泳裝穿搭類：中速，卡點在出門/轉身瞬間
- 沖鹽淨身類：安靜，環境音為主，沒有旁白
- 東岸小屋類：隨意慢步調，不需要特別節奏
- 衝浪旅行類：中速到快，公路移動感和目的地抵達感要出來
- 划水健身類：快，動作連貫，能量感強，划水的節奏就是剪輯的節奏
