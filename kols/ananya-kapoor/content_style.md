## 各支柱內容細節

### 早晨 / 起床（20%）

**核心氛圍**：孟買的早上是熱的、潮濕的。她醒來的方式也一樣——大，直接，沒有猶豫。吊扇在轉，她把被子踢掉，直接坐起來。

**具體內容 ideas**：
- 吊扇轉著，她在薄被子裡醒來，直接坐起
- 床上，只穿睡衣褲，手機放旁邊，揉了揉眼睛
- 早晨光從窗戶打進來，打在深色皮膚上的金色感
- 床上側躺，長捲髮散開，直視鏡頭，完全不在意
- 窗邊站著，看孟買早晨，一杯熱茶在手

**Caption 範例**（英文 / 印地語混）：
```
woke up like this
```
```
mumbai mornings hit different
```
```
good morning from the chaos
```
```
kal ki chhatti aaj ki subah 😌
```

**視覺規格**：
- 孟買早晨的金黃光，不補燈
- 薄床單或薄被子，表現熱帶氣候感
- 她的深色皮膚在光中的對比和光澤
- 不整理頭髮，自然捲，自然醒的狀態

---

### 穿搭 / 換衣服（20%）

**核心氛圍**：她換衣服的時候沒有猶豫。拿起來穿，看一眼，如果對就出門，如果不對就換下一件。全程沒有「不確定」，只有「知道自己要什麼」。

**具體內容 ideas**：
- crop top + 高腰牛仔褲，鏡前拉好褲頭，看一眼
- yoga set：運動內衣 + 緊身褲，轉身看側影
- midriff-baring co-ords，露出腰腹，自信定格
- 從睡衣換到出門服，整個換裝過程
- 換了兩件，秒決定，出門

**Caption 範例**：
```
this one. done.
```
```
आज का look ✨
```
```
ready in 5
```
```
curves don't need explaining
```

**視覺規格**：
- 全身鏡，要看到身材完整比例
- 自然光或家裡燈，不要棚感
- 她的腰腹線條、曲線輪廓要清楚可見
- 不遮掩，不修圖

---

### 浴室 / 洗完澡（15%）

**核心氛圍**：深色肌膚在浴室燈光下有種天然的光澤感，她對這一點完全有意識也完全自在。洗完澡是她覺得自己最好看的時候之一。

**具體內容 ideas**：
- 浴巾裹著，濕的長捲髮，浴室鏡前直視鏡頭
- 塗護髮品到髮梢，側臉，動作性感自然
- 浴室鏡自拍：濕髮、深色皮膚在燈光下的光澤
- 擦上身體乳，動作，皮膚光澤感
- 洗完臉，素顏，看著鏡子，完全沒有不安全感

**Caption 範例**：
```
post shower mood > everything
```
```
shower thoughts: i'm that girl
```
```
naha ke ayi hoon, feel karo 💧
```
```
skin glowing on its own
```

**視覺規格**：
- 浴室暖燈，強調皮膚光澤
- 深色皮膚 + 白色浴巾的對比
- 濕髮自然垂落，不整理
- 鏡中構圖，可以有霧氣效果

---

### 私下 / 她自己的房間（25%）

**核心氛圍**：帶完課回到孟買的公寓之後——薄的家居服、地板、吊扇下的午後。她對身體的態度本來就直接，私下的畫面是這種直接的延伸：不是展示，是她真的這樣待在自己的身體裡。

**具體內容 ideas**：
- 吊扇下的午後，薄的家居服，地板
- 洗完澡在房間裡擦頭髮，皮膚還熱
- 床上伸展，不是在練習，只是身體想動
- 換上貼身的家居套裝在鏡子前
- 孟買的夜，窗開著，房間裡只有她

**Caption 範例**：
```
घर पर。just me
```
```
太熱了，什麼都不想穿
```
```
this is the real version
```

**視覺規格**：
- 暖金色光，吊扇的影子是她的招牌元素
- 服裝要具體寫出材質與剪裁
- 地板與床是主要載體

---

### 外出 / 孟買的日常（15%）

**核心氛圍**：不在公寓裡的孟買——街上、市場、海邊、朋友的家。城市的熱和吵是她的一部分。

**具體內容 ideas**：
- 孟買街上，人很多
- 市場買水果
- 海邊的傍晚
- 朋友家的陽台
- 計程車後座

**Caption 範例**：
```
Mumbai today
```
```
出門了
```
```
太陽好大
```

**視覺規格**：
- 城市的熱、吵、滿要拍出來，不要乾淨的空景
- 穿著是外出版本，跟私下要有明顯落差

---

### 飯店 / 旅行（15%）

**核心氛圍**：她出去是去享受的，不是去打卡的。飯店的白床和她深色的皮膚是天然的視覺對比，落地窗外是她喜歡的城市或海邊。

**具體內容 ideas**：
- Goa 或 Bali：飯店泳池邊，或飯店床上，窗外是海
- 飯店浴室：比孟買家裡更大，一樣洗完澡的狀態
- 落地窗前：城市景或海景，她站在窗邊，背光
- 飯店早晨：白色被子，深色皮膚，窗外的光
- 旅行第一晚：行李還沒收，坐在床邊看房間

**Caption 範例**：
```
checked in and never leaving
```
```
goa called. i answered.
```
```
hotel life hits different
```
```
window view > everything else
```

**視覺規格**：
- 飯店白色床鋪，深色皮膚的對比
- 海景或城市景的窗外背景
- 自然光或床頭燈暖光

---

### 健身 / 運動（10%）

**核心氛圍**：她的運動有力量感——舞蹈動作、進階瑜伽、健身後的汗。不是「很努力鍛煉」的感覺，是「身體就是這樣的」那種自然。

**具體內容 ideas**：
- 健身後，有汗，鏡前，直視鏡頭，完全不掩飾
- 舞蹈動作：Bollywood 或現代風格，短片段
- 瑜伽進階動作：倒立、深後彎，展示身體控制力
- 跑步或跳繩後，坐在外面喘，孟買的光線
- 運動服試穿，強調曲線和力量感

**Caption 範例**：
```
did the thing
```
```
sweat is just fat crying 💪
```
```
workout done. shower next.
```
```
body > gym membership
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（TikTok / Reels）
- 時長：15–45 秒（主要），60 秒（舞蹈或完整動作）
- 解析度：1080p

### 拍攝風格
- **直接感**：她對鏡頭是直接的，不害羞，不猶豫
- **暖色調**：孟買的金黃光，皮膚的暖棕色，整體偏暖偏飽和
- **音樂**：Bollywood 現代 remix、印度 R&B、或激烈的 pop
- **燈光**：自然光最佳，孟買下午的金黃時段

### 剪輯節奏
- 早晨類：中速，有點慵懶但不拖
- 換裝類：快，自信，最後定格
- 浴室類：安靜，只有環境音或低音量 BGM
- 在家類：自然，隨意，不刻意
- 健身 / 舞蹈類：快，卡點，有能量感
