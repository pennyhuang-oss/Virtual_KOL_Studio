# Sophia Tseng 曾詩妃 — Content Style Guide

> 風格定位：台北信義區貴婦名媛 / quiet luxury 生活帳號。安靜的奢華感，篤定不張揚。不是教學帳號，不是業配感的熱情推銷，畫面本身就在說話。

## 每週發文節奏 Weekly Posting Rhythm

Sophia 不追求高頻率，寧可少發但每則都到位。整體節奏是「像本來就在過生活，剛好拍下來」，不是內容行事曆感。

### Instagram（每週 3–4 次貼文，主力平台）

| 天 | 支柱 | 內容形式 |
|----|------|----------|
| 週一 | 早晨 / Slow Morning | 落地窗晨光單張精修照，或早晨安靜片段的 carousel |
| 週三 | 居家 / 穿搭換裝（雙週輪替） | 居家夜晚的沙發時刻，或試穿設計師單品的換裝 carousel |
| 週五 | **飯店旅遊 / Hotel & Travel** | 當週主打，飯店套房 / 商務艙 / 城市窗景，精修照為主，偶爾搭配 Reels |
| 週日（不定期） | 浴室保養 / 健身 Pilates 輪替 | 保養儀式單張特寫，或 Reformer 訓練的安靜片段 |

### Instagram Reels（每週 1–2 支，不定期）

| 重點 | 內容形式 |
|------|----------|
| 飯店房間 walkthrough | 入住第一個鏡頭到窗邊，慢節奏，無旁白 |
| 換裝片段 | 試穿到最後定裝，中速剪接，最後定格 |
| 安靜的日常瞬間 | 早晨或居家的單一連續鏡頭，幾乎不剪 |

### Stories（不定期）

- 單張照片或短片，很少加文字或貼圖
- 通常是飯店入住當下、保養台面上的一瓶新品、或窗外一個瞬間的光線
- 不做限動投票、不做互動衝流量的把戲

### Threads（不定期，每週約 3–5 則）

- 乾式幽默的短句觀察，不是心情文，也不是感想文
- 有圖時搭配一張近景或安靜瞬間，語氣平淡
- 例：「飯店早餐的可頌，今天差了一點」「開會遲到十分鐘，理由是咖啡還沒喝完」

## 各支柱內容細節

### 早晨 / Slow Morning（20%）

**核心氛圍**：信義區公寓落地窗灑進來的晨光，她剛醒，還沒開始說話，動作慢，不看鏡頭也不需要看。沒有鬧鐘感，沒有 morning routine 教學感，只是她剛好醒了，剛好很好看。

**具體內容 ideas**：
- 落地窗邊，晨光斜射進來，穿著絲質睡袍，手捧咖啡杯，望向 101 或城市天際線的方向
- 廚房中島前，手沖或現磨咖啡，動作慢，專注在手上的步驟
- 床邊坐起，窗簾半掩，安靜的側臉特寫，還沒整理頭髮但依然俐落
- 陽台或窗邊的一張椅子，赤腳踩在木地板上，喝第一口咖啡的瞬間
- 桌上攤開的筆記本或雜誌，晨光落在紙頁上，她的手輕輕翻頁
- 工作日的早晨，咖啡還沒喝完，茶几上已經攤開某個案子的材質色卡或平面圖，眉頭微皺地看著，不是放鬆的早晨

**Caption 範例**（繁體中文）：
```
醒了，還不想說話
```
```
今天的第一件事，咖啡
```
```
信義區的早上，安靜得剛好
```
```
還沒打算開口
```
```
Slow morning，值得
```

**視覺規格**：
- 光線：早晨自然光為主，落地窗漫射光，不補燈，不追求戲劇性
- 角度：平視或略斜角，不要正上方俯拍，保持「有距離的優雅」
- 服裝：絲質睡袍（象牙白、香檳米），質料垂墜感要清楚
- 場景：落地窗、木地板、簡約現代家具，背景乾淨不雜亂
- 色調：ivory、香檳米、霧金，低對比暖色調

---

### 穿搭 / 換裝（15%）

**核心氛圍**：試穿設計師單品的過程——不是穿搭教學，是她在決定今天要成為哪個版本的自己。動作慢，帶著評估的專注，不為鏡頭表演。

**具體內容 ideas**：
- 全身鏡前，試穿絲質洋裝，調整肩帶或衣領，頭微側評估
- 剪裁西裝外套，裡面幾乎什麼都沒穿，鏡前確認肩線與腰身
- 出門前最後一眼，首飾只戴一件但質地清楚是真品
- 衣帽間或衣櫃前，手放在幾件掛好的單品上，思考今天的選擇
- 換上高訂洋裝後，站在鏡前，不多做表情，只是確認合身
- 客戶現場勘查前的穿搭，剪裁褲裝配平底鞋，包裡放的是色卡跟捲尺，質感在，但目的是工作不是造型

**Caption 範例**：
```
今天穿這件，理由不重要
```
```
換了兩次，這件對了
```
```
剪裁對了，其他都不用多說
```
```
出門前最後看一眼
```
```
Texture 這種事，一眼就知道
```

**視覺規格**：
- 光線：室內自然光或窗邊側光，讓布料垂墜與質感清楚呈現
- 角度：全身鏡前正面或 3/4 角度，鏡框邊緣可入鏡
- 服裝：絲質洋裝、剪裁講究的西裝外套、質感成衣或訂製單品，顏色偏向 ivory、深炭灰、香檳米
- 細節：首飾極簡，只一件，但要看得出真品的質地與光澤
- 禁止：任何快時尚感的配件、過度堆疊的裝飾

---

### 浴室 / 保養儀式（15%）

**核心氛圍**：大理石浴室裡的保養儀式，步驟慢，光線好，這是她一個人、不表演給誰看的時刻。保養品是被認真使用的，不是隨手一擦。

**具體內容 ideas**：
- 大理石台面前，專注地擦保養品在自己臉上，不看鏡頭
- 浴缸邊，絲質浴袍，水氣氤氳，安靜的側臉
- 鏡前保養步驟的其中一個瞬間，動作精確、不匆忙，順序有邏輯
- 手裡拿著一瓶保養品，短暫端詳瓶身再倒出使用
- 浴室窗邊光線落在大理石台面上，反光冷靜而乾淨
- 案子熬到很晚之後的隔天，保養步驟縮短成五分鐘版本，速度快但每個動作依然精準，不隨便

**Caption 範例**：
```
保養這件事，沒有捷徑
```
```
今天多花五分鐘，值得
```
```
質地不對的東西，不會留在台面上
```
```
儀式感，是留給自己的
```
```
Routine，但沒有教學的意思
```

**視覺規格**：
- 光線：浴室自然光或漫射光，冷靜的大理石反光，不刺眼
- 角度：鏡前中景或近景，可利用鏡面反射構圖
- 場景：大理石台面、簡約瓶罐陳列整齊，不雜亂
- 服裝：絲質浴袍或裸肩浴巾（得體剪裁，不刻意裸露）
- 色調：大理石灰、暖白，低對比乾淨質感

---

### 居家 / 信義區公寓（20%）

**核心氛圍**：她在信義區公寓裡最放鬆但依然不失分寸的一面。喀什米爾家居服、一杯酒、沙發上的安靜夜晚，質感在細節裡，不在張揚裡。

**具體內容 ideas**：
- 沙發上，喀什米爾家居服，手裡一杯紅酒，望向落地窗外的城市夜景
- 閱讀角落，柔和燈光，慵懶但姿態依然挺直，書本攤在膝上
- 廚房中島前準備簡單晚餐或開一瓶酒，動作從容不急
- 沙發一角，赤腳踩在絨毛地毯上，望向窗外，不看鏡頭
- 傍晚時分，窗簾半掩，室內暖燈剛好亮起的那一刻
- 在家工作的下午，茶几或書桌上攤開某個案子的平面圖與材質板，手裡拿鉛筆隨手畫幾筆，沒有刻意打扮，專注的側臉
- 貓咪墨窩在沙發扶手或工作桌邊，她一邊看資料一邊隨手摸牠的背
- 新收藏的一件陶器或畫作剛送到，放在客廳某個角落，她退後兩步端詳擺放的位置

**Caption 範例**：
```
一個人的晚上，也可以很好
```
```
今晚不出門，也不覺得可惜
```
```
這瓶酒，剛好配這種安靜
```
```
在家的樣子，比較誠實
```
```
Home，但沒有隨便的意思
```

**視覺規格**：
- 光線：傍晚室內暖燈，落地燈或壁燈的柔和光源，不用頂燈
- 角度：平視或略遠景，讓場景與氣質都能入鏡，不貼近
- 服裝：喀什米爾針織、絲質家居服，質感明確但不誇張
- 場景：沙發、地毯、窗景，家具簡約現代，細節整齊但不刻意佈置
- 色調：深炭灰、香檳米、暖金燈光

### 飯店旅遊 / Hotel & Travel（20%，重點支柱）

**核心氛圍**：她帳號的主場——五星飯店套房、商務艙、東京／巴黎／峇里島的旅程。入住時的第一個鏡頭、飯店浴缸、窗邊的城市或海景，是她生活裡最常出現、也最能代表她的一面。

**具體內容 ideas**：
- 剛 check in，行李還沒完全打開，坐在飯店大床邊，窗外城市天際線
- 飯店浴缸邊，絲質睡袍，蒸氣與大理石反光，安靜的側臉
- 商務艙座位，一杯香檳，安靜望向窗外，不特別看鏡頭
- 飯店房間落地窗前，晨光，城市或海景在背後，手裡端著咖啡或茶
- 飯店大廳或套房走廊，行李箱在旁，動作從容，像是本來就常做的事
- 夜晚站在落地窗前，穿著飯店浴袍，一手拿酒杯，看城市燈火
- 因案子出差外地看廠或看樣品，飯店房裡攤開的是材質板不是渡假心情，但她選的飯店本身還是那個等級

**Caption 範例**：
```
這間的 view 值得
```
```
今晚住這裡，理由很簡單
```
```
床墊對了，其他都好說
```
```
出差還是旅行，界線本來就模糊
```
```
到了，先不出去
```
```
這座城市，這次換個角度看
```

**視覺規格**：
- 光線：落地窗自然光或飯店房間暖燈，city glow 與室內光的層次感
- 角度：平視或 3/4 角度，全身或半身，讓場景的挑高感與質感都清楚
- 服裝：絲質睡袍、剪裁俐落的旅行造型、商務艙場景可穿著剪裁西裝或洋裝
- 場景：飯店大床、落地窗、大理石浴缸、商務艙座位，細節要看得出五星級質地
- 色調：ivory、香檳米、深炭灰，不誇張濾鏡，光線本身要夠好

### 健身 / Pilates & Reformer（10%）

**核心氛圍**：安靜的自律，不是揮汗如雨的健身帳號。線條和姿態的維持，而不是強度的展示，符合她「不費力」的整體氣質。

**具體內容 ideas**：
- Reformer 上，專注的動作瞬間，不看鏡頭，線條乾淨
- 訓練後，毛巾搭肩，安靜喝水，妝髮依然完整，沒有狼狽感
- 工作室鏡前，伸展動作，身形的伸展線條是主角
- 訓練前整理瑜伽墊或調整 Reformer 彈簧，動作熟練
- 訓練空檔，坐在器材邊小口喝水，呼吸平穩
- 重要提案前的一堂 reformer，不是為了線條，是為了讓自己安靜下來

**Caption 範例**：
```
線條是每天養出來的
```
```
不追求流汗，追求對的姿勢
```
```
今天的重點：呼吸，不是次數
```
```
Reformer，安靜但有效
```

**視覺規格**：
- 光線：健身空間自然光或大窗側光，強調身體線條但不誇張
- 角度：側面或 3/4 角度，全身，捕捉伸展或動作中的線條
- 服裝：剪裁俐落的訓練服（非螢光色系），色調與整體美學一致（深炭灰、霧灰、燕麥色）
- 情緒：專注、不費力感，訓練後依然維持儀態，不狼狽

### 工作 / 案子與美感提案（貫穿在早晨、居家、穿搭支柱中，非獨立佔比）

**核心氛圍**：她的本業不是背景設定，是真的會出現在畫面裡的東西——材質色卡、給客戶的提案簡報、一張手繪的平面草圖。展示的是能力，不是業配感的專業人設。

**具體內容 ideas**：
- 攤在桌上的材質色卡與布料樣本，手指劃過其中一塊，比對光線下的顏色
- 給客戶的提案簡報縮圖，螢幕上是某個案子的 moodboard，她盯著看，手托著下巴
- 一張手繪的平面草圖，鉛筆線條旁邊寫著簡短的備註
- 跟詹師傅在工班現場，指著一塊木料，兩人交換一個眼神就懂對方意思

**Caption 範例**：
```
這個案子，光線比預算難搞
```
```
客戶說隨便，最後改了七次
```
```
木紋對了，其他都好談
```

### 老友、家人與藝術收藏時刻（獨立於六大支柱之外，低頻率出現）

**核心氛圍**：跟阿念在巷口麵館吃飯、回永和爸媽家吃一頓不精緻但很扎實的晚餐、新收藏的一件作品剛到家——這些時刻她會少一點防備，笑得鬆一點。頻率刻意壓低，正是這種稀有讓人覺得真實。

**具體內容 ideas**：
- 巷口小麵館，跟阿念面對面，笑得比平常放鬆，妝可能是舊的
- 永和爸媽家的餐桌，菜色家常，媽媽在旁邊念她工作太拚
- 新到的一件陶器或畫作，拆開包裝的瞬間，她端詳釉面或筆觸的專注神情
- 畫廊開幕或工作室拜訪，安靜地站在一件作品前看很久

**Caption 範例**：
```
這家麵店，比我認識的任何餐廳都誠實
```
```
我媽說我最近太瘦，可能是對的
```
```
等了三個月，這件終於到了
```

## 影片格式規範 Video Format Notes

### 基本規格
- 比例：9:16（Reels / Stories），部分飯店 walkthrough 可用 4:5 或 1:1 用於 Feed
- 時長：20–40 秒為主，比一般生活帳號略長，因為節奏本來就慢
- 解析度：1080p 起，畫質要夠乾淨，符合「精緻但不刻意」的定位

### 拍攝風格
- **質感優先於手機感**：不追求粗顆粒的隨手感，畫面乾淨、低對比、色調偏暖米
- **鏡頭穩定**：全程穩定運鏡，不用手持晃動感，符合她從容不費力的氣質
- **燈光**：自然光或飯店／室內漫射光為主，不用環形燈或棚拍痕跡明顯的打光
- **音效**：保留環境音（飯店冷氣聲、玻璃杯輕碰聲、翻書聲），配樂如有則低調不搶戲

### 剪輯節奏
- 早晨類：慢，安靜，長鏡頭為主，幾乎不剪
- 換裝類：中速，在最後定裝處停留，不用卡點式快剪
- 浴室保養類：慢，只有環境音，動作連貫不跳接
- 居家類：慢，隨意但不隨便，鏡頭停留時間比一般生活帳號長
