### 私下 / 她自己的房間（25%）

**核心氛圍**：打工結束回到巴黎的小公寓——絲質吊帶、亞麻襯衫只扣一顆、午後或深夜的光。她的性感一直是不自覺的那種，私下只是把音量放大了一點點，而且她自己知道。

**具體內容 ideas**：
- 亞麻襯衫只扣一顆，坐在窗邊
- 深夜廚房，絲質吊帶裙，倒一杯剩下的酒
- 床上，晨光還沒完全進來
- 洗完澡包著浴巾找衣服，找了很久
- 公寓地板上，腳邊是沒收的書

**Caption 範例**：
```
personne ne vient ce soir
```
```
juste moi
```
```
晚一點再說
```

**視覺規格**：
- Haussmann 窗光或單一暖燈，維持她的柔霧調
- 亞麻、絲、白色布料是她的材質語言
- 不要刻意的擺拍構圖

### 外出 / 巴黎的日常（15%）

**核心氛圍**：不在公寓裡的巴黎——市場、麵包店、河邊、朋友的餐桌。她的生活本來就有一半在外面發生。

**具體內容 ideas**：
- 市場買菜
- 樓下麵包店，早上
- 塞納河邊走路
- 朋友的餐桌
- 酒窖裡挑一支酒

**Caption 範例**：
```
le marché
```
```
dehors
```
```
今天的巴黎
```

**視覺規格**：
- 巴黎街景要有真實的雜訊
- 穿著是外出版本：襯衫、風衣、平底鞋

## Caption 規則

- **語言**：法文為主，偶爾英文（帶法式口音感）
- **長度**：1–2 句最理想，有時一個字或一個 emoji 就夠
- **語氣**：陳述，不解釋，不問問題
- **禁止**：推薦語氣、教學語氣、過多 hashtag、感嘆號

**Caption 參考庫**
```
早晨類：  "Encore au lit." / "Flemme." / "Le matin." / "😴"
浴室類：  "Je sors du bain." / "Cheveux mouillés." / "😮‍💨"
居家類：  "Flemme de sortir." / "Dimanche." / "La lumière ce soir."
換衣類：  "Finalement le premier choix." / "J'ai mis une heure."
飯店類：  "Le lit." / "Check in." / "Lyon ce weekend."
運動類：  "J'ai bougé." / "Ça compte."
```

## 影片格式規則

### TikTok / Instagram Reels
- **時長**：15–30 秒
- **格式**：9:16 豎版
- **節奏**：慢，法式慵懶，不用力踩音樂卡點
- **音樂**：French indie / soft lo-fi / 環境聲（咖啡聲、窗外巴黎聲）
- **字幕**：偶爾打一行法文，白色細字，不解釋

### X（Twitter）
- 短影片（10–15 秒）或靜態圖
- 一句法文 caption
- 不需要精緻後製，手機感更真實

## 視覺後製標準

- 色調：米白 + 奶油黃 + 淡灰，暖 faded 感
- Film grain：輕微，增加隨手感
- 不磨皮，保留皮膚質感
- 背景要有「有人住在裡面」的真實感（衣服沒折、書散放）
- 少用：環形燈白光、過度飽和、冷藍色調——不是她的招牌，但不必絕對排除
