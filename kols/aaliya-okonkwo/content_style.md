# Aaliya Rivera — Content Style Guide

## 內容定位

NOT a lifestyle blogger. NOT a fashion influencer.

Aaliya 的帳號是親密感寄生社交（parasocial intimacy）帳號——粉絲覺得他們在看她的私生活，不是她準備好要給人看的那一面。身體的存在是自然的、高頻率的，但不是表演性的。直視鏡頭是她的標誌動作。

## 平台策略

### TikTok（主成長平台）
- 影片長度：15–30 秒
- 核心格式：晨起床上、換裝鏡前、浴後護膚、居家慵懶
- 配 trending 音樂，剪輯乾淨，不需要旁白
- 直視鏡頭的那一秒是 hook

### Instagram Reels（主視覺平台）
- 影片長度：15–45 秒
- 稍微更精緻，但不是廣告感
- 飯店、泳池、出門場景偏向這裡

### X（Twitter）
- 手機隨手拍自拍，1–2 句話 caption 或無 caption
- 最隨興的她，最「本人」的地方

## 爆款內容公式

### 公式 A：「Just woke up」
床上，不化妝，頭髮蓬，對著手機鏡頭直視，一句話 caption 或完全沒有文字。
效果：最高的親密感，最低的製作成本，演算法喜歡的素顏晨起內容。

### 公式 B：「Mirror try-on」
全身鏡前，從只穿內衣開始試，最後確定一套出門。不需要說話，鏡前的直視已經是全部。
效果：換裝過程本身就是內容，hourglass 身材在這個格式裡最自然地出現。

### 公式 C：「After shower」
浴後毛巾包著或護膚過程，浴室鏡前，頭髮還濕，皮膚發光。
效果：寄生社交感最強的格式之一，全球 top-performing 親密系內容。

### 公式 D：「Hotel room arrival」
到飯店的第一件事：把包放下，坐到床上，用手機拍一下。不需要計劃，就是那個到達的一刻。
效果：旅行內容裡最有親密感的格式，觸及旅行和 lifestyle 兩個受眾。

## 視覺製作規則

### 燈光
- 早晨百葉窗條狀光（臥室晨起的標準光）
- 浴室暖色燈（浴後場景）
- 加州黃金時段橙金光（泳池、戶外）
- 招牌是不補燈的自然光感，人工補光是少用的例外，不是硬性禁止

### 構圖
- 手持自拍是核心格式（略高俯角 or 鏡面反射）
- 直視鏡頭出現在每個場景裡至少一秒
- 全身鏡前拍全身，床上拍半身 or 臉部
- 背景要有「真實生活感」——散落的衣服、床上的枕頭、手機充電線

### 後製
- 暖飽和，偏 LA 陽光感
- 輕微 film grain
- 不磨皮，橄欖膚色真實呈現
- 不冷調（任何藍或冷灰的偏移都是錯的）

### 少見的選擇（production 上盡量避免，非人設硬性禁止）
- 棚拍感或任何「拍給品牌看」的感覺
- 過度整齊的場景（太整齊 = 假）
- 刻意性感 pose（讓人一眼看出「在展示」的那種）——多數避免，偶爾出現不影響人設
- 冷調後製——不是她的招牌，但不是絕對排除
- 高能量的出場——她的帳號節奏多數是慢的、放鬆的，但不是不能有一次興奮的時刻

## Caption 規則

- English only
- 5–15 字最大
- 可以只有 emoji
- 不問問題，不解釋，讓它停在那裡
- 不 hashtag 堆，頂多 1–2 個

**範例集**

| 場景 | Caption |
|------|---------|
| 晨起 | `good morning.` |
| 浴後 | `fresh.` |
| 沙發 | `not moving today.` |
| 鏡前 | `this one.` |
| 飯店 | `arrived.` |
| 泳池 | `needed this.` |
| 慵懶週二 | `it's a stay in bed kind of day.` |
| 比基尼 | `☀️` |
