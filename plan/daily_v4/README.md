# daily_v4 —— 每位人設量身定做

## 為什麼廢掉 v3

使用者的問題：

> 「但你定好固定的場景數量和白天夜間以及姿勢還有其他設定，不就又會變成不同人設間都有太類似的場景……
> 為什麼不能做個別人設都是量身定做的規劃」

她是對的。v2 和 v3 的結構是一樣的：**從共用池抽，再加「不准重複」的限制**。
v3 只是把池子變大（姿勢 9→53、場景 44→83），機器沒變。
「39 個不重複的零件」不等於「16 個不同的人」——它們全部來自同一個審美分布，併排看還是同一組攝影師的作品。

## 我漏掉的東西

```
grep -rn "character.md|content_style" plan/daily_v2/*.py plan/daily_v3/*.py
→ 0 筆
```

**每一位人設早就有完整的 Character Bible**（`kols/<pid>/character.md`、`content_style.md`、`profile.json`），
受 `PERSONA_CANON.md`（憲章，六條原則）約束，裡面寫好了：
色盤、氛圍、後製傾向、內容支柱與比重、標誌性場景配額、小習慣、語氣、身分背景。

v2 和 v3 一筆都沒讀，是憑空用 tier／zone 建矩陣。

## 一個要更正的判斷

v3 的核心規則「背景要壓暗、光集中在臉」是我從**20 位人設的總和留存率**推出來的。
但這 20 位的檔案規定了彼此相反的美學，平均值正好抹掉了差異。
拆到個人就不成立：

| 人設 | 亮背景光的留存 |
|---|---|
| rin-ayase | 4/4 |
| nanami-fujiwara | 3/4 |
| nico-tsai | 3/4 |
| cheryl-soh | 3/5 |
| ruoruo-tang | 3/5 |

所以 v4 不設全域打光規則，**光由每位人設自己的「視覺美學」段決定**。

## v4 的做法

每位人設一份獨立 shot list，每一項都有出處：

| 欄位 | 來源 |
|---|---|
| 場域 | 她的身分背景、城市、支柱 |
| 光與後製 | 她的「視覺美學」段（每人不同，不共用） |
| 服裝 | 她的色盤 ＋ 當格的支柱 |
| 動作與道具 | 她的「小習慣」——這是招牌鏡頭的來源 |
| 表情 | 她的「語氣與幽默」 |
| 5 格是什麼 | `profile.json` 的支柱比重 |
| 標誌性場景 | 憲章原則二的配額，不得超額 |
| 路人 | 場域的真實人流（她的店只有 16 席，就只會有一兩位熟客） |

## 場域配額（硬規則）

使用者：「工作場景有點太多了，網美經營社群不會放自己工作那麼多素材，多半還是私下精彩的生活」。

第一版樣本把**支柱**當成**場域**在排：wendy 的 5 格有 3 格在吧檯或店門口（W1 私下擺在吧檯、
W4 穿搭擺在她店門口）＝ 60%，**違反憲章原則二**（高辨識度場景不得成為主支柱、不得超過 25%）。

各人設 canon 的比重本來就支持使用者的判斷：

| | canon 規定 |
|---|---|
| 工作類支柱 | 20–35%（多數 20–25%） |
| 私下類（私下＋浴室／晨間） | 一律 45–50%，是最大支柱 |

所以 5 格的場域配額訂成硬規則：

| 場域 | 格數 | 依據 |
|---|---|---|
| 工作場域 | **最多 1 格（20%）** | 憲章原則二：不得成為主支柱、不得超過 25% |
| 她自己的空間（房間／公寓／浴室） | **3 格（60%）** | canon 私下類合計 45–50%，是最大支柱 |
| 房間以外、且不是工作場所 | **1 格（20%）** | content_style：外出支柱的目的只是讓她有房間以外的地方可以去 |

wendy 修正後：吧檯 ×1（同時用掉標誌性配額）、她的公寓 ×3（臥室／客廳／浴室）、
房間以外 ×1（東海岸老咖啡攤，刻意不在她工作的那條街）。

全域限制只剩一條：**跨人設不得撞場域、撞動作**。不再有共用池。
