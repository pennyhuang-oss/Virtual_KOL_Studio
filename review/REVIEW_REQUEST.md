# 三、兩個剛發生的重要修正

## 3-1 人設的禁令被移除了

Yuna 的人設原本寫「不要大笑、誇張反應」，**這條已經刪掉**。使用者的話：

> 「**不要在人設裡面去寫說他絕對不要怎麼樣。**可以講他大部分的風格是怎麼樣，
> 但不要禁止他做任何事情，因為**你要把他當成一個活生生的人，他有任何反應都是有可能的**。」

**所以她現在可以真的驚訝、可以笑出來、可以被燙到。** 不要用「她的人設是克制」來砍掉情緒。

## 3-2 我寫了一句對韓國菜的事實錯誤，被使用者抓到

原本 v6 寫 Yuna 說「**韓國的雞湯是清的**」。使用者指出：**參雞湯是濁的**（塞糯米、人參下去燉）。

**這比一句台詞寫壞嚴重**：這支片的全部價值建立在「韓國人的真實反應」上，
**一旦韓國觀眾在留言區指出她講錯韓國菜，整支的可信度就沒了。**

已改成比較「裡面放什麼」（參雞湯＝糯米人參／如嬌＝干貝金華火腿），
並把「韓國沒有這個」移到**花膠**（粵菜食材，韓國菜本來就沒有）。

> **規則：只有外國人能講的話，前提是那句話對他的母國是真的。**
> **請你也用這條檢查一遍下面的腳本——有沒有其他關於韓國的敘述是可疑的。**

## 這幾個決定的理由

| 決定 | 為什麼 |
|---|---|
| **0–4 秒完全不說話** | 這個類型靠食物先抓人。掀蓋蒸氣是火鍋最強的一格 |
| **她的聲音在人出現之前先進來** | 製造「誰在講話」的一拍，也讓 4–8 秒的食物特寫不無聊 |
| **比較從「湯的外觀」改成「裡面放什麼」** | 只有她能講，而且查得到、不會被打臉 |
| **把「韓國沒有這個」留給花膠** | 花膠是粵菜／中菜食材，韓國菜裡本來就沒有 |
| **驚喜分三次** | 一次驚喜撐不了 48 秒。**湯（味道）→ 花膠（口感）→ 雞（份量）** 是三個維度 |
| **被燙到那一拍** | 全片唯一「不完美」的地方。**它讓前面那個驚訝變得可信**——太順的反應像演的 |
| **招牌句出現兩次** | 第一次自言自語（沒有要給誰聽，所以可信）；第二次才對鏡頭推薦 |
| **「一定要點這個」** | 比「歡迎來吃」具體。觀眾去了知道要點什麼 |
