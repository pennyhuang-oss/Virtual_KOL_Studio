| 0.30–1.05s | 「好喝。」 | 先下結論；語氣肯定但不興奮 |
| 1.05–1.35s | 停頓 | 嘴自然閉合 |
| 1.35–2.10s | 「這鍋，」 | 「這」捲舌偏輕；指涉桌上與前鏡的湯 |
| 2.10–2.30s | 短停頓 | 像在組織中文，不演成忘詞 |
| 2.30–3.95s | 「要先喝原湯，」 | 四聲稍平、語速略慢，仍須清楚 |
| 3.95–4.15s | 短停頓 | 為結尾留節奏 |
| 4.15–4.75s | 「再涮。」 | 句尾輕微上揚，但不是疑問句 |
| 4.75–5.00s | 無字 | 嘴閉合，留剪接尾 |

- **目標實際語音長度：4.3–4.6 秒**，前後合計保留約 0.4–0.7 秒。這是 authoring target，不可在沒有實測音檔前聲稱已達成。
- **語速**：略慢、短句、韓國人在說中文；不能為塞進五秒而後製加速或 time-stretch。若實測超過 4.7 秒，先縮短停頓，不改快語速。
- **為什麼第一支不使用卡詞**：
  1. 卡詞至少需要韓文詞、停頓、找中文與自我確認，五秒會被塞滿或必須加長成本。
  2. 這是第一次測 voice＋wan2_7＋中文嘴型；同時加入跨語言與表演停頓，失敗後無法判斷是聲音、語言切換還是嘴型。
  3. 韓國腔本身已經提供人設識別；先驗證最小版本。通過後，第二支再把卡詞當新增的一個變因，而不是第一支的必過條件。

## Q3 語音路徑

**判定：選（c）「音檔先行、通過後再資產化」，最終仍應建立（b）Yuna 專屬 voice；不選（a）預設無韓國腔 TTS 作正式成片。**

### 最省流程

1. **先製作這一句 5 秒內的獨立語音檔**：
   - 優先使用有明確授權／同意的韓國腔中文聲音來源，直接錄製或合成這一句；
   - 若平台可從合法聲音來源建立 voice element，先產生短預覽，不先做影片；
   - 不使用三個無關既有 voice，也不把無韓國腔預設音當 Yuna 的最終聲音。
2. **音檔先過人工 gate**：
   - 是韓國人在講中文的可辨識口音，但每個字仍聽得懂；
   - 不是刻意醜化或模仿喜劇口音；
   - 台詞逐字正確、停頓自然、實際長度落在約 4.3–4.6 秒；
   - 「好喝」像結論，「再涮」不是疑問；
   - 用人耳聽，不用 RMS 代替。
3. **聲音通過後才餵 wan2_7**：使用既有合格 start_image＋這一條已鎖定 audio_reference，生成一支五秒同步語音片。
4. **通過後把同一聲音來源升格為 Yuna 專屬 voice 資產**，保存 voice_id／voice_type、授權來源、語音樣本與發音規格，後續內容不用重新選聲線。

### 為什麼不是先用預設 TTS 做技術探針

- 7.5-credit 影片若嘴型同步成功但聲音不符合人設，仍不能交付；之後換聲音還要再跑一次影片，總成本更高。
- 專屬聲音多花的一次性成本買到的是**後續每支片的聲音一致性**，而不是只替本片美化。精確 voice 建立／TTS 單價未出現在本檔，執行前必須先跑 get_cost；不能在這裡虛構數字。
- 若內部已有**自願且授權清楚**的韓國腔中文說話者，可先直接錄這一句，影片前置成本可接近 0 credits，之後再決定是否把同一來源建成 voice element。不得未經同意複製真人聲音。

## Q4 驗收 gate 與停損

### A. 語音檔先行 gate（不過就不花 7.5 credits）

- [ ] 台詞逐字為「好喝。這鍋，要先喝原湯，再涮。」沒有漏字、增字、誤讀或韓中語言亂跳。
- [ ] 人耳可辨識為自然韓國腔中文，咬字仍清楚；不機械、不戲謔、不像三個既有無關 voice。
- [ ] 實測語音長度約 4.3–4.6 秒，完整五秒內有自然起音與閉嘴尾巴。
- [ ] 停頓位置符合 Q2，不出現超過約 0.8 秒的意外空白。
- [ ] 聲量、底噪與爆音可後製使用；不以 RMS 平不平判斷表演好壞。
- [ ] 聲音來源及合成／使用權限可進客戶商業素材。

### B. wan2_7 說話鏡硬 gate

- [ ] **第 0 幀忠實**：Yuna 臉、mock-neck、前臂裁切、白碗、鍋緣、背景食客與光色均和 start_image 連續。
- [ ] **身份穩定**：全程仍是同一個 Yuna；五官比例、年齡感、髮型與妝不漂移，嘴動時不能換臉或下顎熔化。
- [ ] **服裝穩定**：象牙色 mock-neck 維持同一件連續上衣；不降領、不變 choker、不露上胸，針織紋理不游動。
- [ ] **肢體穩定**：雙前臂仍搭桌沿，畫面下緣不能長出手掌／手指；肩膀不聳動，不能新增端碗、比讚或指向食物的手勢。
- [ ] **食物與器皿穩定**：白碗持續平放，少量湯汁、暗鍋緣與桌面不位移、不增料、不冒出筷子／湯匙。
- [ ] **表情符合**：克制、肯定；不甜笑、不驚訝、不閉眼陶醉。自然口型不是表情變臉。
- [ ] **背景穩定**：食客維持背／側對，不轉頭搶鏡；木屏、牆板與燈籠不變形、不新增偽文字或人物。
- [ ] **機位與光線穩定**：locked-off，無推拉搖移；暖主光、中性桌面回填、暗鍋區與燈籠高光不閃爍。
- [ ] **只有說話主運動**：不額外點頭、搖頭、轉身、抬碗或做手勢。一次自然眨眼可接受但不要求。

### C. 嘴型同步的可驗收標準

- **必須以人耳＋正常速度觀看判定，不能用 RMS。** 至少看兩次：一次只看自然度，一次對照文字與停頓。
- 音訊開始後，嘴部可見運動的起始差不得明顯超過約 **0.20–0.25 秒**；音訊結束後，嘴部不得繼續像說話超過約 **0.25 秒**。
- 「好喝。」後的停頓中，嘴應回到自然閉合／休止；不能音訊已停但嘴仍連續講話。
- 「這鍋」與「要先喝原湯」的口部節奏須跟著可聽音節推進；不能連續約 **0.30 秒以上**有清楚語音但嘴完全凍住，或無語音卻持續快速動嘴。
- 最後「再涮」結束時，嘴應在約 0.25 秒內回到首幀附近的閉合狀態。
- 不要求逐音素像真人配音棚一樣精準；**正常速度第一次看就明顯感到聲畫分家**即硬 FAIL。若只有逐格才看得到的小偏差，而正常速度自然，判 PASS。
- 因成片只需約前三秒露出 Yuna，最低可交付門檻是：從第一個可聽字開始，至少有**連續 2.5–3.0 秒**嘴型自然同步，能完整看到「好喝。這鍋，要先喝原湯」的大部分；後段可切去鏡 2，由同一錄音繼續。這是預先設計的剪輯，不是失敗後偷改標準。

### D. 跑幾支與停損

- **預設只跑 1 支 wan2_7，7.5 credits。**
- 若一支中有 2.5–3.0 秒連續合格說話窗，身份／服裝／肢體全過，即可按新骨架剪輯，不為追求完整五秒口型重跑。
- 若只在後半嘴型失準，提早於自然停頓切去鏡 2；聲音延續。若聲音本身已通過，這不需要任何新增生成成本。
- 若從第一句就嘴型明顯錯位，或前 2.5 秒內換臉、改衣、長手，先停止，不自動跑第二支。提交實際結果給使用者判斷；只有她確認「再花 7.5 credits 買一次完整同步的機會」值得，才跑第二支。
- 第二支必須固定 start_image 與已通過 audio，只允許縮短／簡化影像動作 prompt；不能同時換聲音、台詞、首幀。
- 若兩支重複出現同類硬失敗，停止 wan2_7，不轉用每五秒 27.5 credits 的 flux_3_video 抽卡。替代方案是保留 Yuna 的真實語音起頭，以靜態 Yuna 畫面短暫建立說話者後立即切產品 B-roll；但若完全看不到任何可靠嘴型，這只能算「Yuna 聲音主導版」，不得假稱完整同步說話片。

## Q5 鮨佐樂

**判定：概念上要改，補回 Luna 自己說「いただきます」與雙手合十；但不要和 Yuna 同時花錢生成。先以 Yuna 驗證語音路線，再決定 Luna。**

  - **Yuna**：直視觀眾，親口下結論與教吃法，負責來客轉換。

## 補充（我漏掉的問題）

- **競品「不靠口播」與本案「KOL 必須自己說」並不衝突**：本方案沒有用一段口播解釋情境。前 2.2 秒仍由濃湯動作抓人，Yuna 只說一個五秒內的結論／吃法，產品鏡再承接她的聲音。畫面承載情境，人物承擔 claim。
- **字幕不是解釋性字卡**：說話鏡應有逐字字幕，服務靜音觀看與韓國腔辨識；不能再加第二層「這是韓國女生的保養法」等解說文字。字幕稿必須與最終音檔逐字相同。
- **先鎖音檔，再鎖字幕，再生影片**：語音 wording 或停頓一旦通過就凍結。後續若嘴型失敗，不回頭順手改 caption、字幕或產品鏡，避免再次失去歸因。
- **聲音權利是新資產 gate**：保存來源同意、可商用範圍、是否允許建立 voice element、voice_id／voice_type 與版本。虛擬人不代表可以任意借用真人聲線。
- **舊鏡 3 的 10 credits 不應影響新決策**：它已作廢就是 sunk cost。保留它作為「無語意點頭」反例，不因已花錢把它塞回成片，也不為彌補損失而降低新說話鏡驗收。
