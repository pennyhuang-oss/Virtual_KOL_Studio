# 發現：Soul V2 用 5 張訓練，學到的不只是臉，是那 5 張的整個調性

**日期**：2026-09-09
**起因**：使用者看 A/B 結果時說 zoey 那組「人也不怎麼漂亮，動作也很奇怪」，而同一段 prompt 的 rin 很好。
**成本**：0 credits（只是把已存在的訓練圖排出來看）

---

## 一、同一段 prompt，兩個結果

zoey-yeh D1 與 rin-ayase D1 的 prompt 結構完全相同：同樣的 15 個區塊、同樣的美貌段、
同樣「主光從正面落在臉上」、同樣的貼身時髦上衣、同樣的 C 級不美地點、同樣的自拍視角。

出來的結果：**rin 是網美，zoey 是素顏文青。**

## 二、原因在訓練圖，不在 prompt

| | rin-ayase 的 5 張訓練圖 | zoey-yeh 的 5 張訓練圖 |
|---|---|---|
| 服裝 | 緞面睡袍、黑色細肩帶洋裝、貼身洋裝、高跟鞋 | 亞麻長褲、工作圍裙、及膝裙、平底鞋 |
| 妝 | 有妝，紅唇 | 素顏 |
| 髮 | 亮面、有造型 | 收起、無造型 |
| 道具 | 梳妝台上的化妝刷具、行李箱、鞋櫃 | 花桶、剪刀、麻繩、水管 |
| 場景 | 都會飯店／公寓，夜景落地窗 | 鄉村老屋，雨天，灰綠色調 |
| 調性 | **網美** | **文青職人** |

**Soul 學到的是這整個調性，不只是臉的幾何。** 所以 prompt 寫「Camera-ready natural makeup」，
rin 的 Soul 照做（她的訓練圖本來就有妝），zoey 的 Soul 抵抗（她的訓練圖全是素顏）。
這解釋了為什麼美貌段在 rin 身上是「更精緻」，在 zoey 身上只是「稍微不那麼素」。

## 三、全 25 位都有同樣的結構：每一位的 5 張都集中在單一調性

| 人設 | 訓練圖調性 |
|---|---|
| rin-ayase | 網美／都會夜 |
| wanyin-jiang | 旗袍精緻／江南 |
| zhiyi-shen | 上班套裝／上海職場 |
| wendy-yeo | 都會冷調／黑白襯衫、酒吧 |
| yerin-han | 高爾夫運動 |
| **zoey-yeh** | **文青職人（全體最素的一組）** |

**這不是 bug，是當初 5 張訓練圖的設計必然帶來的結果**——每位角色的訓練集都是照她的人設寫的，
所以人設的調性就被烘進 Soul 裡。好處是角色辨識度高，代價是**跨調性的內容會被 Soul 拉回原調性**。

附帶注意：25 位的第 3 張全部是「浴袍＋毛巾擦臉」，這是訓練集模板的痕跡，不是各自的設計。

---

## 四、這對日常素材規劃的意義

v2 的 prompt 結構是對的（美貌段有效、R1 的視角修法有效），但**它假設 20 位都能被推到同一個網美調性，
這個假設不成立**。實際上每位能推到的範圍受她自己 5 張訓練圖的限制。

三個處理方向，由使用者決策：

| | 做法 | 成本 | 代價 |
|---|---|---|---|
| **A** | 用網美調性的訓練圖重訓調性偏素的人設 | 每位 25 credits ＋ 訓練圖製作 | 花錢；且會削弱角色差異化 |
| **B** | 接受各人設的原生調性，內容寫在各自的線上，不用同一套網美標準評所有人 | 0 | 有些人設就不會是網美路線 |
| **C** | 先修 prompt 端我自己的錯（表情與姿勢詞庫），再判斷還剩多少是 Soul 的問題 | 0 | 無 |

**建議順序 C → 再決定 A 或 B。** C 是免費的，而且做完才分得清「Soul 的限制」與「我寫壞的詞庫」。

---

## 五、C 的內容：詞庫裡確實有寫壞的條目

zoey D1 拿到的兩條，兩條都不好：

- 表情 `Her expression is confident and still, only a trace of a smile, her eyes holding the lens.`
  → 出來是**面無表情**。rin 拿到的 `a warm open smile, the outer corners of her eyes creasing` 就好很多。
- 姿勢 `her free hand just touching her hair at the temple`
  → 出來**手肘外翻、手懸在半空沒真的碰到**，很僵。

這兩條是我寫的，不是 Soul 的問題。詞庫裡讀起來冷或僵的條目要換掉，而不是留著輪到誰算誰倒楣。
