對照規格：**85/138 與規格不符**，而且方向幾乎一致地**往膝上收斂**：

| 規格 → 實際 | 張數 |

| waist_up → knee | 17 |
| chest_up → waist | 8 |
| chest_up → knee | 6 |
| waist_up → full | 3 |
| three_quarter → full | 1 |

### 這推翻了我先前的假設

我原本判斷「`waist_up`／`three_quarter` 會塌成全身，所以事後裁切（全身→腰上）可以 0 credits 解決」。
**量測結果是反的**：塌陷的方向是**全身→膝上**。裁切只能往更緊的方向做，
所以裁切可以補「腰上」「胸上」，**但補不出全身**。

- 最終 100 張需要 40 張全身，實際只有 **34 張**真正把腳收進畫面 → **缺 6 張**。
- 全身格命中率 34/78 ≈ **44%**。
