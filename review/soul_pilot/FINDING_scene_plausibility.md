## 我做錯的地方（結構性的，不是措辭問題）

### 錯誤一：`people` 是我逐格手動掛的旗標，跟 `location` 沒有任何關聯

`background_ok` 共 **62/100 格**。其中：

- **30 格在「有座位的室內店家」**（咖啡廳、酒吧、茶館、餐館、kopitiam、hawker centre）。
  這種場所的人是**坐著**的，我的 prompt 卻寫「一兩位背對走離」——這個描述本身就不成立。
- **12 格在鄉間／庭院／水邊／海邊**等僻靜場景（田間小路、農舍之間、古典園林、
  茶館庭院、運河步道、寺廟庭院、海灘木棧道）。這些地方本來就不該有人流。

正確的做法是：**`people` 應該是 `location` 的屬性，而不是一個獨立旗標。**
鬧區／夜市／商店街／車站／觀光景點 → 有路人合理；
田地／庭院／私密露臺／室內店家 → 不該有走動的路人。

### 錯誤二：路人的穿著從頭到尾沒有寫

100 格的 §9 條款只有這句：`clearly different from her in build, age and clothing`。
**0/100 格說明路人在那個場景該穿什麼。**

所以模型自由發揮 →「田間小路出現穿西裝的路人」。
這正是你在 `F202`（zoey-yeh D5）看到的那個人。

### 錯誤三：穿著是依「露出程度」分層指派的，location 完全沒有參與

`outfit` 的指派依據是 `tier`（A/B/C 露出等級）與 `zone`（風格帶）：

| tier / zone | 格數 |
|---|---|
| C / 貼身極簡 | 20 |
| B / 都會上班 | 15 |
| C / 運動休閒＋精品包 | 14 |
| A / 夜間 glam | 12 |
| B / 洋裝 | 11 |
| B / 針織慵懶 | 10 |
| C+B / 日系學院 | 9 |

**0/100 格把穿著綁到場景。** 所以會出現：
田間小路 ＋ 度假風薄紗長洋裝（zoey-yeh D5）、
魚市場清晨 ＋ 露腰 bandeau（somi-oh D1）、
濕貨市場 ＋ 細肩帶短版上衣（ruoruo-tang D1）、
寺廟庭院 ＋ 馬甲式短洋裝（emma-kao D5）。

`F202` 那一張是三個錯誤同時發生：僻靜場景掛了路人 ＋ 路人穿西裝 ＋ 度假洋裝下田。

## 我猜不中「場景好不好看」——這一項我不自己決定

我試著把 100 格的場景分成「不好看（功能性／髒濕／工作後場）」「僻靜卻有路人」
「穿著不合場景」，再對照你的選片結果：

| 我的分類 | 你的留存率 |
|---|---|
| （我沒標問題的） | 34/74 = 45.9% |
| 場景不好看 | 17/35 = 48.6% |
| 僻靜卻有路人 | 8/19 = 42.1% |
| 僻靜卻有路人 ＋ 穿著不合 | 2/5 = 40.0% |

**四組留存率都在 42–49%，我的分類完全沒有解釋力。**
也就是說我對「場景好不好看」的判準跟你的不一樣，我猜不中。

所以審美這一項不由我決定：我把 100 格的場景／穿著／路人列成一頁給你標，
你裁決，我只負責把你的決定實作成規則。
