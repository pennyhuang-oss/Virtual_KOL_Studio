- **T-01｜重度修圖來源：不批准作結構 donor。** 「漂亮」可以是輸出目標，但不能拿已被演算法改形的部位當結構依據，否則 pilot 測到的是濾鏡形變，不是可追溯的部件相容性。ref_06｜眼與眉 明確命中這條，排除；ref_14｜鼻、ref_03｜口 既已有「骨相不可信」的逐張警告，也一併不進 pilot。指定優先替代為 ref_01｜眼與眉、ref_15｜鼻、ref_02｜口：三格均為已寫出兩個簽名的 usable-B，因此不增加未知額度。這三個是替代候選，不是免檢通行證；仍須先各寫一條與 cheryl-soh 人設的相容理由。若其中任何一格不相容，就從未被修圖改形的 A／usable-B 集合重選，不得退回 provisional-B，也不得為守住原解而沿用上述三張問題來源。

- **T-02｜pilot 臉型：改成 ref_02。** ref_08 與「長卵形／長窄／窄顎＋長鈍頦」在主軸上相反，不能保留。ref_02 的長卵形、高額、中庭長、窄而俐落顎線與人設同向；本輪不選條件式的 ref_07。改後必須維持 cheryl-soh 0 未知，並同步更新 donor sheet、manifest、檔名／順序與相容理由。

- **T-03｜其餘 18 位：選 (a)，逐格補相容理由再重排。** 目前 76 格只證明約束可解，尚未證明美感配對成立；「只修明顯相反」沒有可稽核的邊界，而先跑 pilot 會把來源污染與人設錯配混進 calibration 結果。每格至少記錄：人設主軸、donor 可見特徵、同向／可接受的理由，以及來源完整性；不相容或來源部位被修圖改形就重排。完成後重新驗證跨槽上限、每位未知上限、calibration wave 條件與 pilot 0 未知。在這項檢查完成前仍維持 0 credits，不把 pilot 包交使用者。
