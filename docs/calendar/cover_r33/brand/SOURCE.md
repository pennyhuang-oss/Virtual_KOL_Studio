# 直式封面 Logo 來源紀錄（M-5 R33）

## 指定款
Owner（Penny）在 R32 頁面回饋指定：直式深色封面要用「藍色圓底、白色圖示與白色 Insight Software 字樣」那款完整 Logo，不能用 R32 自行改白的透明底長條 Logo，也不能替官網長條 Logo 加一個藍圓冒充。

## 實際使用的檔案
- `insight-software-logo-circle.png`：**Penny 在 R33 進行中直接提供的原檔**（2026-11-03，訊息原文「這個logo也給你做參考」），原樣保存。
  - sha256：`859e51e7ddf0e9a4c7cccc0a725d5e5ae9a134c15110b0fcdbdbdc8056665416`
  - 800×800 PNG（RGBA）；圓＝整張（圓外透明）；藍色 #2B33F2（與官網 Logo 圖示同色）；白色圖示＋兩行白字「Insight Software」。
- 用法：原樣等比放進封面（直徑 22 mm，約 924 ppi），不重畫、不改色、不加圓、不拉伸。PDF 內以無損方式嵌入（含透明遮罩）。

## 核對
- 和官方 YouTube、Facebook 頭像（同一款排法：白底、藍色圖示＋黑字）逐像素比對：圖示與字樣重疊率約 98%（差異只在邊緣反鋸齒），是同一個正式排法的藍底反白版。
- 和官網長條 Logo `logo01.svg`（`../../cover_r32/brand/`）比例不同：圓形款的圖示與兩行字距另有排法。所以不能用長條 Logo 加藍圓代替。
