# CAL_16 — 主推薦圖的本機局部清理（TASK-CAL-001／R3）

> 對應主管 R3 §4：以本機、不花 credits 的工具清理會印出的主推薦圖；不修臉、不美顏、不改身形；修後重查手、肢體交界、衣服、反射與背景接縫；工具做不到就列未完成。
> 規格（人寫）：`data/cal_r3_cleanup.json`；結果：`data/cal_r3_cleanup_report.json`；程式：`tools/build_cal_r3_cleanup.py`、主角遮罩 `tools/cal_seg.py`。
> **原圖一律不動**；清理後的完整圖存在本機快取（不進 repo），樣張實際用哪一版由 sha256 對應（`CAL_14b` 的「使用檔」欄）。

## 1. 工具與保護

| 項目 | 內容 |
|---|---|
| 工具 | 逐欄上下內插（字戳）；OpenCV `seamlessClone`（Poisson 梯度域無縫複製，用同一張圖別處的同材質紋理）；排除主角像素的高斯模糊與減光（路人、招牌、人像牆）。全部是傳統影像處理，**沒有生成、沒有外擴、沒有 AI 增強、沒有花 credits** |
| 主角保護 | mediapipe selfie_multiclass 分類模型（只用來決定「哪些像素不准動」）→ 主角遮罩外擴 11–15 px 並羽化；遮罩內像素在程式最後一律回寫原值 |
| 核對 | 6 張清理圖：主角的臉、皮膚、頭髮、配件像素與原圖**逐一相同（最大差 0）**。唯一放行：Rainie 字戳左端壓在馬甲上，該處 402 個**衣服**像素被修補 |
| 標誌用語 | 移除 Hello Kitty 等可辨識角色是**成品清理選擇**，不是法律定論；Vicky 運動內衣上的小圖形標「**未辨識**」，保留，不斷言是否為品牌 |

- 修後重查是 Claude 在螢幕上以 100% 與縮圖目視，**不是**印刷打樣檢查。
