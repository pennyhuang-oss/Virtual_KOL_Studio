## 2. 量測方法

| 項目 | 定義 |
|---|---|
| 原生像素 | 裁切後的原圖像素（`crop_px` 的 w×h）；清理版與原圖尺寸相同 |
| **有效 ppi** | 原生像素 ÷ 照片框英吋（寬、高各算一次；兩者一致）。**不是** 300 dpi 輸出像素，也不是放大後像素。「渲染時放大」只表示輸出時像素被拉大 |
| 裁切位置 | 先讓臉中心落在框高的固定比例，再盡量讓髮頂進框並離開線圈區，最後確保下巴在框內；仍超出原圖的就照實記錄。同一張圖在不同框的裁切本來就不同，表上各自列出，不強求一致 |
| 臉 | mediapipe 478 個特徵點全部在裁切內＝臉完整；特徵點最上緣 ≥ 12 mm＝臉避開線圈區 |
| 髮頂 | 程式：selfie_multiclass 模型的「頭髮」類別在主角身上的最上緣。分四種：原圖已缺髮頂（頭髮碰到原圖上緣）／髮頂被照片框裁掉／髮頂在線圈區內（臉不受影響）／髮頂完整。**另有人工目視欄**，程式估計不當作人工確認 |
