# 如嬌｜腳本 v3 提案「湯太好喝，她忘記涮了」

> **這一版是 Claude 自己寫的，不是覆核給的。**
> 起因：Penny 判定 v2「皮膚科那句完全不知道什麼意思」「腳本看起來也蠻無聊」，
> 並要求「把自己當作一個很有經驗的宣傳企劃者」。

---

## 一、先誠實回答她的問題

> 「你覺得這個腳本會有趣嗎？對宣傳餐廳會有效果嗎？」

**不會，也不會有效果。以下是理由，用行銷的話講。**

### 1. 皮膚科那句是「辯解」，不是「賣點」

> 「我媽媽在皮膚科，所以『喝湯會變漂亮』這句，我不敢亂講。」

**這句話在回答一個沒有人問過的問題。** 觀眾從頭到尾沒聽她說喝湯會變漂亮，
她卻先自清一次——這在廣告裡叫**免責聲明偽裝成台詞**。
Penny 說得更直接：「客戶也沒有要求他說喝這碗湯會變漂亮，他自己突然講這句話。」

**而且它是負面資訊**：一支 34 秒的推廣片，花了 7 秒在說「有一件事我不敢講」。
餐廳付錢買的是理由，不是保留。

### 2. 五顆鏡頭裡有三顆是她對鏡頭講話

**「一個人對鏡頭說這家店很好」是美食內容裡最弱的形式。**
我們自己的競品分析（30 支 Reels）結論是「**情境 > 美貌**」，
前 4 名沒有一支是口播——第 1 名是她在 Uber 後座睡著、第 2 名是路人一直回頭。

v2 把「事件」寫成一場**論述**：制止 → 自清 → 舉證 → 結論。
**那是提案簡報的結構，不是短影音的結構。**

### 3. 她從頭到尾沒有吃到東西

碗靠近嘴就切掉、花膠被湯勺提起來但沒有人吃。
**一支美食影片裡沒有人真的享受到食物。**
而 `CAMPAIGN_PLAN` Tier 1 排第一的型態就是「**第一口反應片**」，
標記★（最好做）、「**最高頻、最好做、成效最穩**」——我們一直在繞開它。

### 4. 沒有人會想把它傳給朋友

火鍋是揪團生意。**這支片沒有任何一個「哈哈這就是我朋友」的瞬間。**

---

## 二、我的提案：把簽名動作變成一個笑點，而不是一堂課

**「先喝原湯，再涮」是規劃書定的品牌資產。**
v2 把它演成教學（她教你怎麼吃），**我要把它演成一個被抓包的畫面**：

> **她一碗接一碗喝湯，桌上要涮的料一口都沒動。**

這句話同時做完三件事：
1. **它是對湯最高的稱讚**——好到讓人忘記火鍋還有別的東西可以吃
2. **它是一個情境，不是一個宣稱**——沒有任何功效、沒有任何形容詞
3. **它可以被傳**——「我朋友就是這樣」

**而且它技術上最安全**：笑點靠**疊起來的空碗**（靜態道具，首幀就決定），
不需要吞嚥、不需要入口、不需要咀嚼。

### 片名／標題
> **「叫她先別涮，結果湯被她喝完了。」**

## 三、腳本（24 秒、4 刀）

| 秒 | 畫面 | 聲音 |
|---|---|---|
| **0–3** | **【爆點先行】** 金色湯勺舀起奶白偏金的濃湯，湯**濃到掛在勺上緩緩落回鍋裡**。畫面只有湯，沒有人。 | Yuna 的聲音先進畫面（人未出現）：**「等一下——先不要涮。」** 倒湯聲 |
| **3–9** | Yuna 正面，手在畫面外。**她面前已經疊了三個空碗**，旁邊那盤要涮的料**原封不動、擺得整整齊齊**。她一臉理所當然。 | **「這個湯，我先喝一碗就好。」**（韓國腔，語速略慢） |
| **9–15** | **【產品證據】** 整隻玉米雞在金黃湯裡，蒸氣細細地飄。湯勺**慢慢提起一塊花膠**，膠質微微顫動。 | 畫外音：**「玉米雞、干貝、金華火腿，熬近兩天，最後才加花膠。」** 湯滾聲放大 |
| **15–21** | 回到 Yuna，**鏡頭比第二顆稍微寬一點——空碗變成四個**。她看著鏡頭，停一拍，表情是被自己抓到。 | **「이거 진짜 좋아。」**（停 0.5 秒）**「……啊，我忘記涮了。」** |
| **21–24** | 客戶真實店景（櫻花樹＋吧台）＋三店資訊 | 餐廳底聲；字卡「如嬌 花膠雞・鍋物／台北民權｜台北仁愛｜台中」 |

### 為什麼這樣排

| 決定 | 理由 |
|---|---|
| **前 3 秒沒有人** | 火鍋店的爆點是湯的濃度。**先讓產品自己講**，人第 3 秒才進來 |
| **她的聲音先於她的臉** | 「等一下——先不要涮」在畫面上還看不到人的時候響起，製造「誰在講話」的一拍 |
| **空碗從 3 個變 4 個** | 這是全片唯一的「劇情」。**觀眾在第 15 秒自己發現多了一個碗**，笑點是自己抓到的，不是被告知的 |
| **料原封不動** | 沉默的笑點。不需要任何台詞解釋 |
| **收尾不是結論，是承認** | 「我忘記涮了」比「這個真的好」更像真人。而且**它把品牌句 `이거 진짜 좋아` 保留在前面**，不浪費 |
| **不提皮膚、不提膠原蛋白、不提美容** | 完全避開功效宣稱。這支片的說服力來自「她喝到忘記涮」，不來自任何療效 |

### 技術上為什麼可行

| 風險 | 這個腳本怎麼處理 |
|---|---|
| 視線離開鏡頭（全專案 8/8 失敗） | **全部直視鏡頭**，一次都不用 |
| 吞嚥／入口／咀嚼 | **完全不需要**。笑點是空碗，不是喝的動作 |
| 手部近景 | **手全部在畫面外**（沿用已驗證的下緣裁切寫法） |
| 一鏡多動作 | 每顆一個主運動：①湯落回鍋 ②說話 ③湯勺提花膠 ④說話 |
| 空碗數量要對 | **空碗是首幀就決定的靜態道具**，不靠模型生成動作。第 4 顆首幀比第 2 顆多一個碗、鏡位稍寬 |

**唯一的新技術題**：第 2、4 顆首幀要穩定生出「桌上有 N 個空碗＋一盤沒動的料」。
這是 `soul_2` 的構圖題，不是影片題，**每張 0.12，可以多生幾張挑**。

## 四、備選版本（如果你覺得笑點太輕）

**「三間店，她只認得出一間的湯」** —— 盲測型。
她閉眼喝三種湯（客戶有三種湯頭的俯拍照），只有花膠雞那碗讓她停住。
**優點**：更強的「產品比較」說服力。
**缺點**：需要三碗、需要閉眼（我們沒測過閉眼），而且盲測的公信力會被「她是虛擬人」削弱。

**我推薦主版本。**
