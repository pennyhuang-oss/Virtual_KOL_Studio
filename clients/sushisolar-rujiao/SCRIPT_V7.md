## 一、R28 挑出的四個問題

1. **外國人反應片的主角到第 8 秒才出現。** 前 4 秒無聲無人無字，觀眾會先把它當成一般火鍋廣告
2. **24–28 秒把已被否決的「好喝到忘記」笑點帶回來**（「忘記燙」是 v3「忘記涮」的近親）
3. **三次驚喜不等於三次升級**——雞胸被壓散只是產品展示，情緒沒有再往上
4. **三句事實／語意要修**：「韓國沒有花膠」太絕對、「干貝、火腿」像整鍋只有兩樣、「熬兩天」會被讀成這隻雞熬兩天

## 三、v6 → v7 改了什麼

| 段 | 改動 | R28 的理由 |
|---|---|---|
| **開場** | 🔴 **新增 0–0.9 秒的「와……」預告** | 「**反應先行、答案延後**」。第一秒就交代這是外國人反應片，不會被誤認成餐廳廣告。而且**這顆不用多生成，是同一顆反應鏡的重剪** |
| 掀蓋 | **刪掉**，改低幅推近 | 客戶沒有掀蓋照；蒸氣爆開容易把食物遮成白霧 |
| 4–8 台詞 | 「你看這個湯」→「**你看它流下來的速度**」 | 更像她真的被濃度抓住，不像主持人 cue 畫面 |
| 8–14 台詞 | 三個短句 → **兩句**，並改「**常放**」「**湯底還有**」「**金華火腿**」 | 六秒講三句像在背比較表；「常放」避免把參雞湯講死 |
| 14–18＋18–24 | **合併成一段** | 倒湯→喝→反應是**一個完整因果**，不需要當兩章 |
| 碗 | 「滿到接近碗緣」→ **七分滿** | 接近碗緣不像豐盛，像快灑出來 |
| 吹氣 | **刪掉** | 手、嘴、液體同時增加風險，改成很輕的吸氣 |
| **24–28 被燙到** | 🔴 **整段刪除** | 見下方「我自己的檢討」 |
| 花膠 | 「韓國沒有這個」「Q 的」→ **韓中卡詞** | 全稱命題會翻車；卡詞把她的天性用起來 |
| 整雞 | 刪「肉一壓就散」，台詞改成「**湯底熬了快兩天，鍋裡還有一整隻玉米雞**」 | 原句會被讀成這隻雞熬兩天；「一壓就散」也可能被理解成煮過頭 |
| 收尾 | 「來的話」→「**第一次來，就點這鍋**」 | 給清楚的使用情境，把觀眾從觀看推到點餐 |
| 指鍋 | **刪掉** | 直視鏡頭講完就夠，方向由剪接完成 |

## 四、🔴 我自己的檢討：「被燙到」那一拍是我加的，而它是錯的

我在 v6 加了「摀嘴、吐舌、太好喝所以忘記它很燙」，理由寫的是「**全片唯一不完美的地方，讓驚訝變得可信**」。

**R28 判定整段刪除，不要修**，理由三條，每一條我都同意：

1. 「太好喝了，我忘記它很燙」是 **v3「太好喝所以忘記涮」的近親**——
   **Penny 已經否決過這個機制一次，我換了個包裝又把它放回來**
2. 它**沒有新增任何餐廳賣點**，只是在重複「很好喝」
3. 摀嘴、吐舌、笑三個動作連在一起，**反而不像自然反應，像要求演員表演可愛**

> **我把「安排一個可愛的小事故」誤當成「真實感」。**
> 真實感不是安排出來的不完美，**是她真的在找一個中文詞**——那個卡詞才是真的。

刪掉的四秒 R28 建議**移給花膠的卡詞**，我照做了。

## 五、🔴 定稿前要客戶確認的 4 件事

| # | 要確認什麼 | 為什麼非確認不可 |
|---|---|---|
| 1 | **花膠的實際口感**是 Q 彈、軟糯、滑嫩還是厚實？ | 台詞「QQ 的？」直接掛在這上面。**花膠依泡發與烹調方式口感差很多，不能只看照片寫** |
| 2 | **湯真的濃到「流下來的速度比水慢」嗎？** | 4–8 秒的台詞在替畫面作證。**如果素材看不出來，就退回原句「你看這個湯」**，不能用台詞替產品加戲 |
| 3 | **熬煮製程的正式說法**（是湯底熬近兩天？整雞另煮？） | 「湯底熬了快兩天」要跟客戶的官方說法一致 |
| 4 | **玉米雞的份量、雞種名稱、供應方式** | 「鍋裡還有一整隻玉米雞」是產品事實宣稱，要客戶背書 |

**在 1 與 3 確認之前，這支不能定稿送生成。**

> 「**不要把『藏資訊』誤認成留言機制。**真正能讓人主動問的，
