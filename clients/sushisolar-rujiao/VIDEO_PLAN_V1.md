# 餐廳推廣影片｜第一支（每人各一支）

> 2026-08-31 建立。狀態：**規劃中，等 Penny 決定規格後才生成。**
> 依據：`CAMPAIGN_PLAN.md` 第三節敘事線／第四節 Tier 1／第七節 POC 風險、
> `DAILY_VIDEO_SOP.md` 的四步驟流程、`reference/SPACE_NOTES.md` 的空間理解。

## 一、成本：影片跟圖完全不是同一個量級

`get_cost` 預檢（`kling3_0`、9:16、sound on）：

| 長度 | credits |
|---|---|
| 5 秒 | **10** |
| 10 秒 | **20** |

**2 credits／秒，線性。** 對照圖片是 **0.12 credits／張**——
**一個 5 秒鏡頭 ≈ 83 張圖。**

> ⚠️ **「生成兩張選一張」這條規則不能原封不動搬到影片上。**
> 圖是 0.24 credits 看兩個結果，影片是 20 credits 看兩個結果。
> 影片要靠**先把 start frame 挑好**來降低失敗率，而不是靠多生幾支。

`cost-log.md` 原本把 `kling3_0` 記成「待測」，這筆數字要補進去。

## 二、技術路線（照 `DAILY_VIDEO_SOP.md`）

```
soul_2 + soul_id 生 start frame（0.12/張，可以多生幾張挑）
  → media_import_url 取得 media_id
  → kling3_0 + medias[start_image] 生 10 秒單鏡頭
```

**每一個鏡頭都要一張自己的 start frame。**所以「三鏡影片」＝ 3 張 start frame ＋ 3 支 kling。

| 參數 | 值 | 理由 |
|---|---|---|
| `model` | `kling3_0` | start_image 鎖臉，單鏡頭 |
| `medias role` | `start_image` | 鎖定身分 |
| `sound` | `on` | **只帶環境音，不生成語音** |
| `multi_shots` | 不設定 | 絕對不用多鏡頭 |

### 語音怎麼辦

**中文口播不做**——`CAMPAIGN_PLAN` 風險 #4（中文 lip-sync）從來沒測過，
沒過就不該用在客戶素材上。

**這一支走字卡＋環境音。**兩人的招牌句都用**母語一句話**，
後製配音（kling 的 `sound:on` 不生成語音），母語短句就算嘴型不完美也自然。

## 三、剪接規格（`DAILY_VIDEO_SOP.md` 的實測數據）

> 競品 30 支 Reels：**前 8 名平均切 3 刀、單鏡頭 5.79 秒、觀看 78 萬；
> 後 8 名切 5.9 刀、單鏡頭 3.84 秒、觀看只有 4.7 萬。**

**→ 本片設計為 3 鏡、每鏡 5 秒、共 15 秒、2 刀。** 正好落在前 8 名的區間。
餐飲片最容易做成快剪美食蒙太奇，那是這份資料裡表現最差的形式。

另一條：**情境 > 美貌**。所以三個鏡頭都是「她在做一件事」，不是「她對鏡頭微笑」。

# 四、Luna × 鮨佐樂

**敘事線**：「日本人在台北，找到最像家的那一口。」
**簽名動作**：吃前雙手合十說 いただきます，吃完說 ごちそうさま
**表演方向**：不推銷。omakase 的氣質就是安靜，Luna 不需要演。

> **這支片的結構就是簽名動作的閉環**：いただきます → 看那一貫 → ごちそうさま。
> 三個鏡頭把品牌識別動作演完，**而且全程沒有拍到食物入口**。

## 鏡 1｜いただきます（5 秒）

| | |
|---|---|
| **畫面** | 她坐在原木吧台前，雙手合十在胸前，微微低頭，然後抬眼看向前方的檜木台 |
| **動作驅動** | 低頭 → 抬眼。`kling3_0` 靠她的動作製造鏡頭動態，不要寫鏡頭晃動 |
| **為什麼是這個** | 簽名動作開場，一秒定身分。**合十是全清單最安全的手勢**——兩手做同一件事、沒有細長物件、沒有手物接觸點 |
| **識別元素** | 原木吧台、手邊一個有顏色的陶杯（每個座位茶杯顏色不同，是最省力的識別元素） |
| **光線** | 吧台上方的檯燈打在臉與手上，背景暗下去 |
| **風險** | 低 |

## 鏡 2｜她看著那一貫（5 秒）

| | |
|---|---|
| **畫面** | 一貫壽司在前景清楚，她在後景微微前傾看著它，眼睛彎起來 |
| **為什麼是這個** | **這是「不拍入口」的核心解法**——讓食物當主角，她的反應是配菜。`CAMPAIGN_PLAN` 風險 #2 說生成模型做不好食物入口，這一鏡直接繞開 |
| **手** | **不入鏡。**沒有筷子、沒有手部近景（風險 #3） |
| **識別元素** | 檜木台、壽司 |
| **風險** | **中——食物生成品質是這一鏡的唯一變數。**這也是最需要先測的一鏡 |

## 鏡 3｜ごちそうさま（5 秒）

| | |
|---|---|
| **畫面** | 空的檜木台、她靠回椅背、再次雙手合十、輕輕吐一口氣 |
| **為什麼是這個** | 收尾閉環。**空盤比「吃」的畫面更好做，而且更有說服力**——吃完了才有滿足 |
| **風險** | **最低。**全片最好做的一鏡 |

**字卡**：進場「京都出身，台北第三年」／收尾「連京都來的女生都說道地」
**語音**：片尾一句日文「ごちそうさまでした」（後製配）

# 五、Yuna × 如嬌

**敘事線**：「韓國女生的保養第一步，是一鍋湯。」
**簽名動作**：先喝一碗原湯，再涮
**表演方向**：她可以講、可以下 verdict（人設的 quirk 就是「講一句話下結論」）

> **這支片的結構就是簽名動作**：舀起原湯 → 捧碗喝 → 下結論。
> 火鍋店要的正是「為什麼這對你好」的說服，而 Yuna 的人設允許她給出這個。

## 鏡 1｜舀起第一碗原湯（5 秒）

| | |
|---|---|
| **畫面** | 金黃濃稠的雞湯在鍋裡，她用店裡那支有雕飾的湯勺舀起一勺、倒進碗裡，湯柱落下 |
| **為什麼是這個** | 簽名動作的第一拍，同時是產品核心（湯色）的最佳展示。**湯是這家店賣的東西** |
| **識別元素** | 濃稠奶白偏金的湯（不是清湯）、有雕飾的湯勺 |
| **風險** | **中**——① 手＋長柄勺（但粗柄比筷子安全）② **蒸氣是已知弱項**（風險 #6）。緩解：prompt 只寫「湯面微微冒著熱氣」，**不要求大量蒸氣**，剩下後製疊 |

## 鏡 2｜雙手捧碗、閉眼喝（5 秒）

| | |
|---|---|
| **畫面** | 雙手捧著碗靠近臉、閉上眼睛喝一口、放下碗 |
| **為什麼是這個** | **整支片最重要的一鏡。**「一碗雞湯抵 10 片面膜」這個品牌訴求，整個就在這個畫面裡 |
| **手** | **雙手捧碗是全清單最安全的手勢**——兩手做同一件事、接觸面大、沒有細長物件 |
| **不拍入口** | 碗沿遮住嘴，「喝」這個動作靠脖子的動作與閉起的眼睛表達 |
| **風險** | **低** |

## 鏡 3｜verdict（5 秒）

| | |
|---|---|
| **畫面** | 她放下碗、一手輕撫喉嚨或鎖骨、看向鏡頭、點一下頭 |
| **為什麼是這個** | Yuna 是兩人裡唯一可以下結論的。**手撫喉嚨＝機能利益的體感表達，不用講話就說完了** |
| **識別元素** | 背景帶到雕花隔屏或櫻花樹（如嬌最強的識別元素） |
| **風險** | 低。⚠️ 背景要帶到隔屏，但**模型景別拉不遠**——隔屏只能當背景的一角，不要企圖拍出全景 |

**字卡**：「이거 진짜 좋아 — 這個真的好」
**語音**：片尾一句韓文「이거 진짜 좋아」（後製配）

# 六、已知會打到的三個地雷

這三個都是 **2026-08-31 LG-05 那次生成剛剛證明的**（見 `CALIBRATION_TEST.md` §30），
不是推測：

| # | 問題 | 對這兩支片的影響 |
|---|---|---|
| 1 | **服裝控制失效（4/4）**。指定領口幾何、三重同義宣告都無效，模型自己給低領蕾絲 | **最嚴重。**這是客戶的品牌素材，Luna 在 omakase、Yuna 在火鍋店穿什麼有場合規範，生成低領是不能接受的。**start frame 一定要人工看過才可以拿去生影片** |
| 2 | **景別拉不遠（3/3）**，目前沒有任何寫法能推遠 | 鮨佐樂**不受影響**（本來就是暗調近景，缺陷方向剛好一致）。如嬌的鏡 3 要帶隔屏，**只能當背景一角** |
| 3 | **相機方位術語可能無效**。`three-quarter front-left` 2/2 給正面；但 `Following her from behind` 是 2/2 成功 | 假設是「模型不吃攝影術語，只吃可想像的場景關係」。**這兩支片的方位一律用場景關係寫**，不要用術語 |
