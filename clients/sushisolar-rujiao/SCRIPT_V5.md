# 如嬌｜腳本 v5「韓國人第一次喝到這種湯」（外國人反應片）

> **Penny 直接指出前面全部走錯類型**：
> 「有一些最簡單的套路，就是**拍外國人來台灣**。他可以說**在韓國從來沒喝過這種口味的湯**之類的，
> **不需要直接在影片裡把價位這些資訊都放進去**。
> 通常畫面都是**拍食物看起來非常誘人、非常好吃的樣子**，然後他**表現出很高的驚喜感**，
> 說『天啊這真的好好喝』，接著講說**真的很推薦大家一定要來這家餐廳試試看**。
> 通常這種情況底下才會**有網友留言問說是哪一家**，KOL 才會去回覆餐廳資訊，
> 或者是在貼文裡面 **tag 這家餐廳的帳號**。」

---

## 一、我上一份 research 查錯類型了

我查的是**中國抖音的「探店」格式**——人均價位、報菜名、勸退提醒、行動指令。
那是**資訊交付型**，適合本地觀眾比價選店。

**Penny 要的是「外國人反應片」——完全不同的類型：**

| | 探店片（我查的） | **外國人反應片（要做的）** |
|---|---|---|
| 核心 | **資訊**：多少錢、點什麼、什麼人別來 | **反應**：她的臉、她的驚訝 |
| 賣點 | 幫觀眾做決策 | **只有外國人能給的比較基準** |
| 價格 | **必須給** | **不需要放進影片** |
| 缺點／勸退 | 必須有，建立信任 | **不需要**，會殺掉情緒 |
| 資訊怎麼給 | 影片裡直接講 | **留言問 → 回覆／貼文 tag 店家** |
| 成功訊號 | 收藏、分享 | **「這家在哪？」的留言** |

**而 Yuna 本來就是韓國人。這個類型是她最自然的形式，我們卻一次都沒用。**

---

## 二、這個類型為什麼有效（research）

- **食物先於人**：食物畫面同時觸發多重感官，是網路上最強的注意力工具之一。
  觀眾看到、聽到食物時，大腦會**開始模擬進食的體驗**，自動補上缺少的味覺與嗅覺。
- **反應必須看起來是即時的**：這類影片的可信度來自「**沒辦法造假的當下反應**」。
- **對鏡頭的眼神接觸**創造陪伴感——像有個朋友在跟你一起吃飯。這是這類影片刻意為之的手法。
- **外國人的比較基準是內容本身**：「在韓國沒喝過這種湯」是一句**只有她能講**的話。
  台灣 KOL 講「這湯很濃」是形容詞；韓國人講「韓國沒有這種湯」是**資訊**。

## 三、腳本（約 38 秒）

| 秒 | 畫面 | 聲音／台詞 |
|---|---|---|
| **0–4** | **只有食物。** 整隻玉米雞躺在金黃濃湯裡，蒸氣細細往上。畫面滿版、很近。**沒有人、沒有字卡、沒有音樂。** | 只有鍋裡的湯聲 |
| **4–8** | Yuna 進畫面，**眼睛已經盯著鍋**，不看鏡頭。她的臉被鍋的熱氣打亮 | **「我是韓國人，我們很愛喝湯。」**（韓國腔，語速慢） |
| **8–13** | 湯勺舀起濃湯，**濃到掛在勺上緩緩落回鍋裡**。特寫 | **「可是這種湯……在韓國沒有喝過。」**（停一下）**「這個顏色不一樣。」** |
| **13–18** | 她雙手捧起白瓷碗、靠近嘴——**在碰到之前切掉** | 瓷碗離桌的聲音；不加音樂 |
| **18–24** | **【全片重點】** 喝完的她。**眼睛睜大、停住半秒、身體微微往後、笑出來** | **「와……」**（停 0.6 秒）**「天啊，這個真的好好喝。」** |
| **24–30** | 她指向鍋（手在畫面外，用視線與身體帶）→ 切到整隻雞的特寫 → 花膠的特寫 | **「一整隻玉米雞，熬兩天。」**「這個是花膠。」 |
| **30–35** | 回到她，**直視鏡頭**，表情從驚訝轉成認真推薦 | **「이거 진짜 좋아。真的很推薦，一定要來喝喝看。」** |
| **35–38** | 店內空景（櫻花樹＋吧台）＋**只有店名**的字卡 | 餐廳底聲收尾 |

### 字卡（極簡）

- 全片只有兩處字卡：**8–13 秒的「韓國沒有這種湯」**、**35–38 秒的店名**
- **不放地址、不放價格、不放三店清單**
- 逐字字幕照常（靜音觀看用）

### Caption（資訊放這裡，不放影片裡）

> 我是韓國人，我們很愛喝湯。
> 但這種湯，我在韓國真的沒有喝過。
> 一整隻玉米雞，熬兩天。
> ——@（如嬌帳號）
>
> 想知道在哪一間的留言跟我說 🍲

**地址與三店資訊放在留言第一則**，或等網友問了再回。

## 四、這一版和前四版的差別

| | v2–v4 | **v5** |
|---|---|---|
| 開場 | 人先出現／有台詞 | **只有食物，4 秒不說話** |
| 她的功能 | 講道理、下結論、演一個誤會 | **給出只有韓國人能給的比較** |
| 情緒 | 克制的 verdict | **真的驚訝，笑出來** |
| 資訊 | 塞在影片裡 | **移到 caption 與留言** |
| 結尾 | 三店 CTA | **一句推薦 ＋ 店名** |
| 成功訊號 | 看完 | **有人留言問「這在哪」** |

## 五、要處理的一個人設張力

`character.md` 寫 Yuna 是**克制**型，「不要語速快、大笑、誇張反應」。
但這個類型需要**驚喜感**。

**解法**：驚訝不等於浮誇。
她的驚訝要演成**韓國人的「진짜?!」**——眼睛睜大、停住、身體往後、然後笑出來，
**而不是台式業配的「哇～超好吃的啦！」**

> **「와……」那半秒的停頓，比任何形容詞都有說服力。**
> 這也跟她「先講結論再補一句」的語癖一致。

## 六、技術可行性

| 需要 | 我們的狀況 |
|---|---|
| 食物特寫要誘人 | ✅ 客戶照片 i2v 已驗證（倒湯、雞鍋兩支都過） |
| 她講韓國腔中文 | ✅ `wan2_7` 已驗證 |
| **喝的動作** | 🔺 用 POC #2 的規避法：**捧碗 → 靠近 → 切 → 喝完的表情**。不拍入口 |
| **驚訝的表情** | 🔴 **這是我們沒測過的**——過去只做過克制表情。**眼睛睜大＋笑出來屬於較大幅度的表情變化** |
| 視線先看鍋、再看鏡頭 | 🔴 **視線離開鏡頭全專案 8 次全失敗**。**必須用首幀決定視線**：第 4–8 秒那顆首幀就要是「低頭看鍋」的狀態，不要求模型在片中轉視線 |

**兩個新風險（表情幅度、看鍋的首幀）都要先用便宜的首幀測，不要直接跑影片。**
