## 一、客戶概況

同一位客戶旗下兩個餐飲品牌，希望用 Virtual KOL Studio 的數位人設當品牌代言人／發言人，
並製作宣傳影片。客戶已口頭同意：**兩間店社群帳號（IG 等）發布過的素材，我方可任意取用發揮。**
（⚠ 此授權範圍需書面確認，見 CAMPAIGN_PLAN 第八節「素材使用分級」——客戶帳號上有大量
轉發自部落客／網紅的內容，那些版權不在客戶手上。）

客戶動機（原話轉述）：「希望達到有漂亮女生幫忙代言的效果。」
→ 客戶是**看外型選人**的，不是看人設內容路線選人。這一點決定了後面所有調整的自由度：
外型不能動，其餘（國籍設定的在地化、內容路線、語氣）都可以為這個案子重寫。

## 二、兩間店的基本盤

### 2.1 鮨佐樂 omakase（@sushisolar）

| 項目 | 內容 |
|------|------|
| 業態 | 無菜單日本料理／江戶前壽司，師傅發辦 |
| 地址 | 台北市大安區大安路一段 192 號 1 樓（捷運大安站週邊） |
| 規模 | **12 席，全預約制** |
| 價位 | 午 NT$3,500–8,000／晚 NT$4,000–8,000（2026 夏季菜單，含海膽限定套餐） |
| 招牌 | 「變態壽司」（黑鮪魚佐赤海膽）、「融化壽司」（星鰻配比目魚鰭邊） |
| 主廚 | 木村哥（@rken1224） |
| 客群特徵 | 饕客、商務宴請、紀念日；**港澳觀光客是明確客群**（店家自己在講） |
| IG 現況 | 約 3.7K 追蹤，內容以季節菜單公告、價目說明、轉發部落客貼文為主 |

**商業模型判讀**：12 席 × 預約制 = 座位是硬上限，**行銷目標不是「衝來客數」，是
「訂得到位的稀缺感 + 品牌溢價 + 訂位需求填滿冷門時段」**。內容要做的是慾望與地位感，
不是促購折扣。

**現況痛點**：帳號是公告板，不是內容資產。有菜單、有價格、有別人拍的照片，
但沒有一個「屬於這家店的人」在說話。高單價餐廳最缺的就是這個。

### 2.2 如嬌 花膠雞·鍋物（@rujiao_hotpot）

| 項目 | 內容 |
|------|------|
| 業態 | 花膠雞湯火鍋（自稱台灣首創花膠雞鍋品牌） |
| 門市 | 台北民權一店（松山區民權東路三段 60 巷 9 號）、台北仁愛二店（大安區仁愛路四段 300 巷 20 弄 12 號）、台中三店（西區存中街 13 號） |
| 招牌 | 黃金花膠雞湯鍋——玉米雞＋干貝＋金華火腿熬近兩天，頂級花膠 |
| 品牌訴求 | **膠原蛋白／「越喝越美」／「一碗雞湯抵 10 片面膜」** |
| 客群特徵 | 女性客群、閨蜜聚餐、家庭、養生美容需求；價位中高 |
| IG 現況 | 約 4.4K 追蹤、**僅約 27 篇貼文** |

**商業模型判讀**：三店、可複製、翻桌率導向 = **行銷目標就是來客數**，
而且有明確的地域性（台北兩店＋台中一店，內容需要能分流到不同店）。

**現況痛點**：貼文數量嚴重不足（27 篇），品牌故事（兩天熬煮、花膠等級、美容機能）
完全沒有被講出來——這其實是最好做的部分，因為故事本身很強，只是沒人講。

## 三、一句話總結兩店的差異

| | 鮨佐樂 | 如嬌 |
|---|---|---|
| 賣什麼 | 稀缺感、職人、場合價值 | 來客數、機能利益（美容）、可複製 |
| 內容目標 | 讓人「想被帶來這裡」 | 讓人「這週就想去吃一鍋」 |
| 內容節奏 | 少而精，質感優先 | 量要夠，頻率優先 |
| 視覺語言 | 低飽和、暗、木頭、特寫、安靜 | 暖、金黃湯色、熱氣、豐盛、人聲 |
| 適合的代言氣質 | 內斂、有品味、說話少但有份量 | 明亮、有說服力、講得出「為什麼對你好」 |

**這張表是後面所有配對與內容決策的依據。**
