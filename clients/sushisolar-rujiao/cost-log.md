## 2026-08-26 生成方式變更：一個 spec 只生一張

pilot 用 `count=2` 跑了兩組，**每組兩張的構圖、姿勢、服裝幾乎一模一樣**。
第二張沒有提供新資訊，等於把同一個結果再看一次。

→ 往後 **一個 spec = 一張**。不滿意就改 prompt 再生。
要同場景多張變體，寫成不同的 spec（不同表情、不同景別），不靠 `count`。

**這不是為了省成本**（圖只要 0.12 credits/張），是為了**每一次生成都要學到東西**。
