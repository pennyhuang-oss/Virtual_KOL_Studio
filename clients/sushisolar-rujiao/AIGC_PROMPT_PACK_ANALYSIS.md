# 外部 AIGC 短劇提示詞包｜分析與可移植性評估

> 來源：Penny 提供的 Google Drive 資料夾（28 個 .txt，全部為簡體中文）。
> 原用途：**AI 短劇／漫改劇**（小說 → 分鏡 → Seedance 2.0／即夢 2.0 生成）。
> 本檔判斷：**哪些能搬到「虛擬 KOL 幫餐廳推廣」的素材上，哪些不能，以及為什麼。**
> 起因：如嬌成片 v1 交出去後，Penny 判定「要說它好也沒有好到哪裡去…可能原本的腳本就寫得不像是一個 KOL 在推廣一間餐廳」。

## 二、🟢 可以直接搬、而且我們現在正好沒有的五件事

### 1. 鏡頭「內部」的時間軸拆解 —— 這是最大的一條

他們每一顆鏡頭都寫成 3–4 個時間段，每段給齊四件事：

```
[0-3秒]  鏡頭：[景別]+[鏡頭運動]+[核心動作]；音效：[主音效]+[環境音]；[台詞/畫外音]
[3-6秒]  鏡頭：[景別]+[鏡頭運動]+[互動反應]；音效：[關鍵音效]；[台詞/畫外音]
[6-8秒]  鏡頭：[景別]+[鏡頭運動]+[情緒特寫]；音效：[氛圍音]；[畫外音/沉默說明]
[8-10秒] 鏡頭：[景別]+[鏡頭運動]+[下一鏡鋪墊]；音效：[過渡音]
```

**我們的 i2v prompt 是一整段靜態描述——只給模型「一個狀態」，然後祈禱它自己長出五秒。**
他們是給「四個節拍」。這個差別可能就是「看起來沒事發生」的直接原因。

### 2. 音效必須逐段指定

主音效／環境音／關鍵音效／氛圍音／過渡音，**每一段都要寫**。

**我們從來沒有在 prompt 裡寫過任何音效。** 成片的聲音是我事後補洞補出來的，不是設計出來的。
「聲音很薄」對一支 15 秒的推廣片是致命的。

### 3. 風格錨定公式：固定前綴 ＋ 可變內容 ＋ 固定後綴 ＋ 固定負面詞

```
【固定前綴（永遠不動）】超寫實仿真人風格，電影級質感，8K超清，細膩皮膚紋理，
真實毛髮質感，柔和自然光，統一冷色調，電影構圖，景深效果，無卡通渲染
【可變內容（每次只改這裡）】…
【固定負面詞（永遠不動）】卡通，動漫，3D建模，二次元，誇張表情，變形，模糊，塑料感，蠟像感
```

**我們四顆鏡頭是四種視覺個性**：鏡 1／3 是客戶照片轉的深色特寫、鏡 2 是 AI 生的暖色餐廳、鏡 4 是客戶明亮的實景空間。
**它們看起來不像同一支片。** 這很可能就是「不像一個 KOL 在推廣一間餐廳」的視覺成因。

### 4. 「不要字幕」寫進每一則 prompt

他們每個分鏡開頭固定寫「寫實電影感風格，**不要字幕**」。
我們沒防這個——模型自己燒字上去我們就只能重跑。

### 5. 每一則 prompt 內含「承接上一鏡：…」

他們的自檢機制明列：**`video_prompt` 必須包含「銜接前置指令」段落。**
六維一致性裡的「動作連貫：**新分鏡起始動作必須承接上一鏡結束狀態**」。

**我們四顆鏡頭之間零動作銜接**——它們是四個互不相干的片段，靠剪接硬接在一起。

## 三、🟡 要換算、不能照搬的三件事

### 1. 「10 秒一鏡、5–6 組細微動作、嚴禁畫面靜止」

**這條和我們實測得到的規則直接衝突。**
我們的「運動預算：一主一次，其餘寫成穩定狀態」是從失敗裡量出來的
（鏡 3 點頭版：只寫一個點頭，模型還是做出 16.9% 臉高的過大動作 ＋ 預備動作）。

**兩邊的模型不同**：他們針對 Seedance 2.0／即夢 2.0，我們用 kling3_0／wan2_7。
**不能因為文件這樣寫就改我們的規則**——這要單獨驗證。

### 2. 成本結構完全不同

他們的流程假設「10 秒一鏡、可以多跑」。
我們是 **kling 2 credits／秒、wan 1.5 credits／秒**——一顆 10 秒鏡頭要 15–20 credits。
**他們的方法論建立在生成很便宜的前提上，我們沒有這個前提。**

### 3. 景別紀律：「多用近景、特寫、大特寫，少用中景，**不使用遠景**」

我們的鏡 4（櫻花空景）**正好是遠景，而且是承載 CTA 的那一顆**。
這條值得認真對待，但我們的鏡 4 有它的任務（證明真實店景），不能無條件砍掉。

## 四、🔴 不能用的部分

- **違禁詞過濾表**（血腥／低俗／封建迷信）——那是短劇題材的風險，餐廳推廣用不到
- **動漫／漫剧風格錨**（賽璐璐、韓漫 webtoon、新海誠…）——我們是寫實，只有「超寫實仿真人」那一組前綴適用
- **小說台詞 50 字拆分＋情緒標註的 JSON 流程**——我們沒有小說原文，我們是廣告腳本
- **人物三視圖／建模模板**——我們用 soul_id 鎖臉，不需要重建角色

## 五、我自己的判斷：手法之外，腳本可能根本沒有「事件」

**這一節不是從資料夾讀來的，是我對成片的檢討。**

上面那五條都是**手法**。但 Penny 的原話是「不像是一個 KOL 在推廣一間餐廳」，
而我看成片，缺的可能更基本：

| 缺什麼 | 現況 |
|---|---|
| **一個非去不可的理由** | 全片只說「先喝原湯，再涮」。**花膠、干貝、金華火腿、熬近兩天——一個字都沒出現在畫面或聲音裡** |
| **一個事件** | 四顆鏡頭是：產品／臉／產品／空間。**沒有任何事情發生**，沒有轉折、沒有反應、沒有意外 |
| **第三方反應** | 我們自己的競品分析說「第三方的反應可以是內容主體」（前 4 名有 2 支靠這個）。**這支片一個人都沒有** |
| **KOL 的存在感** | 她在 14.7 秒裡出現 3 秒，**沒有碰過食物、沒有進過那間店的空間**。她可以在任何地方 |

**這四點沒有一點是提示詞技巧能解決的。**
所以我認為要同時處理兩層：**腳本層（有沒有事件）＋ 手法層（分鏡與音效怎麼寫）**。
只修手法，會做出一支更精緻、但仍然沒有事情發生的片子。
