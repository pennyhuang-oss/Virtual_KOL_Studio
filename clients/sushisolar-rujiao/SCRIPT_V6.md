## 一、v5 → v6 加了什麼

| | v5（38 秒） | **v6（48 秒）** |
|---|---|---|
| 食物鏡頭 | 2 個 | **5 個**，而且每個都有動作（蒸氣、掛勺、倒湯、花膠顫動、雞肉散開） |
| 驚喜 | 1 次 | **3 次**：湯 → 花膠 → 整隻雞 |
| 真人感 | 無 | **被燙到那一拍**（規劃書自己舉的例子：「湯太燙她被嗆到」） |
| 招牌句 | 出現 1 次 | **出現 2 次**：先是自言自語，最後才對鏡頭 |
| 推薦 | 一句話 | **具體到「點什麼」**：指著鍋說「一定要點這個」 |
| 收尾 | 店名 | **留一個讓人想留言的鉤子** |

**核心原則：這個類型靠的是「食物很誘人 ＋ 她的臉」。所以食物鏡頭要多、要有動作；她的反應要有層次，不是只有一次。**

## 二、腳本（48 秒）

| 秒 | 畫面 | 聲音／台詞 |
|---|---|---|
| **0–4** | **【只有食物】** 鍋蓋掀開，**蒸氣爆開往上衝**，露出金黃湯面與整隻雞。滿版、很近 | 只有蒸氣與湯的聲音。**沒有音樂、沒有人聲、沒有字卡** |
| **4–8** | 金色湯勺舀起濃湯，**濃到掛在勺上，緩緩落回鍋裡**。特寫 | 她的聲音先進來（**人還沒出現**）：**「等一下，你看這個湯。」** |
| **8–14** | 她入畫，**眼睛盯著鍋**，臉被熱氣打亮 | **「我們韓國，也有一整隻雞的湯。」**（停）**「可是裡面是糯米、人參。」**（停）**「這個是……干貝、火腿。」** |
| **14–18** | 湯倒進白瓷碗，**滿到接近碗緣**。她捧起來，**吹了一下** | 倒湯聲放大；她吹氣的聲音 |
| **18–24** | **【驚喜 ①：湯】** 喝完的她。**眼睛睜大 → 停住 0.6 秒 → 眉毛揚起 → 笑出來** | **「와……」**（停）**小聲自言自語：「진짜 맛있다。」** |
| **24–28** | **【真人感】** 她**摀了一下嘴、吐了一下舌頭**，然後笑 | **「啊，好燙。」**（笑）**「太好喝了，我忘記它很燙。」** |
| **28–34** | **【驚喜 ②：花膠】** 湯勺從湯裡**慢慢提起一塊花膠**，膠質**微微顫動、反光**。切到她咬一口（**在入口前切**）→ 她咀嚼後的表情：**眉毛抬起、點頭** | **「這個……」**（想詞）**「花膠。」**（停）**「韓國沒有這個。」**（咬）**「Q 的。」** 字卡：**花膠** |
| **34–39** | **【驚喜 ③：整隻雞】** 湯勺輕輕壓一下雞胸，**肉自己陷下去、散開**。蒸氣 | **「一整隻玉米雞，熬兩天。」**（停）**「肉一壓就散了。」** |
| **39–45** | 回到她，**直視鏡頭**。表情從驚訝轉成認真。她指著鍋的方向 | **「이거 진짜 좋아。這個真的好。」**（停）**「來的話，一定要點這個。」** |
| **45–48** | 店內空景（櫻花樹＋吧台）＋**只有店名**的字卡 | 餐廳底聲收尾 |

### 這幾個決定的理由

| 決定 | 為什麼 |
|---|---|
| **0–4 秒完全不說話** | 這個類型靠食物先抓人。掀蓋蒸氣是火鍋最強的一格 |
| **她的聲音在人出現之前先進來** | 製造「誰在講話」的一拍，也讓 4–8 秒的食物特寫不無聊 |
| **比較從「湯的外觀」改成「裡面放什麼」** | 這是**只有她能講的一句話**，而且**查得到、不會被打臉**。韓國的參雞湯裡是糯米、人參；這鍋是干貝、金華火腿。台灣 KOL 講「這湯很濃」是形容詞，韓國人講這句是**資訊** |
| **把「韓國沒有這個」留給花膠** | 花膠是粵菜／中菜的食材，**韓國菜裡本來就沒有**。這句放在花膠上是安全的，放在雞湯上不安全 |
| **驚喜分三次** | 一次驚喜撐不了 48 秒。**湯（味道）→ 花膠（口感）→ 雞（份量）** 是三個不同維度 |
| **被燙到那一拍** | 全片唯一「不完美」的地方。**它讓前面那個驚訝變得可信**——太順的反應像演的 |
| **招牌句出現兩次** | 第一次是**自言自語**（沒有要給誰聽，所以可信）；第二次才是**對鏡頭的推薦**（有意識地在推薦） |
| **「一定要點這個」** | 比「歡迎來吃」具體。觀眾去了知道要點什麼 |
| **不放地址、不放價格** | 這是反應片不是探店片。資訊放 caption 與留言 |

## 四、技術：哪幾顆有風險、安全替代是什麼

| 鏡 | 風險 | 安全替代 |
|---|---|---|
| 0–4 掀蓋蒸氣 | 🔺 客戶照片裡**沒有掀蓋的動作照**，蒸氣要靠 i2v 生 | 改用**已驗證的雞鍋片**（本來就有蒸氣），用推近取代掀蓋 |
| 4–8 湯掛勺 | ✅ 已驗證（倒湯片） | — |
| 14–18 吹氣 | 🔺 吹氣是嘴部動作，沒測過 | 可省略，改成「捧碗停一下」 |
| 18–24 **睜大眼睛＋笑出來** | 🔴 **沒測過的表情幅度** | 先用首幀測（0.12／張）。**首幀就要是驚訝的臉**，不要求模型在片中變臉 |
| 24–28 **摀嘴、吐舌** | 🔴 **手部＋嘴部，風險最高的一顆** | 退而求其次：**只做「摀嘴」的首幀 ＋ 笑**；再不行就整顆拿掉，用聲音（「啊，好燙」）配她笑的臉 |
| 28–34 湯勺提花膠 | ✅ 同倒湯的物件運動 | — |
| 28–34 **她咬一口** | 🔺 用 POC #2 規避：**夾起 → 靠近 → 切 → 咀嚼後的表情** | — |
| 34–39 **湯勺壓雞胸、肉散開** | 🔴 **食物形變，沒測過**。模型可能把雞做壞 | 改成**湯勺在雞旁邊舀湯**，用台詞帶「肉一壓就散」 |
| 39–45 直視鏡頭說話 | ✅ 已驗證 | — |

**四顆紅字都要先用便宜首幀測，不能直接跑影片。**

## 六、修訂：拿掉「韓國的雞湯是清的」（2026-09-03，Penny 指正）

> 「他講那一句說什麼『韓國的雞湯是清的』，這句可能不要講。
> **因為韓國的參雞湯我記得也是比較濃稠一點的，應該不是清澈的。**」

**她是對的，而且這個錯誤比一句台詞更嚴重**：

參雞湯是整隻童子雞塞糯米、人參、紅棗下去燉，**糯米的澱粉會把湯煮成濁的、偏白的**，
不是清湯。**這句話一講，韓國觀眾第一個留言就會來糾正。**
一支主打「韓國人的真實反應」的影片，**被韓國人指出對韓國菜的常識錯誤，整支的可信度就沒了。**

### 改法：把比較從「外觀」移到「裡面放什麼」

| ❌ 原本 | ✅ 改成 |
|---|---|
| 「韓國的雞湯是清的。」 | 「**我們韓國，也有一整隻雞的湯。可是裡面是糯米、人參。這個是……干貝、火腿。**」 |
| 花膠：「口感好特別，QQ 的。」 | 花膠：「**韓國沒有這個。**」（咬）「Q 的。」 |

**改完之後反而更好：**

1. **不會被打臉**——參雞湯放糯米人參、如嬌放干貝金華火腿，兩邊都是事實
2. **「韓國沒有這個」移到花膠身上是安全的**——花膠是粵菜／中菜食材，韓國菜本來就沒有
3. **而花膠正好是這間店的招牌差異**，等於把最強的一句話放在最該賣的東西上
4. 順帶解決了原本花膠那句「口感好特別，QQ 的」太空的問題

### 給自己記一條

**只有外國人能講的話，前提是那句話對他的母國是真的。**
寫「外國人比較」型的台詞時，**每一句關於母國的敘述都要當成事實查核，不能靠印象。**
