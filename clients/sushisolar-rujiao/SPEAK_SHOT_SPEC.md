### 🔑 為什麼她不用碰食物也成立

R24 的關鍵判斷：**上一版失敗不是因為沒有真的吞嚥，是因為她只點頭、沒有任何可解碼的語意。**

食物關係改由三層同時成立：
1. **鏡 1 的倒湯在她出現前先建立對象**
2. 她的畫面下方**仍有平放白碗、少量湯汁與暗鍋緣**
3. 她**親口說「這鍋」「先喝原湯，再涮」**，並立刻切回整雞湯鍋

> 端碗／喝／放下碗會**重新打開手部、器皿、吞嚥、液體、服裝漂移五類風險**，而它們不是必要的真實感。

### 🔑 鏡 3 用產品 B-roll 承接，是設計不是補救

Yuna 的**同一條錄音**跨過剪接點繼續（L-cut）。這同時做兩件事：
- 用真實產品證據承接她說的吃法
- **把說話鏡後半可能出現的嘴型誤差藏在產品畫面下**

所以成片只需要**前 2.5–3.0 秒**的嘴型是好的。**這是預先設計的剪輯，不是失敗後偷改標準。**

### 文案

- **標題**：「第一碗，先不要涮。」
- **Caption**：「Yuna 的第一碗規則：先喝原湯，再涮。玉米雞、干貝、金華火腿熬近兩天，再加花膠，湯才會是奶白偏金。台北民權／台北仁愛／台中。」
- **「一碗抵十片面膜」不進口播、不進主字幕**——避免把品牌趣味話術升格成客觀美容功效
- 字幕**只做逐字轉寫**，服務靜音觀看；**不再加第二層解說字卡**，字幕稿必須與最終音檔逐字相同

## 二、台詞（R24 逐字指定）

> **好喝。這鍋，要先喝原湯，再涮。**

| 時間 | 內容 | 表演 |
|---|---|---|
| 0.00–0.30 | 無字 | 安靜直視，保留自然起音空間 |
| 0.30–1.05 | 「好喝。」 | **先下結論**；肯定但不興奮 |
| 1.05–1.35 | 停頓 | 嘴自然閉合 |
| 1.35–2.10 | 「這鍋，」 | 「這」捲舌偏輕；指涉桌上與前鏡的湯 |
| 2.10–2.30 | 短停頓 | 像在組織中文，**不演成忘詞** |
| 2.30–3.95 | 「要先喝原湯，」 | 四聲稍平、語速略慢，仍須清楚 |
| 3.95–4.15 | 短停頓 | 為結尾留節奏 |
| 4.15–4.75 | 「再涮。」 | 句尾輕微上揚，**但不是疑問句** |
| 4.75–5.00 | 無字 | 嘴閉合，留剪接尾 |

- **目標語音長度 4.3–4.6 秒**。這是 authoring target，**未實測前不得聲稱已達成**
- 超過 4.7 秒 → **先縮短停頓，不改快語速**，也不後製 time-stretch

### 🔴 第一支不使用「卡詞」

Yuna 的卡詞行為（韓文 → 停 → 翻成中文）是人設檔案標記的最強真實感細節，**但 R24 判定不放在第一支**：

1. 卡詞至少需要韓文詞、停頓、找中文、自我確認，**五秒會被塞滿或必須加長成本**
2. 這是第一次測 voice ＋ `wan2_7` ＋ 中文嘴型，同時加入跨語言與表演停頓，**失敗後無法歸因**
3. **韓國腔本身已經提供人設識別**；通過後第二支再把卡詞當成新增的一個變因

## 四、語音路徑（R24：選 c，先做音檔、通過後再資產化）

**不選**：用無韓國腔的預設 TTS 當正式成片的聲音。
**理由**：7.5 credits 的影片就算嘴型同步成功、聲音不符人設仍不能交付；之後換聲音要重跑，**總成本更高**。

| 步驟 | 動作 | 成本 |
|---|---|---|
| 1 | 做出這一句 4.3–4.6 秒的獨立音檔 | `seed_audio` 每句 **0.1 credits**（`get_cost` 實數） |
| 2 | **音檔先過人耳 gate**（見第五節 A） | 0 |
| 3 | 音檔通過**才**餵 `wan2_7`（既有首幀 ＋ 鎖定的 audio_reference） | 7.5 |
| 4 | 通過後把同一聲音來源**升格為 Yuna 專屬 voice 資產** | 待 `get_cost` |

> **聲音權利是新的資產 gate**：保存來源同意、可商用範圍、是否允許建立 voice element、`voice_id`／`voice_type` 與版本。
> **虛擬人不代表可以任意借用真人聲線。未經同意不得複製真人聲音。**

## 五、驗收

### A. 音檔 gate（不過就不花那 7.5 credits）

- [ ] 台詞逐字正確，沒有漏字、增字、誤讀或韓中亂跳
- [ ] 人耳可辨識為**自然韓國腔中文**，咬字仍清楚；不機械、不戲謔
- [ ] 實測長度約 **4.3–4.6 秒**，五秒內有自然起音與閉嘴尾巴
- [ ] 停頓位置符合第二節，**不出現超過約 0.8 秒的意外空白**
- [ ] 聲量、底噪與爆音可後製使用；**不以 RMS 平不平判斷表演好壞**
- [ ] 聲音來源與使用權限**可進客戶商業素材**

### B. `wan2_7` 說話鏡硬 gate

| 項目 | 判準 |
|---|---|
| 第 0 幀忠實 | 臉、mock-neck、前臂裁切、白碗、鍋緣、背景食客與光色與 start_image 連續 |
| 身份 | 同一個 Yuna；嘴動時不換臉、下顎不熔化 |
| 服裝 | 象牙 mock-neck 維持同一件連續上衣；不降領、不變 choker、不露上胸 |
| 肢體 | 前臂搭桌沿，**畫面下緣不長出手掌／手指**；不新增端碗、比讚、指向食物的手勢 |
| 食物與器皿 | 白碗持續平放；不位移、不增料、不冒出筷子／湯匙 |
| 表情 | 克制、肯定；**不甜笑、不驚訝、不閉眼陶醉**。自然口型不是變臉 |
| 背景 | 食客維持背／側對不轉頭；木屏、牆板、燈籠不變形、不長偽文字 |
| 機位與光 | locked-off；暖主光、中性回填、暗鍋區與燈籠高光不閃爍 |
| 運動預算 | **只有說話**。一次自然眨眼可接受但不要求 |

### C. 嘴型同步（**人耳＋正常速度**，不能用 RMS）

- 至少看兩次：一次只看自然度，一次對照文字與停頓
- 音訊開始後嘴部起始差**不超過約 0.20–0.25 秒**；音訊結束後嘴不得繼續像說話超過 **0.25 秒**
- 「好喝。」後的停頓中嘴應回到自然閉合；**不能音訊已停但嘴還在講**
- **不能連續 0.30 秒以上有清楚語音而嘴完全凍住**，或無語音卻持續快速動嘴
- **正常速度第一次看就明顯感到聲畫分家＝硬 FAIL**；只有逐格才看得到的小偏差判 PASS
- **最低可交付**：從第一個可聽字起，**連續 2.5–3.0 秒**嘴型自然同步

### D. 停損

| 狀況 | 處置 |
|---|---|
| 有 2.5–3.0 秒連續合格窗，身份／服裝／肢體全過 | **採用**，不為追求完整五秒口型重跑 |
| 只有後半嘴型失準 | **提早於自然停頓切去鏡 3**，聲音延續。**0 新增成本** |
| 第一句就嘴型明顯錯位，或前 2.5 秒內換臉／改衣／長手 | **停止**，交給使用者判斷。不自動跑第二支 |
| 第二支（只有使用者確認才跑） | **固定 start_image 與已通過的 audio**，只准簡化影像 prompt。不同時換聲音、台詞、首幀 |
| 兩支重複同類硬失敗 | **停止 `wan2_7`**，不轉用 27.5 credits 的 `flux_3_video` 抽卡 |

> 最後的替代方案是「Yuna 聲音主導版」——靜態畫面短暫建立說話者後立即切產品 B-roll。
> **但若完全看不到可靠嘴型，不得假稱是完整同步說話片。**

## 九、停頓修正（2026-09-03，4 次重跑共 0.4 credits）

Penny 的判定：**音色能當 Yuna（過）；沒有韓國腔但她判定無所謂；🔴 頓點要修。**

> 韓國腔一項由使用者主動放棄，記錄在案：**這是她的決定，不是我判斷不需要。**
> 人設檔案的「韓國腔是資產」仍然成立，只是第一支不追。

### 只改標點，不改字

送進 TTS 的**字完全沒變**（好喝／這鍋／要先喝原湯／再涮），字幕稿也不變。
**標點在 TTS 是韻律控制參數，不是台詞內容**——所以這不算改動 R24 鎖定的 wording。
這一步本身就是在執行 R24 gate A 的「停頓不得出現超過約 0.8 秒的意外空白」。

### 四次結果

| 版 | 送進去的字串 | 總長 | 停頓 1 | 停頓 2 |
|---|---|---|---|---|
| v1 | 好喝**。**這鍋**，**要先喝原湯，再涮。 | 4.90s | **0.84s** 🔴 | 0.43s |
| v2 | 好喝**，**這鍋要先喝原湯，再涮。 | 4.40s | 0.37s ✅ | **0.69s** 🔴 |
| v3 | 好喝**。**這鍋要先喝原湯，再涮。 | 3.90s | **0.87s** 🔴 | 0.29s ✅ |
| **v4** | 同 v2（重跑） | 4.18s | **0.27s** ✅ | **0.35s** ✅ |
| v5 | 同 v2（重跑） | 4.40s | 0.27s ✅ | 0.45s ⚠ |

**兩個發現：**

1. **句號是那個 0.85 秒的來源。** v1 與 v3 都用「好喝。」→ 0.84／0.87；
   改成「好喝，」→ 0.37／0.27／0.27。**這是可重複的因果，不是偶然。**
2. **同一組標點的第二個停頓在 0.29–0.69 之間跳動**（v2 0.69 vs v3 0.29 vs v4 0.35 vs v5 0.45）。
   **這是 TTS 韻律變異，不是標點決定的**——所以 v2 的 0.69 值得重跑，而重跑確實拿到了 v4。
   > 這符合專案規則：**一次失敗＝隨機瑕疵可重跑；兩次同方向＝系統性要改寫。**
   > 句號那條走的是後者（改寫），第二個停頓走的是前者（重跑）。

### ⚠ 帶出來的剪接問題

四個版本的語音跨距都是 **3.2–3.5 秒**，比 R24 的 authoring target（4.3–4.6）短約 1 秒。
**不是缺陷，但成片秒表要跟著改**：「再涮」會落在鏡 2 之內，而不是原設計的落在鏡 3 上。
L-cut 的切點要往前挪，讓「再涮」壓在產品鏡上。**這是剪接參數，不重生。**
