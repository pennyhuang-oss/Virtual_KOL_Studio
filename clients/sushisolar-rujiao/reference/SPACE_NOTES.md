## ⚠️ 這份的限制，先講清楚

**CAMPAIGN_PLAN 設想的是「蒐集多位部落客從不同角度拍的店內畫面」的多角度圖庫。**
**這份不是。這份只有文字描述。**

| 想要的 | 實得 | 原因 |
|---|---|---|
| 客戶 IG 的店內照（多角度圖庫） | ✅ **已於 2026-08-31 用 Apify 取得**（鮨佐樂 24 影片＋4 圖、如嬌 27 圖） | 原記「HTTP 429 被擋」**判斷有誤**：IG 其實回 200，但對不能跑 JS 的 client 只吐空 body。需要能跑 JS 的爬蟲，Apify 一次就拿到 |
| 部落客食記的店內照 | ❌ 零張 | 只取到文字，沒有下載圖片 |
| 空間的文字描述 | ✅ 有 | 從食記正文抽取，見下 |

**後果**：目前只能做到「氛圍對」，做不到「認得出是那家店」。
要提高神似度，需要另外想辦法取得實際圖片。

## 鮨佐樂 Omakase（@sushisolar）

台北市大安區大安路一段 192 號 1F｜12:00–14:00、17:30–21:30

| 元素 | 描述 | 可直接寫進 prompt 的措辭方向 |
|---|---|---|
| **吧台** | **原木製作**，2019 年重新裝潢，板前 **12 席** | **淺色原木長吧台 ＋ 漆紅色出餐檯面**（2026-08-31 看過實拍影片後修正——原本從食記文字推成「暗木吧台」是錯的。整體氛圍是暗的，但吧台木頭本身淺色，出餐面是紅漆。見 `ASSET_LEDGER.md`）|
| **座位** | 一個時段只服務一批客人 | 安靜、無其他客人（**這點很重要：空景在這裡是合理的**，不是合成訊號） |
| **茶杯** | **每個座位的茶杯顏色都不一樣** | 一個有顏色的陶杯放在她手邊——**這是最省力的識別元素** |
| **板前設備** | 吧台內嵌**有冷藏功能的木箱** | 師傅側的木箱 |
| **門面** | **低調、有神秘感，容易走過去沒注意到** | 外景要暗、要窄，不要寫成明亮的店面 |
| **氣氛** | 「乾淨舒適的板前座位」，質感優於亮度 | 暗調、局部打光、低飽和 |
| **招牌菜** | 變態壽司（黑鮪魚佐赤海膽）、融化壽司（星鰻配比目魚鰭邊） | — |
| **主廚** | 木村哥（@rken1224），會依食客步調微調醋飯溫度與抹醬比例 | 師傅的手可入鏡但**要虛化**（手部風險） |

> **對生成最有利的一點**：這家店本來就是暗調、近景、淺景深。
> **模型「總是把景別拉近」的缺陷方向，在這裡剛好是對的。**

## 如嬌 花膠雞．鍋物（@rujiao_hotpot）民權一店

台北市中山區民權東路三段 60 巷 9 號 1F｜17:00–23:30｜捷運中山國中站步行 5 分

| 元素 | 描述 | 可直接寫進 prompt 的措辭方向 |
|---|---|---|
| **風格** | **東方宮廷風**，典雅氣派 | 深色木質、雕花、暖金色調 |
| **標誌性擺設** | **盛開的櫻花樹**、**中式雕花隔屏**、潮牌公仔 | 櫻花樹與雕花隔屏是**最強的識別元素**，一眼認得出 |
| **桌距** | 不大但桌距寬，講話鄰桌聽不到 | 可以只帶一桌，不需要拍出滿場——**對「景別拉不遠」是好消息** |
| **包廂** | 兩間，可打通 | — |
| **湯勺** | **華麗、有雕飾** | 不要寫成普通不鏽鋼勺 |
| **湯** | 黃金花膠雞湯，玉米雞＋干貝＋金華火腿熬近兩天，**濃稠、奶白偏金** | `creamy golden chicken broth`，不是清湯 |
| **附餐** | 點鍋附開胃小菜、**黃金花膠一盤**、甜點 | 花膠單獨一盤＝特寫鏡的現成主體 |
| **店外** | 有**網美打卡牆**、有小道具 | 外景鏡的現成場地 |

> **對生成最不利的兩點**：① 熱氣／蒸氣是已知弱項 ② 「豐盛一桌」需要拉遠，而模型拉不遠。
> **緩解方向**：主體放在鍋與碗（桌面近景），不要企圖拍滿桌。
